## 1. Derivative filtration — a general identity

Let F=(f_1,...,f_m) be a tuple of Boolean polynomials on the whole cube F2^n. Let Q0 be an independent existing linear measurement basis. A sufficient linear observation Q extending Q0 must have ker Q contained in the joint translation stabilizer

    H = {d : f_j(x+d)=f_j(x) for every x,j}.

H is a subspace because translations form a group. The minimum possible row space is therefore row(Q0)+H^perp. The question is how to construct it without enumerating 2^n states or guessing an adequate basis.

Define D_d f(x)=f(x+d)+f(x). For all d,e,

    D_(d+e) f(x) = D_d f(x) + D_e f(x+d).

If all D_d f for d in a subspace K have degree at most k, the coefficient of every degree-k monomial of D_d f is a linear functional of d on K: translating x in a degree-k polynomial preserves its top homogeneous part. It suffices to check a basis of K for the bound, by the displayed composition identity. This does not require lower-degree coefficients to be linear on K.

Start K=ker Q0. Find the largest degree k of a nonzero derivative across a basis of K and all target polynomials. Form all coefficient functionals at that degree using their values on the kernel basis. Intersect K with their common kernels. Every stabilizing d in K must satisfy all those constraints; conversely every d in the refined K has derivative degree strictly below k. Repeat until all basis derivatives vanish. The final K is exactly H intersect ker Q0. Thus, at most d rounds for input degree d, regardless of source dimension. Each added independent row is necessary modulo the previously retained row space. The final rank is the exact minimum for unrestricted linear observation on the full cube. The argument works for any finite Boolean degree; the executable contract is deliberately degree <=4 and n<=128 under explicit work caps. This is a constructive application of elementary translation algebra, not a claim that arbitrary nonlinear measurement languages are optimizable in polynomial time.

For a quadratic, the first nonzero degree-one layer is the polar matrix, and the remaining constant layer is the radical correction of OTG-001. For higher degrees the degree of the residual derivative is the dynamic that determines the next necessary information.

## 2. Executable anatomy

[higher_derivative.js](higher_derivative.js):

- `compile(n,fs,old,cap)`: source ANFs are arrays of distinct BigInt monomial masks, zero mask denotes constant 1. Construct a kernel basis, derive top coefficient rows, append necessary independent observations, and form a decoder by substituting a right section of Q into the original polynomials. Each event carries a concrete indistinguishable pair x,x+d for which the target differs, plus the top-degree coefficient establishing necessity.
- `verify(n,fs,old,g,cap)`: independently expand each derivative by factor toggles, check kernel basis spanning with opposite-pivot rank elimination, verify necessity of each row and point counterexample, then rederive the complete source ANF by recursively expanding g(Qx). This verifies both sufficiency and minimal rank without trusting the producer's elimination or right section. The shared ANF conventions and basic operations are not independent implementations in different languages.
- `observe`, `ev`: evaluation of source and formed decoder.
- `image`: enumerate only the admitted quotient coordinates (cap 16 by default), not the source cube, to find exact joint target outputs and representative quotient coordinates. Surjectivity of Q follows from independent rows over the entire cube.

Example:

```js
const a = require('./higher_derivative.js')
const fs = [[7n, 8n], [11n]]
const g = a.compile(4, fs)
if (!a.verify(4, fs, [], g).ok) throw Error('not admitted')
const z = a.observe(g.rows, 9n, a.meter())
console.log(g.decoders.map(f => a.ev(f, z, a.meter())))
```

Representation is in-memory; canonical portable packets and authenticated authority remain future work. A bounded refusal is not an impossibility proof.

## 4. Nonlinear quotient refinement — separate linear rank from information rank

Given an admitted full-rank linear Q and its decoded old outputs A(z) and requested new outputs B(z), define

    Y = { A(z) : z in F2^r }
    F_y = { B(z) : A(z)=y }.

The old coordinate needs ceil(log2 |Y|) bits if recoded compactly. If the old observation is retained and we add a fixed-width unrestricted nonlinear observation, the exact worst-case additional bits needed are

    d_nl = ceil(log2 max_(y in Y) |F_y|).

Proof: the largest fiber requires distinct supplemental labels for every different new output (pigeonhole lower bound). Assign local ordinal labels independently within each fiber, giving the matching constructive upper bound. A joint re-encoding may use fewer bits than retaining the old fixed-width code and appending new bits. This count says nothing about the work required to acquire those bits, or the minimum under a restricted measurement catalogue. A zero additional-bit result means the old output alone determines the new output, not that computing the decoder is free.

[nonlinear_refinement.js](nonlinear_refinement.js) constructs groups with exact representative quotient coordinates, independently audits coverage of every quotient point and each representative and bit claim, and supports rank/unrank within each old fiber (encode/decode). It relies on the prior source-qualified full-rank Ground. A representative z has a source preimage because Q is onto; this module returns the quotient representative, not a materialized original source vector. The image enumerator is exponential in quotient rank and explicitly capped.

Crucially, the retained test compiles only the *new* source ANFs with the old admitted Q as a prefix; it reuses old decoder objects unchanged. It independently verifies the new part, compares minimal rank against a cold joint compilation, and then enumerates the joint quotient. Old formation and verification cost 438,556 units and are retained, not erased. The following table excludes that already-paid setup from retained marginal costs; it includes both compile and verifier for each route but lists image formation/audit separately in the JSON. New requests use the full original source ANF, not hidden parity coordinates as supplied annotations.

This is not a claim that all observations can be acquired cheaply from a compact code: when a new intention splits an old fiber, the lost distinction must be observed from a surviving source/representation. A latent parity is one such example: no more linear information is needed if the old seven coordinates survive, but a four-bit nonlinear output alone cannot reconstruct it.

**Research insight:** the obstruction is not merely a counterexample. Its highest surviving derivative coefficient specifies an entire necessary linear restriction. Applying this recursively constructs a language for a nonlinear computation. Once admitted, a second observation quotient can retain only the distinctions required by later intentions, or precisely witness why more information is needed.
