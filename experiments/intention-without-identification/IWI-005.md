# IWI-005 — Context-scoped finite coverage and epistemic time horizons

**Research date:** November 15, 2026.  
**Status:** executable finite synthetic experiment, with a process-separated signing demonstration and adversarial tests. Hosted CI remains an independent gate.

## Research question

What additional evidence could justify treating a transition as a **stable law** for a requested intention? Can a finite set of state/action observations establish the claim across other contexts and a process restart?

**Core distinction:** finite source reports can support a *conditional, exactly scoped finite-table reconstruction*, but no finite observation prefix alone establishes an unconstrained future law. Signing a report authenticates its claimed issuer, not its truth.

This extends [IWI-001/002](README.md), [IWI-003](IWI-003.md) and [IWI-004](IWI-004.md). It also deliberately preserves [GCI-004](../cross-ground-continuity/gci004/README.md) and [GCI-005](../cross-ground-continuity/gci005/README.md)'s distinction between receiver identity, signed measurement and observational truth.

## 1. A concrete indistinguishability counterexample

Use the inherited seven-state finite Ground. The unknown static transition \`t:0:1\` may lead to state **2** or **3**. Other observed cells, including output cells and an unrelated transition, have identical values in both completions.

The retained observations \`o:0\`, \`o:2\`, \`t:1:2\` cannot distinguish these two laws. Yet an attempt to execute actions \`[0,3]\` from state 1 leads to:

| Completion | State trace | Is terminal in goal 0? |
| --- | --- | --- |
| \`t:0:1 = 2\` | \`1 → 2 → 0\` | **Yes** |
| \`t:0:1 = 3\` | \`1 → 3 → 6\` | **No** (trap) |

An exact machine-readable countermodel is retained in [results/coverage_counterexamples.json](results/coverage_counterexamples.json). Neither completion contradicts the chosen observations. The result establishes why mere agreement with a finite subset of samples cannot justify a universal guarantee for the requested execution.

## 2. Conditional finite coverage

IWI-005 defines an explicit, closed finite state/action/output domain. In the seven-state, five-action example, complete table coverage is:

    7 states × 5 actions = 35 transition cells
    7 state-output cells  =  7 additional cells
    -------------------------------------------
    Total                 = 42 unique cell claims

A separate OS test worker reads the declared synthetic source table and signs its exact cell reports with an ephemeral Ed25519 key. The independent checker requires a distinct correctly ordered receipt for each expected cell, with an exact model revision, context, epoch, host identity, run challenge, state/action key, and value. It rechecks every signature and reconstructs the complete source table without using the producer's table as the accepted answer.

**Critical premise:** The receipt is a table lookup from a synthetic test worker, *not a physical experiment or an E-CPU native receiver transition*. Even if the table had been sampled from a real host, complete finite sampling would only support a stable law under independently justified assumptions. The verifier therefore requires all five caller-supplied contract premises:

- finite state set is complete;
- allowed action set is complete;
- experimenter can faithfully select the claimed pre-state;
- reported output is faithful;
- governing transition/output functions are stationary **within this specific epoch and context**.

The checker tests that these premises are explicitly asserted. **It does not prove them from cryptographic signatures or from the finite sample collection.** Boolean assertions are not trusted hardware attestations, sensor calibration, or an independent proof of physical completeness.

The result status is \`CONDITIONAL_COMPLETE_FINITE_COVERAGE\`, never \`PHYSICAL_LAW_VERIFIED\`. It carries a reconstructed **proposal**, not actual VGI Ground admission or E-CPU permission to execute. The table fingerprint is a canonical SHA-256 commitment to the *reported table data*, not a fingerprint of the physical executable machinery.

This is intentionally more stringent than IWI-004's hypothetical one-cell oracle: a complete test-table read is finite and enumerable, but it does not grant a live host's observation the authority of a universal law.

## 3. Recovery and context cannot be silently collapsed

The test suite invokes a real Node.js worker program twice as **separate operating-system processes**, with the same ephemeral signing identity and retained source-table file. Each new process emits independently signed, request-bound receipts for a new epoch. The checker reconstructs and compares both complete tables.

- **Same complete table / new epoch:** \`CONDITIONALLY_CONSISTENT_ACROSS_EPOCHS\`. This verifies the two signed reports agree; it does **not** prove what happened between them or that future behavior will agree.
- **Same signing identity / changed table after restart:** \`REFUSED_TRANSITION_DISAGREEMENT\`. A valid credential cannot override a semantic contradiction.
- **Changed context, revision, replayed run challenge, or non-increasing epoch:** refusal. A law claim for one exact Ground/context cannot be silently reused under a different one.
- **Signed false table:** the verifier can reconstruct the false data if a dishonestly provisioned source and caller-pinned table fingerprint agree. It does not possess a separate physical truth oracle. This remains an explicit limitation, reinforced by an adversarial test.

The worker demonstration is **not** a hard-kill/recovery of a live E-CPU transport, durable consensus, physical federation, or an independent administrative failure domain. The test's same private key is retained locally in a temporary file and removed afterward; no key is committed to the repository.

## 4. Formal boundaries and proof sketches

### Conditional coverage proposition

Let S and A be known finite, complete sets. Let δ:S×A→S and λ:S→O be total deterministic functions that remain unchanged during a declared context/epoch. Assume each pre-state/action can be faithfully selected, each outcome is accurately reported, and the observed cell values have been verified for **every** member of S×A and S.

Then the reconstructed table agrees with δ and λ **throughout the declared stationary epoch**. Proof: by exhaustive equality of corresponding entries, plus the stationarity premise. This is a finite extensional argument, **not** an empirical proof that the premises hold in an arbitrary external environment.

### Finite-prefix impossibility

For any finite observed time-index prefix of length N, define two systems:

    L₀(t) = 0 for all t
    L₁(t) = 0 when t < N, and 1 otherwise

Both produce exactly the same first N outcomes but disagree at t=N. Therefore, without a stationarity law or some stronger verified structural assumption, **no finite prefix of outcomes alone can entail eternal stationarity**. The retained counterexamples include N=0,1,16,1024. This is a simple established identifiability limitation, not a newly claimed theorem.

### Cross-epoch comparison proposition

If two separately verified bundles are bound to successive distinct epochs, share an externally pinned context/revision/host, and reconstruct identical complete tables, the finite **reported tables** are consistent at their observation points. It does **not** follow that the transitions between observation points, or any future epoch, will be identical. The returned status therefore retains \`unknownBetweenEpochs=true\` and \`unknownFutureEpochs=true\`.

## 5. Reproduction and exact evidence

Files: \`context_coverage.js\` (independent receipt checker, countermodels and epoch comparator), \`coverage_worker.js\` (separate signing process), \`test_context_coverage.js\` (coverage, signature tampering, refused time/context transfer, identical/changed process-produced reports, false-source caveat), and [results/coverage_counterexamples.json](results/coverage_counterexamples.json).

Requires standard-library Node.js 20+:

~~~sh
node --test experiments/intention-without-identification/test_context_coverage.js
~~~

The [GitHub Actions workflow](../../.github/workflows/intention-without-identification-coverage.yml) runs Linux and Windows with Node 20 and 22, alongside the parent IWI test suites. The test worker uses **actual child processes** on each runner rather than a V8 simulated API. Passing CI is evidence of those declared tests only; it does not establish that physical hosts generally satisfy the model's premises.

## 6. Relation to established testing theory

Classical conformance-testing methods, including the W-method, derive finite complete test suites **relative to a fault domain** and assumptions such as a known bound on states, a reliable reset and suitable distinguishing sequences. For examples and details, see [Small Test Suites for Active Automata Learning (2024)](https://link.springer.com/chapter/10.1007/978-3-031-57249-4_6) and [FSM-based conformance testing methods: a survey (2010)](https://www.sciencedirect.com/science/article/pii/S0950584910001278).

IWI-005 **does not implement the W-method**, infer hidden physical state identifiers, or claim fault-domain complete testing. Its direct source-state access and exhaustive table read are deliberately stronger synthetic assumptions. The point is to make those assumptions explicit and refuse to extrapolate from authenticated samples when they are absent.

## 7. Next frontier

A high-value next bridge would replace this test's self-declared source table with **E-CPU receiver-operated transitions** observed through authenticated channels and independently checked against **VGI Ground revision witnesses**, while preserving source state injection, context, replay, time, and host-loss provenance. Only a separately verified source-level invariant or adequate fault-domain conformance contract could elevate such observations to reusable law claims.

The end goal is **intention-relative law certification**: ask only for the transition relationships necessary for a desired realization, but make their justification as strong and independently inspectable as the complete finite-table control used here. Missing evidence remains unknown; contradictory authenticated evidence remains contradictory, and unsupported context transfer remains refused.
