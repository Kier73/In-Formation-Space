# IWI-003 — Lazy navigation across incomplete static Grounds

**Research experiment · 2026-11-15.** Can an observer guarantee a final state without specifying every transition and observation, while retaining what earlier observations taught about persistent unknown laws?

IWI-001/002 already distinguished hidden state and hidden complete transition law. IWI-003 allows **unknown cells within the law itself**. This is a special case of established contingent/conformant planning, not a claim to have invented belief-state planning or solved general compact planning complexity.

## Exact semantics

A model supplies a nonempty initial set B, nonempty goal G, an action alphabet, and for each action and state a **nonempty domain** of possible destination states. Each destination state likewise has a nonempty domain of visible outputs. One *actual, fixed deterministic completion* chooses one value for each unknown cell before execution; the observer does not know that completion, never receives an initial observation, and selects actions according to outputs observed **after** each transition.

Unknown cells are **independent** in this model. Relational dependencies between cells must be represented separately (for example by explicit alternative full laws in IWI-002). A real unknown cell is **persistent**: after its result becomes known within a possible world, that same world must predict the same result when the cell is revisited. A branch-specific scenario stores only the current state and commitments to unknown transition/output cells it has actually encountered.

The lazy AND/OR planner advances each compatible scenario through *every* allowed transition and possible output, splitting on output and retaining the corresponding commitments. A policy leaf is successful only when **every** surviving current state is in the goal. It never gets to choose a convenient completion or silently remove an incompatible one.

The bounded planner explores depths from 0 through a caller-chosen horizon H (maximum 16). The first winning depth is minimal **worst-case actions**. Its separately implemented checker recomputes branch semantics and checks every terminal and observation branch, then independently checks that a shorter strategy cannot win. A negative result means **no certain strategy through H**, not global impossibility. All resource caps throw explicit errors instead of producing a false negative.

A distinct small-model oracle explicitly enumerates all full static laws (cap 256), constructs their disjoint-union state graph, discovers every reachable observation belief and computes the **unbounded** winning attractor. A globally losing initial belief receives a closed losing-trap witness: every available action has an outcome remaining outside the winning set. This oracle is independent of the lazy commitment representation.

The experiment also defines a fresh-effect adversary: an unknown transition can pick a new allowed outcome on **every use**, instead of respecting a fixed law. It is intentionally a different model.

## Three discriminating results

| Case | Static unknown-law result | Independent global check |
| --- | --- | --- |
| Persistent unknown probe, observable diagnostic | **Guaranteed in 5 actions**, proven minimal | Winning rank 5; 13 reachable beliefs |
| Same laws, diagnostic outputs erased | No winner within 5 actions | **Globally impossible**; 6 reachable losing beliefs |
| Shared reset, 24 unrelated unknown binary cells | **Guaranteed in 1 action** | Global enumeration intentionally not attempted |

### Five-action navigation requiring persistent memory

Begin at state 1; only state 0 is the goal. The probe action at state 1 has one *fixed but initially unknown* result: state 2 or state 3. Both appear as output 0. The diagnostic action from those states moves to states 4 and 5, respectively, producing distinct outputs 1 and 2. A reset then moves either diagnostic state back to the starting state 1. The second probe **must revisit the same destination** as the first because its law is fixed. The finishing action is selected from the remembered diagnostic outcome.

~~~text
probe -> diagnose -> (output 1) reset -> probe -> finish-left  -> goal
                   -> (output 2) reset -> probe -> finish-right -> goal
~~~

The independent complete-law oracle proves the minimal worst-case depth is exactly **5**. In the contrasting fresh-effect model, where the second probe may disagree with the first, the global winning-attractor rank is **-1**.

### An actual unbounded refusal

Erase the diagnostic distinctions while preserving the two complete underlying transition laws. The independent global oracle now finds **8 reachable observation-beliefs**, including a **closed trap of 6 losing beliefs**, and certifies impossibility at all finite policy depths. The lazy planner separately reports the honest bounded non-winner result for horizon 5.

### Realization across 16,777,216 completions

A 26-state model has an action that resets all initially possible states to the goal. Another action contains **24 untouched independent binary transition cells**, so the space of fully specified laws has 2^24 = **16,777,216** candidates. The lazy solver visits **3 depth-indexed beliefs**, retains no full-law list, and independently verifies the one-step guaranteed reset.

This is an exact task-relative shortcut because the unknown cells are irrelevant to that specific strategy. It is **not a general algorithmic promise** that arbitrary partial-law planning avoids exponential blowups.

- partial_ground.js: on-demand static commitment search, bounded-optimal policy and independent checker, fresh-effect comparison.
- global_oracle.js: small explicit completion oracle and unbounded strong winning/losing certificates.
- test_partial_ground.js: persistent revisits, observation-law consistency, adversarial policy tampering, malformed/capped inputs, independently verified optimality/refusal, and corpus replay.

## What remains unknown and what should come next

The input domains are synthetic assumptions. The generated traces are **counterfactual worlds**, not physical observations. Local finite mathematics does not authenticate reports, prove sensor coverage, admit a VGI Ground, or authorize remote E-CPU execution. A signed false observation would still be false; a single genuine observed transition does not establish that every unseen transition follows the same law.

The next experiment should retain **versioned real receiver evidence** from E-CPU, compare it against VGI Ground descriptions, distinguish contradictions from absent observations, and synthesize policies valid in **every evidence-compatible completion**. No guessed edges and no unauthorized actions. An unexpected live result should create an explicit model-revision proposal, not silently alter a previously certified strategy.

## Machine-checkable trace support and mathematical proof

[The detailed invariant proof](IWI-003-PROOF.md) explains why persistent partial-law commitments represent exactly the compatible full completions, why finite policy verification is universally sound, why a closed losing trap proves unbounded failure in the small global model, and why the unknown cells touched by a verified policy form a **sufficient, not necessarily minimal, relevance support**.

The dedicated [support_certificate.js](support_certificate.js) walks every verified policy branch and aggregates which unknown transition/observation cells were actually encountered. [Results](results/support_certificate.json): the five-step probe policy reads **one** unknown transition cell, while the one-step reset reads **zero** of its **24** unknown transition cells. Unobserved cells need not be resolved for that particular guaranteed action sequence. The verifier rejects fabricated supports, and separate [tests](test_support_certificate.js) cover unknown output labels and tampering.
