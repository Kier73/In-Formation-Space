# CLT-015 — Bilinear arithmetic over independently structured Grounds

Stacked on CLT-014, commit 8255791e274899abcf218ad0c8e2a725dedbc4a6. Invoke actual CLT-013 fixture/compiler/decoder and CLT-014 marginal arithmetic through a minimal optional API export (default behavior unchanged). Construct a second local descriptor sequence with different internal boundaries and coefficient laws, subject to the exact same outer cycle geometry. This is a bounded compatibility contract, not general alignment of arbitrary sources.

Within a common cycle, each slot has affine start/end coordinates. For every cross-source boundary pair, the sign of their affine difference changes at most once; binary-search the first changed comparison and partition the cycle domain. In each regime, each nonempty overlap has affine start and length. The two local byte patterns have bounded periods; their product has period lcm(mA,mB). Across cycles, choose a joint residue period divisible by both byte periods and both coefficient periods. Along each residue the pattern, relative offsets modulo local periods, and overlap length remainder are fixed.

For t=r+Lq (local regime origin), the overlap sum is affine in q. Its first moment relative to absolute byte coordinate is a polynomial of degree at most three, because cycle geometry is quadratic, overlap start affine and local moment quadratic. Compile Newton forward differences from at most four in-domain samples, then use sum_{q=0}^{K-1} binom(q,j)=binom(K,j+1). Prefix sums of residue differences give direct cycle aggregate. Binary search outer cycle coordinate and evaluate only partial overlap patterns for arbitrary byte endpoints. Exact signed BigInt arithmetic, not constant bit complexity. Count, slots, residue and pattern work capped; mismatch of outer geometry refuses. No general proof of optimal representation. No expansion of model records in producer; actual finite source expansion is separately required for independent checks.

13 finite cases: twelve actual CLT-013 drifting models with distinct second partitions and an additional shrinking/crossing control. Validate 64 random ranges per case for dot product and absolute-coordinate-weighted dot product against raw byte prefixes, and compare the first source marginal with actual CLT-014 index. Large fixture is independently declared, not extrapolation of finite data or an admitted HSG1 wire. Two different boundary geometries cross at a million cycles. Independent oracle sweeps boundaries at each sampled residue and uses endpoint averages for linear product sums and symmetrization for cubic weighted sums. This is independent arithmetic, not trillion-cycle direct execution. Query and formation work metered separately; oracle work, source acquisition, bit arithmetic and memory are not fully priced. The weighted result uses zero-based absolute coordinate, not a local range-relative weight. No wall-clock or native speedup claim. Arbitrary different outer cycle geometries and matrix multiplication remain open.
