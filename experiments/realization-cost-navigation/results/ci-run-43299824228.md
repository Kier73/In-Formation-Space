## MailCPU reference-path work

The experiment compiles an experiment-specific binary decision tree from each complete table using the existing E-CPU `Program`, `BRANCH`, `SET`, and `HALT` instructions. It does not modify or replace E-CPU's existing minterm table compiler.

Every row is required to execute exactly:

`input_width + output_width + 1`

instructions in both MailCPU interpreters: one branch per input bit, one SET per output bit, and HALT. The measured path counts are retained per row. The maximum verified path in this corpus is 14 instructions (eight input bits, five output bits, and HALT).
