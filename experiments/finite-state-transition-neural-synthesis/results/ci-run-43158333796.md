## Liveness-compaction mechanism

The new `compile_live_compositional_transition_program` compiler performs a feature-liveness pass over the typed Boolean expression DAG. At each layer it retains only:
- raw input bits used by later expression nodes or direct output leaves;
- computed ReLU features that are still dependencies of later nodes or output expressions.

Other coordinates are projected away instead of being copied through another identity layer. The compiler still emits ordinary dense layer matrices, but dead rows and hidden features are no longer carried. A complete 16-row Boolean self-check is run after construction.

The result establishes exact behavior only over the complete 16-row Boolean domain for the specified typed transition and its one-row override.
