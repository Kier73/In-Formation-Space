# GLA-004 — Self-observing recurrence discovery

Follow-up to GLA-003. Learn unknown local operator coefficients and observe the discovery process itself. No code copied from historical repositories.

For axis r or c, discover monic causal stencil E[i,j]=A[i,j]-sum(theta[t]*A[i-t,j]) (or along columns). Missing predecessors are zero. This triangular transform is invertible by forward recurrence; column action uses the transposed inverse, via reverse recurrence on the RHS. Fit candidate orders 1..3 over F_257 by exact Gaussian elimination on eight random small systems, rank by 48 observations, then screen the best on 48 fresh observations. All admitted candidates retain the full exact residual and are inverse-certified coefficient by coefficient. Candidate theta values are not supplied. The transform vocabulary (axis and order) is supplied.

The observer records the actual cost and potential q-column savings of each attempted arm, including failed fits and full realization/certificate costs. Self policy uses exponentially decayed per-arm reward and observation counts from its own prior decisions, selects two arms, and periodically tries the least-observed arm. Compare fixed r2/c2, rotating two-arm, and all-six policies. Each policy receives identical 240 tasks in four shifting regimes; no family labels or future task outcomes are supplied to the policy. Each arm's random seed is paired across policies. Rewards are marginal potential savings (not jointly additive); the selected arm minimizes application cost among useful realized arms. Search overhead is sunk; selected representation may not repay it. This is a small hand-designed online bandit heuristic, not autonomous invention of its own learning algorithm.

Ledger: field additions/multiplications, coefficient reads in fitting/transform, candidate support and reconstruction comparisons, and base scans; application ledger checked exactly. Does not price allocation, RNG, indexing, sorting, self-profile bookkeeping or wall time. Independent test workload is generated synthetically with varying coefficients, sparse innovations, random and sparse controls. One stream, one size, one horizon; no statistical claim of generalization. Full residual and exact inverse guarantee reconstruction for the realized matrices, not predictive utility.

Run `node experiment.js > results.json`. Executed same function in JS runtime: 960 product checks, 374 coefficient certificates and 2880 proposals. Results contain prequential decisions, actual rewards, learned profiles and per-regime comparisons. A negative comparison is a valid result.
