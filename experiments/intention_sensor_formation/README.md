# CLT-010 — Intention-driven sensor formation

A deterministic policy over perception S exists exactly when every realized observation fiber has a nonempty intersection of successful action sets. A policy may choose any member of that intersection. Pairwise action compatibility is insufficient: {0,1}, {1,2}, {0,2} have pairwise overlaps but empty total intersection. An inclusion-minimal conflict core is a certificate that the current perception needs refinement (or an expanded action set). The experiment records a core for the initial empty perception; candidate testing uses full fiber intersections, not a pairwise proxy. It searches in order of output width then deterministic expression order, not a conflict-directed optimal grammar search.

Eight source bits, four actions, four seeded concealed coordinate arrangements. The learner queries actual action-success masks at zero, unit and two-bit anchors (37 states); it never sees the hidden task law or permutation. Test empty, single and two-feature perceptions in a bounded grammar of raw bits and pairwise AND/XOR. After two qualified intentions, add their learned expressions to a bank and permit pairwise composition of bank members. The third task is compared with the original grammar alone under the same width cap. This intentionally structured curriculum exposes compositional reuse; it is not a general learning or compression theorem.

Each candidate policy undergoes full-domain checking of its chosen action; failure returns the state and its action mask, which is added to training. An independently implemented recursive feature evaluator then checks every successful policy on all 256 states against the same fixture action-success oracle. A mutation only at state 255 agrees with all initial samples but invalidates the candidate, and the width-one grammar refuses after incorporating the witness. Refusal excludes only the tested grammar/width, not all sensors. No external authority or physical action is claimed.

The learned composed sensor reduces policy output width from two bits to one, not necessarily source acquisition or evaluation cost. Both still depend on four underlying bits. Record training and audit action tests, feature evaluations, candidate tests and partition visits separately. The cold grammar has 64 candidates; warm adds two compositions (66). Earlier A/B work is reported separately and must be included if performed only to solve C. A/B are independent useful intentions in the curriculum. Candidate order and grammar expansion are part of the experiment, not a universal search advantage. The independent final audit, allocation, hashing, sorting, cache storage and bit-operation costs are not fully metered. No wall-clock speedup is claimed.
