## More complex exact model

For `L` layers and `H` attention heads per layer, each token's layer input `x_l` is transformed by pinned finite-field matrices:

```
q_lh = Wq_lh x_l
k_lh = Wk_lh x_l
v_lh = Wv_lh x_l
state_lh <- state_lh + ((1,k_lh) ⊗ v_lh, (1,k_lh))
y_lh = Observe(state_lh, q_lh)
x_(l+1) = x_l + Wo_l concat_h(y_lh)
```

All arithmetic is exact in a declared prime field. Observations may be normalized by field inversion, but **must refuse** a zero denominator. This is a mathematically defined causal, multi-head/multi-layer affine-kernel neural computation with residual connections. It is **not** softmax, Qwen3/Transformer semantics, RMSNorm, RoPE, a trained pretrained model, or float32/float16 inference.

Each head's retained prefix has shape `(key_dim + 1) × value_dim` plus `(key_dim + 1)` field elements and source digest, regardless of token history length. One token's layer-serial update therefore requires `O(L H)` matrix applications and `O(L H d_k d_v)` accumulator work at bounded dimensions. The independent direct-token history oracle rescans every past key/value on each step and is quadratic in the number of tokens. These are *operation-count formulas*, not measured runtime/energy/speedup figures.

**Layer ordering matters.** Heads within a layer read the same layer input, while each downstream layer consumes the newly realized residual output. A segment's moments can be combined independently only after its head-specific `(k,v)` pairs have already been formed. We make **no** claim that arbitrary stacked recurrent neural layers can be segmented and parallelized without recomputing their interdependent inputs.

## Associative range Grounds

Each contiguous interval `I=[a,b)` carries:

```
(count, source_start, source_head,
 matrix_I = Σ_{i in I} φ(k_i) v_i^T,
 mass_I   = Σ_{i in I} φ(k_i))
```

For adjacent intervals `I=[a,b)` and `J=[b,c)`, require the exact same Ground, adjacent indices and `source_head_I == source_start_J`. Merge by elementwise field addition: `(matrix_I + matrix_J, mass_I + mass_J)`. The result is associative and independent of parenthesization. Once **source-verified**, a materialized range can be queried without token payload replay. Source/authority provenance is not implicit: a receiver must inspect the original tokens once or trust a previously audited root that it controls. An untrusted sender's rehash alone establishes no authority.

This permits a future segment tree, bounded parallel *verification of fixed head inputs*, and source-pinned range query. It does **not** turn a mathematical range aggregation into a physical in-transit kernel.

## Continuity and restoration

A source-pinned checkpoint retains the network identity and all current head moments and history roots. The verifier reconstructs typed `PrefixGround` objects and accepts the checkpoint only if its recomputed state digest and source head equal **external receiver-owned high-water pins**. The test destroys the old in-memory state at token 89, rebuilds from the compact checkpoint, processes another 88 tokens, and compares with uninterrupted processing of 177 tokens.

This demonstrates **mathematical continuation**, not durable storage, process-kill recovery, independent trust domains, authenticated transport or E-CPU recovery-lineage quorum. Those would require reusing the already implemented E-CPU receiver/quorum services with independently authenticated state digests.
