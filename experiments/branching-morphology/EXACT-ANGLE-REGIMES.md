# BMO-003: Exact angle-driven canopy transitions at depth two

**Status:** Checkable all-angle convex-hull classification for a fixed finite branching grammar.  
**Date:** 2026-11-14  
**Lineage:** Independent continuation of [BMO-001](README.md) and [BMO-002](EXACT-LATTICE-60.md).  
**Scope:** The convex hull of the endpoints in the **two-expansion** drawing, with unit steps, grammar `F -> F[+F]F[-F]F`, initial heading up, and turn angle `0 < θ < 90°`. This is not a claim about all internal segment crossings or arbitrarily deep expansions.

## Result

For the convex hull of all drawn endpoints, there are **exactly two transitions** of extreme-vertex identity in the stated angular domain:

| Angle interval | cos(θ) interval | Strict convex-hull vertices |
| --- | --- | ---: |
| 0° < θ < 60° | 1/2 < c < 1 | 6 |
| θ = 60° | c = 1/2 | 5 |
| 60° < θ < arccos(1/4) | 1/4 < c < 1/2 | 5 |
| θ = arccos(1/4) | c = 1/4 | 4 |
| arccos(1/4) < θ < 90° | 0 < c < 1/4 | 4 |

The second exact angle is **arccos(1/4) ≈ 75.522487814°**. At each transition an exposed endpoint becomes collinear with its neighboring hull endpoints. The hull vertices remain endpoints generated by the same fixed grammar throughout.

## How an infinite continuum becomes a finite certificate

After exactly two rewrites, the drawing has 25 segments and **26 distinct symbolic endpoints** (a point is represented by the number of unit steps taken at each integer multiple of θ; coincident coordinates at special angles are allowed). For each endpoint `p`, collect the counts `n_k` of steps in headings `kθ` relative to upward. With `c = cos θ`, the exact Cartesian coordinates are

```text
x_p = sin θ * X_p(c)
y_p = Y_p(c)

X_p(c) = Σ_{k > 0} n_k U_(k−1)(c) − Σ_{k < 0} n_k U_(|k|−1)(c)
Y_p(c) = − Σ_k n_k T_|k|(c)
```

Here `T_m` and `U_m` are the Chebyshev polynomials of first and second kind. Thus each endpoint is represented by **integer polynomial coefficients**. For three endpoints a, b, p, the usual oriented area / cross product has the form

```text
cross(a,b,p) = sin θ * P_(a,b,p)(cos θ).
```

Because `sin θ > 0` on the domain, the sign comes entirely from an **integer polynomial** `P(c)`.

For each proposed hull polygon, every endpoint must lie on the left side of every counterclockwise edge. This is a finite collection of polynomial inequalities. The source checks each polynomial over its **entire cosine interval** using exact rational Bernstein coefficients:

```text
Q(z) = (1+z)^d P((a+bz)/(1+z)),   z >= 0

When every coefficient of Q(z) is nonnegative, P(c) >= 0
for every c in [a,b]. If at least one coefficient is positive,
P(c) > 0 for every c in (a,b).
```

The certificate checks all **390** edge-to-endpoint half-plane constraints (including trivial zeros) and **15** strict adjacent-corner orientations (6 + 5 + 4). All pass. Each candidate polygon uses actual symbolic endpoints, is strictly convex in the open interval, and contains every point; therefore its ordered vertices **are exactly the convex-hull vertices** for every angle in that interval.

A separate exact rational monotone-chain hull determines which vertices remain extreme at the two boundary angles. None of this depends on a floating-point grid or approximate root isolation.

## Why the transitions occur at these precise angles

Endpoint IDs refer to the deterministic first-seen enumeration returned by `endpoint_signatures()`. At the first transition, endpoint 7 becomes collinear with endpoints 10 and 0:

```text
cross(point10, point7, point0) = sin θ * 3(2c−1).
```

It is exposed for `c > 1/2`, and ceases to be extreme at `c = 1/2`. At the second transition, endpoint 19 becomes collinear with endpoints 0 and 20:

```text
cross(point0, point19, point20) = sin θ * 3(4c−1).
```

It ceases to be extreme at `c = 1/4`. The exact all-endpoint containment checks exclude other convex-hull transitions between the two identified events.

## Reproduce

No third-party packages are needed; Python 3.11+ standard library suffices.

```bash
python experiments/branching-morphology/angle_transitions.py
python -m unittest discover -s experiments/branching-morphology -p 'test_*.py' -v
```

The first command emits a JSON report naming the 26 symbolic endpoints, the three convex-hull vertex cycles, the two transition polynomials, and the number of checked inequalities. The second runs the existing generator and exact-lattice tests along with five new tests for the Bernstein transform, boundary cases, exact hull reconstruction, witness sign changes, and an **independently implemented floating-point turtle**.

The five new tests and the previous ten tests passed locally on Linux / CPython 3.13.5 (15/15). GitHub Actions is configured to run the complete discovered suite on CPython 3.11 and 3.13; see the run on the pull request.

## What is and is not established

**Verified algebraically by the finite certificate:** All depth-two convex-hull regimes and their exact transition angles for `0° < θ < 90°`, assuming the implemented deterministic grammar and usual planar Euclidean geometry. The positivity argument is universal on each interval; the Python arithmetic uses exact integers and fractions.

**Observed through independent tests:** The symbolic endpoints agree with the previously implemented geometric turtle at sample angles. The certificate recomputes exact rational hulls at rational cosines inside the regions and at both transition values.

**Not established:** At depths three or higher, more hull transitions can arise. Even at depth two, internal segment intersections and overlap may change without changing the convex hull. The interval proof is not a classification of every topological change of the drawn line network; biological interpretation is outside its scope.

**Next research direction:** Scale this approach to depth three, where the number of endpoints grows but each oriented-area test is still a univariate integer polynomial. Explore whether the resulting transition polynomials admit an exact isolating rational interval and independent root-count certificate, rather than requiring a dense angle scan.
