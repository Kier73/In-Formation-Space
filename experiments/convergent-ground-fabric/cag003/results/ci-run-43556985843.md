## Interpretation and remaining dependencies

This is authenticated **workflow-scoped origin integrity** and real receiver-local **pure computation admission**, not independently administered publisher identity. The receiver's public-key trust record was attested by GitHub Actions rather than provisioned from an externally controlled authority. A compromised trusted workflow could generate another attested key.

E-CPU constructs its own SystemSeed/VirtualGroundRef and applies its local compute capability to a deterministic pure handler; the input packet descriptions do not supply code or permissions. The exact retransmitted event returns a cached effect without executing a second time, but does not establish globally atomic exactly-once external side effects.

VGI's eight finite witnesses belong to a separately declared auxiliary Z/8Z Ground tied to the source context. They are **not** a proof or admission of the entire CAG integer operation DAG. The arithmetic result of 44 was checked separately from the actual CAG captured source records.

Both real network protocols ran on the same GitHub-hosted runner over loopback. The separate receiver and verifier jobs exchanged signed artifacts via GitHub, not independent WAN paths. No actual libp2p circuit relay or separately administered NATS service was used, and no independent provider outage was tested.

Therefore [CAG-003 issue #197](https://github.com/Kier73/In-Formation-Space/issues/197) remains open for independently hosted transport domains, stable externally trusted publisher identity, cross-provider outages, receiver decision-time evidence and cost measurements. [PON-002](https://github.com/Kier73/In-Formation-Space/pull/198) provides a separately merged public HTTPS two-operator delivery baseline with a shared source origin, but was not composed into this experiment.
