# OFG-001 — Exact nonlinear observer fibers as a reusable complexity resource

**Research state:** Executed finite and compositional SAT/observer experiment, 22 November 2026. Python standard library; deterministic source replay. This tests observer-relative information cost in a strictly factorizable CNF class, not unrestricted SAT complexity or a P-vs-NP separation.

## Model

Let original CNF F have variables partitioned into disjoint blocks B_i. Require **every source clause** to be contained wholly within one block. Then its satisfying domain factors exactly:

\[
S(F)=\prod_i S_i,\qquad S_i=\{x_i\in\{0,1\}^{|B_i|}: F_i(x_i)=1\}.
\]

For each block the observer supplies arbitrary, potentially nonlinear finite maps o_i(x_i) (already observed) and q_i(x_i) (requested). Define the observer's possible new output fiber

\[
T_i(z_i)=\{q_i(x_i): x_i\in S_i, o_i(x_i)=z_i\}.
\]

Because source constraints and both observation maps are block-separable, the global fiber is the Cartesian product of these sets. Thus the maximum number of distinguishable new observations compatible with one old observation is exactly

\[
M=\prod_i \max_{z_i} |T_i(z_i)|,
\qquad d=\lceil\log_2 M\rceil.
\]

Here d is both necessary and sufficient **in the worst case over old observations** for any fixed-length binary supplement that allows exact recovery of the requested new coordinate from the old coordinate. Necessity is pigeonhole counting on the largest fiber. Sufficiency uses a mixed-radix code of the new-output indices within each local fiber, then pads it to d bits. A representative source assignment for every local pair (o_i,q_i) makes the supplement executable: decoding returns a satisfying original-source witness with the intended new observation. The supplement is a witness/observer code; it is not an encoding of the full original state when q is coarser than identity.

A formula with an empty local S_i has zero satisfying assignments. The independently reconstructed empty local table is a valid UNSAT certificate for the whole factorizable formula; an exhausted budget or rejected cross-block clause is not.

## Resource accounting and refusal

With b blocks, maximum local width k, and m source clauses, local construction and independent replay take O(sum_i 2^{|B_i|} times the local clause-evaluation work), and store O(sum_i 2^{|B_i|}) values plus output encodings. At **fixed k** this is polynomial in source length, independent of the exponentially large product of possible source states. An arbitrary nonproduct CNF or non-block-separable observer mapping is refused. Letting k grow permits exponential construction cost; no universal SAT performance follows.

`compile_ground` emits source SHA-256, exact model count, local fiber tables, source-valid representatives, maximum fiber cardinality, minimal supplement bits, and a separate local-evaluation counter. `verify_ground` independently enumerates Boolean tuples, replays the **original source clauses**, and compares all claims. `encode_observation` requires an original-source SAT witness; `decode_observation` returns another SAT witness with equal old and new observation values. Consumers must independently admit the certificate before using its derived cardinalities.

A source revision changes the digest and refuses reuse. Counterfeit fiber tables, representatives, counts, widths and digests are rejected. Cross-block clauses and missing observation data are refused, rather than turning an invalid decomposition into a false decision.

## Measured experiment

`python -m unittest -v test_observer_fiber_ground.py` — **7 tests passed**, including 120 seeded random small nonlinear observer/CNF cases compared with independently enumerated *global* fibers, exhaustive witness round trips, SAT/UNSAT, tampering and source revision refusal.

`python run_observer_fiber_ground.py` — deterministic 200-query per-case cost and certificate ledger in `OFG-001-results.json` (one local CPython 3.13.5 run, timings are not cross-machine performance claims).

Each block forbids local assignment 11 and therefore admits three assignments. The target new observation is the pair's exact two-bit local value. At b=256 (n=512), 3^256 source assignments exist but only **1,024 local states** are checked by each independent construction pass. The source clause family is deliberately separable. Measured certificate lengths are 19,434–38,766 JSON bytes depending on the old observation.

| Original variables | Existing observation per block | Additional minimum bits | Compile ms | Independent replay ms | 200 encode/decode queries ms |
|---:|---|---:|---:|---:|---:|
| 512 | constant | 406 | 2.085 | 2.044 | 257.706 |
| 512 | parity | 256 | 1.956 | 2.526 | 261.807 |
| 512 | identity | 0 | 2.059 | 2.557 | 268.995 |

The same CNF produces different relative information costs because the old observation partitions the original solution space differently. The identity observer has zero **additional** information requirement but already carries the entire source state. These three rows do not mean increasing observation knowledge is free: acquiring old observations has its own cost, addressed by VL-I TDL-003 and E-CPU observer-path accounting.

## Follow-on experiment

1. Connect this exact fiber certificate to **VL-I TDL-002/003**. Test whether nonlinear source-fiber encoders can be admitted through the existing least-cost observation planner without enumerating the joint state.
2. Extend beyond product Grounds using separator-conditioned factor decompositions, charging for separator width, coordinate compilation and independent reconstruction. This makes direct contact with IFS PNG-001 frontier width.
3. Separate source-version continuity from observer-intention continuity: SFI-004 currently handles strengthening under the same declared interpreter; arbitrary observer-map refinement needs its own source-bound mapping.
4. Retain the three-valued decision policy and E-CPU/VGI authority boundaries. Test a genuinely remote execution only after these semantic contracts are locally verified.
