# OFG-003 — Frontier-derived, cost-aware observer navigation

**Experiment date:** 23 November 2026. **Scope:** source-bound, compositional SAT/observer experiment implemented in Python 3, standard library. **Status:** executable, tests and independent source replay. **Repository:** `experiments/pnp-ground-navigation/observer_fibers/`.

## Question

Can the Boolean problem itself expose **which observations are worth acquiring**, without being given a separator by hand? OFG-001 handled disjoint SAT components, while OFG-002 handled a shared separator specified by the caller. OFG-003 reuses [PNG-001's `min_fill_order`](../frontier_ground.py) to discover bounded separator candidates and then uses OFG-002's verified conditional fiber algebra. It compares alternative separator-bit observation plans *before* seeing their outcomes.

This has a close interface to [VL-I TDL-002](https://github.com/Kier73/VL-I/blob/main/docs/MINIMAL_REFINEMENT_TDL002.md) (minimal linear observation bits), [VL-I TDL-003](https://github.com/Kier73/VL-I/blob/main/docs/COST_AWARE_REFINEMENT_TDL003.md) (costed offered measurements), [E-CPU INTENT-001](https://github.com/Kier73/E-CPU/blob/main/docs/INTENT_001_OBSERVER_FORMED_FABRIC.md) (observer-formed machines), and [VGI's minimax partial-attention policy](https://github.com/Kier73/Virtual-Ground-Interpreter/blob/main/virtual_ground_interpreter/docs/PARTIAL_PROBE_POLICIES.md). OFG-003 is a source-semantic producer: the receiver still separately qualifies any actual sensor observation, execution host or communication path.

## Source → frontier → Ground

An intention specifies `(n, clauses, requested_vars, offers)`. `requested_vars` is a globally fixed projection, independent of the candidate separator. Each offered observation is `(variable, nonnegative declared cost)`. All clauses and offers are checked for well-formed variable IDs.

1. Call **the actual PNG-001** `frontier_ground.min_fill_order` on the source CNF. Replay induced fill edges and collect bounded elimination frontiers; also consider relevant one-vertex cuts and bounded unions of sampled frontiers. For a degenerate edgeless source, include one canonical anchor. This is a finite candidate heuristic, not an optimal treewidth search.
2. For each candidate separator `S`, remove `S` from the **original clause primal graph** and recompute connected components `B_1,...,B_k`. Admit only if each `|B_i|+|S|` is at most `max_bag`, the separator is within `max_separator≤3`, and the number of conditional local assignment visits does not exceed `max_local_states`. Choose deterministically by maximum bag-plus-separator width, local evaluation count, separator width and canonical variable order. Refuse rather than silently weaken clauses if no cut fits.
3. Re-derive the original clauses' bag membership. Every clause must involve at most one private component outside `S`. Therefore, for each separator assignment `t`, the original satisfying set factors exactly:

   \[
   \operatorname{Sat}(F\mid S=t)=\prod_{i=1}^{k}\operatorname{Sat}(F_i(t, B_i)).
   \]

4. Automatically form OFG-002's local finite observation tables. The requested projection's separator bits (if any) appear only in the first bag's new-output label; all other requested bits appear in their unique private bag. This preserves a bijection between global requested projections and tuples of local labels, even if the chosen cut changes. The baseline old local observation is constant. Compile **one** hidden-separator OFG-002 Ground and independently verify every source-attached row and representative.

## Exact partial-observation theorem

For each separator assignment `t`, let `Y_i(t)` be the finite set of requested local observer labels admitted by the original source's `i`th component. For an acquired subset `A ⊆ S` with measured value `a`, the remaining possible new observations form

\[
\boxed{\mathcal Y_{A=a}=\bigcup_{t\in\{0,1\}^{S}:\ t|_A=a}\ \prod_i Y_i(t).}
\]

For every nonempty set of active separator rows, the implementation uses OFG-002's exact inclusion-exclusion algorithm to count the union of overlapping output rectangles. It uses symbolic lexicographic rank/unrank for the target observer tuple, followed by source-valid representative reconstruction and independent original-clause rechecking.

The **necessary and sufficient worst-case supplementary bit count**, for fixed-width coding of the *new observation* after measuring `A`, is

\[
\boxed{d(A)=\left\lceil\log_2\max_a|\mathcal Y_{A=a}|\right\rceil,}
\]

with `d(A)=0` for an empty solution space, which is separately marked `UNSAT`. This quantity is an observer-information bound, **not** the time complexity of finding a SAT witness or a bound on the minimum number of physical probes.

## Costed pre-observation choice

For each subset of the available offers on `S`, the planner enumerates all possible observed bit values `a`, calculates exact fiber cardinalities, and evaluates a conservative symbolic rank/unrank *intersection-probe upper count* `W(A,a)`.

With `r` distinct admitted rectangles and local output domains `D_i`, the declared intersection probe bound is:

\[
W(r,D)= (2^r-1)\,k\,(2\sum_i |D_i|+1)+rk.
\]

This upper-bounds selected subset-by-component iterations for one rank/unrank round trip; it is **not** a bound on Python wall-clock time, memory bandwidth, energy or the cost of an externally supplied witness. The planner separately charges a shared Ground-preparation ledger `P` for both local source enumerations and independent replay, a conservative clause-check count, and the number of sampled separator candidates.

For declared observation prices `c_v` and a nonnegative integer navigation-work price `u`, choose

\[
\boxed{A^*=\arg\min_{A\subseteq\mathrm{offered}(S)}\left(P+\sum_{v\in A}c_v+u\max_a W(A,a)\right).}
\]

Tie-break by fewer acquired bits, then lower supplementary information bound, then variable order. The Ground is prepared **once**, and its construction price is explicitly shared across the counterfactual policies. The algorithm optimizes over the sampled separator and offer subsets, not all decompositions or arbitrary measurement methods. The distinction between declared navigation units and observed elapsed time is retained in the benchmark ledger.

## Reproduction and exact evidence

From this folder:

```sh
python -m unittest -v test_frontier_observation_planner.py
python -m unittest -v test_observer_fiber_ground.py test_separator_fiber_ground.py test_frontier_observation_planner.py
python run_frontier_observation_planner.py > OFG-003-results.json
```

The tests independently enumerate **all global assignments and their requested projections** on randomized small arbitrary CNFs that admit a bounded cut; they compare SAT model counts and every conditional output fiber with the symbolic Ground, and round-trip every satisfying assignment through observer rank/unrank. Extra tests cover one- and two-variable discovered separators, a deliberately expensive missing observation, selective one-bit acquisition, invalid dense cuts, source mutation, forged costs and certificates, JSON round-tripping, a fresh Python verification process and explicitly `UNSAT` sources. **23 combined OFG-001/002/003 tests passed** in the reported local environment (Python 3.13).

The independent `verify_plan` call reconstructs min-fill candidate discovery, the clause-primal components, full OFG-002 Ground rows and the cost-policy choice from the original intention. A fresh-process CLI, `verify_frontier_plan.py`, reads `{intention,plan}` from JSON stdin and rejects falsified evidence. The intention itself must be anchored by its receiver to original source bytes.

### Measured fixtures

The single-hub fixture has `n=b+1` variables, clauses `(s ∨ ¬x₁) ∧ (¬s ∨ ¬x₂)`, and target projection `(x₁,...,x_b)`. The compiler *discovers* `S={s}`. There are exactly `2^b` source assignments and `4b` local visits, instead of enumerating the global `2^(b+1)` Boolean cube.

| Case (`b=256`) | Acquired separator | Additional bits (worst) | Declared intersection bound | Median encode | Median decode |
| --- | --- | ---: | ---: | ---: | ---: |
| Free observation | `{s}` | 255 | 262,144 | ~1.4 ms | ~11.5 ms |
| Prohibitively expensive observation | none | 256 | 787,712 | ~1.7 ms | ~41.7 ms |

Both rows have exactly `2^256` models and 1,024 local-state visits. Cold compilation and independent verification were charged and timed separately; time measurements are local and noisy. **The observation cost is a declared input, not an observed sensor latency.** The `2^256` count is an exact mathematical consequence of the source's constraints, not an exhaustive SAT search.

A second fixture has 24 private variables and **two shared separator variables**, giving 26 variables and 16,777,218 source models. The compiler discovers `{1,2}`. With both observations free it selects both (2,352 symbolic probes), with only observation 2 cheap it selects that one (7,032 probes), and with both prohibitively expensive it acquires neither (16,368 probes). In all three, the worst-case target projection still requires 24 supplementary bits; the improvement is **navigational rather than informational**. See `OFG-003-results.json` for measured producer, independent checker, rank/unrank timings and certificate bytes.

## Interface and next tests

`compile_plan(Intention(...)) → JSON-compatible certificate`; `verify_plan(intention,certificate) → True or GroundRefusal`; `observe_source_state` is explicitly a **test fixture** requiring a supplied source-valid assignment, not an external sensor; `encode/decode` preserve the original requested projection and source CNF. Unknown, unauthenticated physical observations are not silently accepted. No general SAT solver, Lean proof, optimal decomposition, host authentication or P-vs-NP result is claimed by this scoped experiment.

**Next:** extend from a global separator to **nested junction-tree messages** (tree decomposition) with proof-carrying observer output projections and arbitrary old-observation maps. Then consume actual VGI-finalized measurement receipts in VL-I TDL-003 and let E-CPU select a receiver-approved path; keep the source-semantic certificate separate from live execution authority.
