# OFG-002 — Separator-conditioned observer-fiber Grounds

**Status:** executable bounded research; exact arithmetic; source-replayed certificates; 22–23 November 2026. The new result extends [OFG-001](OFG-001.md) from disjoint SAT factors to multiple factors joined through explicitly declared separator variables, without enumerating their global assignment product. This is a tractable structural family, not a universal SAT solver or a P-versus-NP theorem.

## Cross-repository design decision

This experiment builds on existing capabilities rather than duplicating them:

- [IFS PNG-001](../README.md): exact SAT/#SAT frontier factor elimination; width is an explicit resource. OFG-002 is a constrained star decomposition, with a shared separator and bounded local bags. Generic clause-to-factor decomposition is future integration work.
- [IFS PNG-003](../PNG-003.md): source-derived algebraic structure and proof-carrying transformations; discovery cost remains separate from navigation.
- [VL-I TDL-002](https://github.com/Kier73/VL-I/blob/main/docs/MINIMAL_REFINEMENT_TDL002.md): exact additional linear observation bits by rank. OFG-002 supplies a nonlinear, constraint-relative witness/observer comparison.
- [VL-I TDL-003](https://github.com/Kier73/VL-I/blob/main/docs/COST_AWARE_REFINEMENT_TDL003.md): least-cost offered observations; OFG-002 computes required information, not the physical cost of obtaining it.
- [NCR-006/007](https://github.com/Kier73/Navigable-Compute/blob/main/docs/NCR-007.md): exact observer-generated linear/nonlinear transition coordinates; OFG-002 is a static solution-set Ground rather than a future-transition quotient.
- [VGI](https://github.com/Kier73/Virtual-Ground-Interpreter/blob/main/virtual_ground_interpreter/docs/PARTIAL_PROBE_POLICIES.md): independent evidence admission and minimax partial observation; our certificate is an exact mathematical candidate, not an authenticated observation.
- [E-CPU](https://github.com/Kier73/E-CPU/blob/main/docs/INTENT_001_OBSERVER_FORMED_FABRIC.md): intentional processor formation and eligible host/path realization remain separate authority boundaries.

## Source and observer model

Take a CNF formula `F` with variables partitioned into a small separator `S` and disjoint nonempty private bags `B_1, ..., B_b`. Each clause uses only separator variables, or variables from `S ∪ B_i` for **one** bag. The input includes the original CNF (not merely a compiled factor), canonical ordered variable IDs, per-bag old and new observation lookup tables, and explicit resource bounds.

At a fixed separator valuation `t`, the satisfying set factors into `∏_i X_i(t)` and the original model count is

\[
\#F=\sum_{t\in\{0,1\}^{|S|}} [F_S(t)]\prod_{i=1}^b |X_i(t)|.
\]

The constructor evaluates exactly `2^|S| Σ_i 2^|B_i|` local assignments; no `2^(Σ|B_i|)` enumeration is performed. Each local observation fiber is

\[
T_i(t,z_i)=\{q_i(t,x_i): x_i\in X_i(t),\ o_i(t,x_i)=z_i\}.
\]

### Visible separator: exact conditional product

If the old observer already knows `t`, the new observable coordinates compatible with old coordinate `(t,z_1,...,z_b)` form `∏_i T_i(t,z_i)`. Thus

\[
M_{\rm vis}=\max_{t\,\text{admitted}}\ \prod_i\max_{z_i}|T_i(t,z_i)|,
\qquad d_{\rm vis}=\lceil\log_2 M_{\rm vis}\rceil.
\]

An exact mixed-radix rank/unrank code realizes the bound. A source-checked representative exists for each local `(t,old,new)` observation. Decoding reconstructs a global original-source satisfying assignment and checks its old and new coordinates.

### Hidden separator: union of overlapping products

For a hidden separator, the producer currently admits only **constant old observations per bag**. This ensures the old coordinate is the same for all source states; it avoids an unaccounted exponential search over possible old labels. The target observation may still be nonlinear in the separator and bag variables.

Each admitted separator valuation supplies an output rectangle `R_t=∏_i T_i(t)`. The available new outputs form the **union** of these potentially overlapping rectangles, not their disjoint sum. Inclusion–exclusion supplies an exact symbolic cardinality:

\[
\left|\bigcup_{t\in A}R_t\right|=
\sum_{\varnothing\ne J\subseteq A}(-1)^{|J|+1}
\prod_{i=1}^b\left|\bigcap_{t\in J}T_i(t)\right|.
\]

This gives the exact maximum new-output fiber cardinality (there is only one old-label vector), and the minimum fixed-width auxiliary code

\[
d_{\rm hidden}=\left\lceil\log_2\left|\bigcup_t R_t\right|\right\rceil.
\]

Prefix-constrained versions of the same formula compute a lexicographic rank/unrank code **without materializing the union's elements**. The decoder identifies an admitted separator row, reconstructs local representatives, then independently checks the final source CNF and observation values.

## A nontrivial measurement: one missing separator bit

`shared_switch_source(b)` has one separator `s` and `b` private bits `x_1,...,x_b`. Its clauses are `s ∨ ¬x_1` and `¬s ∨ ¬x_2`. Thus `s=0` forces `x_1=0`; `s=1` forces `x_2=0`. Each separator row has `2^(b-1)` satisfying source assignments, hence `2^b` source assignments total (including separator identity).

Request the vector `(x_1,...,x_b)` as the new observation. With separator **visible**, the largest conditional fiber has `2^(b-1)` possible values, requiring `b-1` additional bits. With separator **hidden**, the output is the union of two hyperplanes, cardinality `2^(b-1)+2^(b-1)-2^(b-2)=3*2^(b-2)`, requiring `b` bits. In other words, the same CNF and requested output lead to different exact information requirements based solely on what the observer already knows.

For `b=256` the source has **257 Boolean variables, `2^256` satisfying assignments**, and the hidden observer has `3*2^254` distinct possible requested outputs. Construction checks only **1,024 local bag/conditional states** per pass. All large counts are exact Python integers; this does not amount to searching or tabulating an exponential global state space.

The hidden case is more expensive to navigate because rank/unrank evaluates prefix-restricted exact union cardinalities. This demonstrates why ***minimum information bits and minimum computational cost are different objectives***. At separator width `s` the product constructor's local work is `O(2^s Σ_i 2^|B_i| * clause evaluation)`. Hidden inclusion-exclusion uses at most `2^(2^s)-1` nonempty configuration subsets. The implementation refuses hidden separator widths over three, enforces a source-local enumeration budget, and refuses cross-private-bag clauses.

## Evidence and tests

`python -m unittest -v test_separator_fiber_ground.py`: eight tests passed, including 100 seeded random small systems checked by independent **global exhaustive** enumeration of source-valid assignments and global old/new fibers; distinct visible/hidden witness round trips; source revision refusal; tampered counts, bit bounds, representative masks, separator rows, boolean evidence and digests; no-witness UNSAT; and budget/cross-bag/hidden-observation refusals.

`verify_ground` reconstructs every source-bound local fiber independently by Cartesian Boolean tuples and compares all claims. Full global exhaustive verification is confined to small test fixtures; source-factorization validity is checked syntactically on every input. The certificate includes source hash, original separator configurations, local evidence, model counts, information bound, and construction budget. Host authorization, actual physical probe costs, and Lean kernel proof are distinct subsequent gates.
