# SFI-002 — Problem-selected non-affine and heterogeneous SAT interpreters

**Status:** bounded executable research experiment, 21 November 2026 (America/Toronto).  
**Follows:** [SFI-001](SFI-001.md), [PNG-003](PNG-003.md), [VL-I problem-formed execution](https://github.com/Kier73/VL-I).  
**Question:** can a CNF description cause an interpreter to *construct and choose its own internal computational state and operation structure* rather than being assigned one fixed representation for every problem?

**Observed answer, within the tested domain:** yes. We construct and verify local truth-table processors directly from source CNF without gate labels; contrast them against the existing independently qualified affine Ground; and construct a heterogeneous composite of these interpreters when a source CNF admits exact variable-disjoint components. This is an experimental composition of established finite Boolean methods, **not** a proof of P=NP, a polynomial-time SAT solver, or network-native computation.

## 1. Non-affine interpreter constructed from CNF clauses

SFI-001 constructs an affine decoder `x=x*+Nz` from independently proved finite-field relations. SFI-002 broadens the source grammar. The new `morphic_sat.py` accepts **only ordinary CNF clauses**, a declared variable count and fixed construction budgets. It does not accept named AND, OR, MUX, majority or other gates as instructions.

For each candidate support `S={y,x1,...,xk}` (`k≤3`), it collects the original clauses that both mention the possible output `y` and use variables from `S`. It considers all `2^k` inputs and both choices of `y`. A block is admitted as a function only when **exactly one** value of `y` satisfies all of those clauses for every input, and all proposed inputs influence its truth table. Thus the block is *exactly equivalent* to an inferred Boolean function `y=f(x1,...,xk)` — not just equisatisfiable. No function is admitted from an incomplete truth table.

Candidate supports derive from clause scopes and unions of overlapping clause scopes. This matters for compact encodings of multiplexers whose clauses may have scope three despite the full four-variable function. Clause groups are selected without overlap; any unconsumed clauses remain as literal CNF residual. Selection is greedy and deterministic, **not proved to be optimal**. It refuses cyclic decoded dependency graphs. Gate truth tables, consumed source clauses, topological order, remaining clauses and free registers form one digest-bound Ground.

For a chosen acyclic set of functions, each Boolean assignment to the free registers determines **exactly one** source assignment obeying the consumed clause blocks. The remaining source clauses filter those reconstructions. Therefore the generator preserves the exact model set, and #SAT is

\[
  \#F=\sum_{z\in\{0,1\}^{d}}[F(\operatorname{Decode}_{G}(z))],
\]

where `d` is the number of unassigned registers. SAT can stop after a verified satisfying observation; exact #SAT and UNSAT by exhaustion require complete coordinate coverage. The implementation evaluates **the original CNF** at every candidate, not an unverified compiler verdict. Search beyond the declared coordinate limit returns `UNKNOWN`.

The separate `morphic_verifier.py` implements its own clause canonicalization, clause evaluator, truth-table consistency checks, dependency test, exact source-clause partition reconstruction, decoder and independent receipt evaluator. Even if an attacker recomputes the outer SHA-256 after modifying a function, source clause, residual, state register or partition count, the checker rejects the forged mathematical claim. These checks establish exact semantics **within the supplied source CNF**; a checksum does not establish an authenticated observation or host authority.

## 2. The system chooses between candidate interpreter structures

`self_selecting_sat.py` now constructs and checks two candidate architectures:

- **Local Boolean function interpreter:** the new acyclic truth-table DAG and exact source-CNF observer, with a free-register search space.
- **Affine proof Ground:** the original PNG-003 compiler, its independent source-rewrite and resolution proof checker, and the SFI-001 affine search interpreter. The affine path can also return a proof-backed contradiction with zero search coordinates.

A candidate participates only after it has been independently qualified, is under the requested complete-coordinate budget, and can run within 128 declared partitions. The heuristic chooses the feasible candidate with smaller projected coordinate count; an algebraic contradiction requires no search and wins when present. If neither qualifies, it returns `UNKNOWN`. **Both constructions are performed and charged in the measured build cost**; this is a validity-and-cost-selection prototype, not a learned compiler or an optimal representation finder. In particular it does not know whether an unexecuted candidate would answer SAT or UNSAT.

## 3. Multiple internal computational structures in one problem

A CNF may factor as `F(x)=F1(x1) ∧ ... ∧ Fm(xm)` on disjoint variable supports. The compiler constructs the exact clause-variable incidence graph, including isolated variables, and proves an exact partition of all clauses and variables into connected components. Then

\[
  \#F=\prod_{i=1}^{m}\#F_i.
\]

It is sound to construct **different** verified interpreter types for different components. This is standard component decomposition and #SAT factorization; our contribution is to test it as an endogenous interpreter-formation mechanism with precise scope qualification and its native source-reconstruction refusal.

One seeded mixed source contains a 64-variable nonlinear gate DAG and a separate 40-variable affine parity system. Neither monolithic interpreter qualifies under the declared budget: the Boolean-function search has **21** free variables, and the affine representation has **55**. The source graph has two exact independent components. The composite constructs an eight-register non-affine interpreter (168 solutions) and a four-register affine interpreter (16 solutions) and produces **2,688** solutions by their exact product. The process does not enumerate `2^104` assignments.

Adding a **single cross-component clause** to the same source merges the two components. Both monolithic candidates remain over budget. The compiler correctly reports `UNKNOWN`; it does not illegitimately multiply the previous counts. This is a falsifier and a direct indication of the next frontier: compose heterogeneous Ground transformations *inside a connected constraint component*, not just across independent components.

A 64-variable example had 213 source clauses, 1,152 attempted local support/target checks, 50,476 charged local literal scans and ~71 ms combined construction/selection. The 128-variable example had 445 clauses, 2,735 support/target checks, 108,460 local literal scans and ~315 ms construction/selection. These are *measured construction costs*, not zero-cost recognition. Additional real arithmetic, memory, verification, communication and physical-host work are not free.

Tests: **18 unit tests**, including **96 deterministic randomized small arbitrary CNF formulas** compared against independent exhaustive `2^n` counts, plus cross-checks of generated long non-affine circuits, local gate templates, forged receipts, incomplete truth tables, cyclic functional relations, contradictory residuals, changed intention and unknown-budget refusal. The campaign checks known-count seeds, the disjoint formula product, parity refutation, bridge refusal and a 16-bit random-source brute-force count.

## 6. Link to VL-I and E-CPU, and precise limits

This experiment concerns **the formation of the computational organism before physical or virtual-host realization**: the problem selects its registers, truth-table logic, affine laws, locally independent processor components and exact observation contracts. The derived instructions and partitions are pure and bounded, so their receipts are candidates for VL-I's PFI-001/004 generated interpreter path and E-CPU's native DAG, Virtual Layer, and majority-fenced transferable execution claims.

**No E-CPU host, network peer, Hypervisor or quorum was invoked by SFI-002.** SFI-001/PFI-004 separately test such integration for affine SAT. The new non-affine path will need a receiver-local numerical/Boolean operator, proof-bound source identity and E-CPU admission before claiming remote or federally fenced execution. Software execution remains on an ordinary CPU in this campaign.

This is also **not** an original general CNF-to-circuit inference theorem: local Boolean functional dependencies, exact truth-table checking, component decomposition, Gaussian elimination, and bounded solver selection are standard mathematical ideas. The experiment is an intentionally narrow bridge toward a new *system architecture*, not a complexity-class result. P versus NP remains unresolved. Small free dimensions in some families do not establish a polynomial-time compiler or navigator for arbitrary CNF, and arbitrary connected formulas may retain exponential search.

## 7. Immediate next experiment

**SFI-003:** substitute an affine Ground's recovered coordinate expressions into a non-affine local-function DAG *within one connected component*, or vice versa, under proof-carrying typed bridges. Demand exact source-equivalence certificates and cost ledgers for every substitution.
