# SFI-001 — Intention-formed SAT interpreter: direct source-evaluated search

**Status:** reproducible bounded research experiment, 21 November 2026 (America/Toronto). No claim that SAT, #SAT, or P versus NP is resolved. **Relationship:** [PNG-001](README.md) explicit Boolean frontiers, [PNG-002](PNG-002.md) parity recovery, [PNG-003](PNG-003.md) proof-carrying nonlocal algebra, [VL-I PFI-001/002/003](https://github.com/Kier73/VL-I) problem-formed processor and transferable pure claims. All experiments use ordinary CPU execution, not computational action by a passive network.

## Research question

What if the decisive adaptation is not selecting a preexisting language, but **forming the interpreter's internal state, operations and execution topology from the problem itself**? Direct SAT provides an unusually strict test because all witness claims are cheaply checked against the original formula, UNSAT must have a complete proof or exhaustive calculation, and general CNF families can cause the generated search space to remain exponential.

Let CNF F have n source bits. The PNG-003 proof-carrying compiler derives an exact affine algebra Ax=b and a residual R; its independent proof verifier checks source equivalence. When consistent, this yields a bijection x=x_*+Nz with d=n-r free bits. SFI constructs a special-purpose interpreter with d source-coordinate registers and source-bound parity decoder gates. For each z, it **evaluates original F(x)**, not merely the residual or a cached compiler verdict. Distinct SAT and #SAT intentions compile distinct result terminals (early witness vs exact integer accumulation). The interpreter partitions the free-coordinate domain under bounded host capacity and refuses absent coverage.

The decoder and source clause observer are mathematical, not a general proof that any arbitrary Boolean problem has a small useful quotient. Their construction includes the PNG-003 preparation work; no cost is hidden as free advice.

## Verified contracts

1. PNG-003 receipt must pass independent proof replay (consensus, bounded resolution, source-compilation equivalence, algebra/count verification). The producer *already computes a result*, and its time is included in the total compilation bill. SFI must independently execute its own source-CNF evaluator rather than read that result.
2. The generated machine is determined by source/ground digests, exact decoder, original clauses, intention, resource budgets and partition topology; SHA-256 identifies a record, not a trusted host or signed credential. A verifier reconstructs the whole architecture from the source proof even if an attacker recomputes its digest.
3. SAT returns a witness only if original source clauses hold. An UNSAT decision is admitted only if every free-coordinate partition is fully evaluated without a witness **or** a separately verified algebraic/resolution contradiction is present. #SAT sums exact per-coordinate model counts.
4. A work partition result binds to the interpreter digest and coordinate interval; audit reexecutes against original clauses. Missing, duplicated, forged and misordered partitions are rejected; finite budget exhaustion is **UNDETERMINED**, not UNSAT.
5. No claim of physical network migration or cross-host execution is made by this module; the target integration is PFI-003's actual E-CPU `TransferableExecutionClaimStore` and `VirtualLayerRuntime`, which must recheck source-bound stages and gate publication through live quorum evidence.

## One reproducible local campaign

Python 3.13.5, standard library; seed-fixed synthetic fixtures. Source generation excluded. Times are local measurements, not speedup ratios; proof verification and source execution are separately timed. The direct original-source checker intentionally does more evaluation work than an optimized residual solver.

## Complexity account

For a consistent affine Ground of rank r with d=n-r, the direct generated source evaluator visits at most 2^d candidates, with per-candidate source decoding O(n d / machine_word_bits) and source CNF evaluation O(length(F)); arithmetic operation and big-integer bit costs are non-constant. When SAT finds a witness within a partition it may stop early, but a global UNSAT requires every admitted partition unless an independently checked refutation is available. The source-ground compilation includes resolution and structural inference; if an instance is hard there, efficient navigation afterward does not establish any end-to-end polynomial bound. A small observed output (SAT or UNSAT) does **not** imply a cheap interpreter-construction algorithm.

SFI deliberately differentiates **intention-dependent machine structure** from *fixed-language solver portfolio* selection. Its register basis, gates, partition count, and output reducer are derived from the actual CNF and observation contract. It is still a finite, declared family, not a general ability to discover arbitrary proof systems or create physical computer substrates.
