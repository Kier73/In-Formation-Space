# SFI-003 — Using the SAT interpreter to construct a better SAT interpreter

**Status:** executable, bounded self-application experiment, 21 November 2026 (America/Toronto).  
**Predecessors:** [SFI-001](SFI-001.md), [SFI-002](SFI-002.md), [PNG-003](PNG-003.md), and [VL-I's problem-formed executor](https://github.com/Kier73/VL-I).  
**Primary question:** can a system already constructed from a problem **assist in changing the architecture by which it constructs solutions to subsequent problems**?

**Finding:** yes, in a precisely scoped self-application. The existing SFI-002 executable CNF interpreter is reused as a *meta-optimizer* for its own source-derived gate selection. On a satisfiable instance where the previous heuristic kept five free registers, a self-generated CNF identified two compatible functions, yielding four free registers. The modified architecture was independently checked for exact original-source equivalence; an independent finite search verified optimality **within the discovered candidate pool**. The same source extended by eleven isolated variables shows 65,536 versus 32,768 candidate evaluations, with identical exact model counts. This is **not** a solution to general SAT, #SAT or P versus NP, and not evidence of autonomous self-programming beyond this finite compiler decision.

## 1. The feedback loop is actual execution, not a policy slogan

The SFI-002 compiler first learns local Boolean functions directly from an unlabelled CNF and greedily chooses non-overlapping, acyclic functions. This is sound but not optimal: a candidate that looks locally best can prevent two other compatible functions from being selected. Every discarded potential output remains a free search coordinate.

SFI-003 takes the *already-discovered functions* as a new problem, described in precisely the same ordinary CNF format that the system already knows how to interpret. No new general-purpose external SAT solver is imported.

The bounded construction is:

1. Independently reproduce the existing **greedy** interpreter; verify it with SFI-002's separate semantic checker. This is the rollback point.
2. Obtain an ordered pool of at most ten candidate functions `g_i = (output_i, inputs_i, truth_table_i, source_clause_block_i)` that have already been learned from the original CNF. If discovery is truncated or the pool exceeds the limit, **preserve the baseline**.
3. Construct a **meta-CNF** over Boolean selection bits `s_i`, with negative binary clauses `¬s_i ∨ ¬s_j` for either a shared output or shared source evidence clauses.
4. Encode `sum_i s_i ≥ t` as CNF using the exact subset condition:

   \[
   \bigwedge_{U\subseteq[K],\ |U|=K-t+1}\bigvee_{i\in U}s_i.
   \]

   This forces at least `t` selected functions. The combinatorial encoding is intentionally admitted only within a small fixed bound.
5. **Compile this meta-CNF with the pre-existing SFI-002 `morphic_sat.compile_ground`**, execute its generated interpreter with `morphic_sat.execute`, and independently replay all partition receipts with `morphic_verifier.check_partition`. Search descending from `t=K` to just above the greedy result.
6. If an allowed meta-witness selects cyclic dependencies, add the sound *no-good* clause `∨_{i selected} ¬s_i` and run the previously built interpreter again. A cyclic selected set remains cyclic under every superset; the cut never removes a valid candidate architecture. All cycles and attempts are bounded.
7. Construct the proposed superior interpreter, topologically sort its functions, retain the other original clauses as residual constraints, recompute its source identity, and have the **independently implemented verifier** check exact truth-table relations and source-clause partition conservation.
8. Accept an improved architecture only after exact semantic qualification. Under every finite refusal, preserve the pre-existing compiler output and report the construction as non-optimal or unadmitted, never UNSAT.

This is finite, one-level **operational self-application**: an existing generated computation supplies a new architectural decision about the generator itself. It neither runs arbitrary generated Python nor changes the underlying authorization layer. It is opt-in (`choose(..., self_refine=True)`) so existing SFI-002 behavior is preserved by default.

## 2. Correctness contract

Let the source formula be `F(x)`. The original SFI-002 independent verifier checks that each selected gate has an exact source-CNF meaning `y_i = f_i(inputs_i)`, that consumed source clauses are disjoint, and that the remaining original clauses form an exact residual `R`. No clause is lost or invented:

\[
F(x)\iff \bigwedge_{g_i\in G} [y_i=f_i(inputs_i)]\ \land R(x).
\]

With acyclic gate dependencies, an assignment to the `d=n-|G|` free registers reconstructs **exactly one** state satisfying all consumed gate constraints. `execute` then evaluates the **original CNF** for each reconstructed state, preserving exact model counts and SAT witnesses. Greedy and self-refined interpreters may have different internal coordinates; their observable solution set and #SAT result must agree.

The optimizer's meta-interpreter independently verifies its source CNF via the existing source checker and replays emitted partition receipts. A **separate optimization auditor** then performs a different, direct finite enumeration of compatible candidate subsets (at most `2^10 = 1,024` masks), checks cycles, reconstructs the original Ground, and validates the candidate-pool optimality claim. It also checks every claimed meta-SAT witness and every meta-UNSAT threshold against its source CNF, without invoking the meta-interpreter for that audit. A changed meta witness, UNSAT status, original formula, function table, constructed register count, or claimed gain is refused, even if the outer JSON digest is recalculated.

**Scope of optimality:** this establishes the largest number of compatible gates within the *bounded, heuristic candidate function pool*, **not** that the pool contains all useful invariants or that the resulting algorithm has globally minimal runtime, proof size, energy, or communication cost. The independent checker consumes additional computational resources; verification is real work.

## 3. Reproducible direct SAT experiment

The test fixture is a satisfiable six-variable, 20-clause CNF with four discoverable local functional interpretations. The greedy `morphic_sat` compiler selects only one gate; the meta-SAT problem discovers a compatible pair. Direct source-CNF enumeration verifies five models in either representation.

| Measurement | Greedy construction | SAT-refined construction |
| --- | ---: | ---: |
| Original variables | 6 | 6 |
| Discovered source-backed candidate gates | 4 | 4 |
| Selected gates | 1 | 2 |
| Generated registers | 5 | 4 |
| Exact search coordinates | 32 | 16 |
| Exact #SAT result | 5 | 5 |

The optimizer first asks whether four selections are possible and obtains a checked UNSAT meta answer, then three selections (UNSAT), then two selections (SAT). The selected mask is checked against the complete meta-CNF and the proposed machine's original CNF semantics.

Add eleven *unconstrained* original variables to the same formula. These cannot be silently discarded: they each contribute a factor two to the total count and remain free registers in both Ground representations.

| Measured quantity | Greedy | SAT-refined |
| --- | ---: | ---: |
| Original source variables | 17 | 17 |
| Retained registers | 16 | 15 |
| Exhaustive source-observation coordinates | 65,536 | 32,768 |
| Exact model count | 10,240 | 10,240 |
| Median evaluation time, 3 local trials | 286.722 ms | 186.402 ms |

The recorded optimizer added roughly 2.71 ms of compilation versus compiling the greedy Ground on this run. The **median** execution saving was around 100.3 ms per complete counting query on the same host. These are local Python timings, with no fixed CPU affinity or performance isolation; they are a reproducible observation, not a universal speedup, and a different environment can change the numbers. On the six-variable case, extra compilation was more expensive than one tiny query, and its measured crossover was roughly 63 repeated queries. This contrast is central: a successful architectural reduction need not be a net win until the system is used.

The benchmark charges both original and meta construction, and reports meta coordinates examined, meta-source identities, main search coordinates, source observations, median times, and a noisy estimated repeated-use crossover. The meta-SAT interpreter's own generated Boolean gates can reduce the number of meta-coordinates it must examine; those computations are **not free**.

## 4. Adversarial and regression tests

- A randomized campaign of **96** independently generated small CNFs checks source-model counts against a distinct truth-table enumerator and checks no register regression.
- A candidate-rich synthetic CNF forces bounded meta-search refusal and retention of the original verified Ground, not a fabricated optimality result.
- Tight candidate, coordinate, construction-round and meta-clause budgets all retain the original compiler's qualified result.
- Competing/cyclic inferred relations may not become invalid executable cycles.
- Forged meta-SAT witnesses, forged meta-UNSAT statuses, incorrect optimality claims, altered original sources and modified gate truth tables fail under the independent audit, including after their outer digests have been recomputed.
- The existing SFI-002 selection API now has an explicit `self_refine` opt-in. Its default behavior is unchanged; predecessor tests are run alongside the new tests.
- The new code contains **no recursive call to its own refinement API**; its self-application calls only the earlier, already-qualified SFI-002 CNF compiler and interpreter. This prevents accidental unbounded self-invocation.

## 5. Development implications and next questions

The central distinction is between *an interpreter that represents a problem* and *an interpreter that can use its own result to revise its future representation of similar problems*. SFI-003 implements the latter for a bounded exact compiler decision. It is a **proof-qualified compile-time revision**, not a free-standing generally intelligent process.

Next experiments should test:

1. **Measured feedback policy.** Use retained operation-span and execution receipts, rather than only register count, to decide when self-refinement is worth its construction cost, and whether it should be cached for repeated intentions.
2. **Incremental meta-Ground continuity.** If a problem gains one connecting clause, preserve only the previous derivations still justified by the new source, rather than blindly reusing obsolete instructions.
3. **Non-disjoint heterogeneous coordination.** Turn exact affine/Boolean interactions into typed source-preserving substitutions instead of requiring the variable-incidence graph to disconnect.
4. **Structural attention.** The current SFI-002 discovery scans pairs of clause supports, potentially quadratically. Use the new feedback machinery to profile which support discoveries contribute to accepted interpreters, then test indexed and bounded attention without sacrificing the soundness of the remaining Ground.
5. **E-CPU and VL-I.** Carry *the proof-qualified compiler revision itself* as a content-addressed Ground: one process proposes an improved machine, a separate observer rechecks its source and cost evidence, and E-CPU may then admit the new pure execution plan under its original Hypervisor and publication fencing. Do not let the optimizer's checksum grant authority.
