# CIG-020 — Incremental, adaptive realization of a proof-derived language

Uses the actual CIG-019 source-qualified multi-output circuit and independent proof verifier. The interpreter is a trusted local Python producer/receiver prototype. Observation codes are supplied computational inputs; no physical sensor authority, authentication, recovery or source reachability claim for arbitrary codes. E-CPU can later supply authenticated channels, epochs and publication fencing rather than duplicating those mechanisms.

## Event semantics

The circuit is a topologically ordered signed-reference AND/OR DAG. An event changes an observation vector u to u'. Only fanout of changed input nodes becomes initially dirty. Reevaluate dirty nodes in topological order; propagate only if the gate's output changes. Thus unchanged gates form semantic quiescence barriers (CIG-010 applied to executable gate state). The producer maintains old gate values and a heap of dirty gates. The receiver separately admits the source proof, computes its own initial gate state, and maintains fanout sets. For each event it checks the circuit digest, next epoch, canonical observation code, strictly increasing gate indices, every required local gate transition and the complete frontier. If any required gate is missing, a duplicate/extra gate occurs, a result is forged, or the output vector differs, the receiver refuses before committing the overlay. Full events carry only the new code and outputs; the receiver independently recomputes all gates. Failed receipts leave old state unchanged. Epoch checks are session-local, not cryptographic freshness authority. Producer and receiver code share no event traversal logic. Both receive actual observation input values, not proof of their physical origin.

Adaptive mode selects full evaluation if more than max(1,k//8) input bits change. Otherwise it begins delta propagation with at most max(1,gates//8) reevaluations before falling back to full. This bounds attempted delta gate evaluations, not heap/queue cost or wall time. The heuristic is not globally optimal. It records abandoned work; full receipts carry no delta proof log. Receiver verifies the final full state independently; reported attempted work is diagnostic. Forced delta and forced full modes are controls.

## Next mathematical possibility

Source-qualified time navigation for evolving proof-derived circuits: derive a transition operator over retained observations, prove invariant or periodic response structure, and use that structure to jump across repeated event sequences. CIG-004/005 and Navigable-Compute's nonlinear pullbacks supply precedents. A changed input vector alone does not imply a unique temporal law; the operator and its evidence must be explicit. Another useful direction is costed dirty-cone prediction and placement of retained gate state across authenticated E-CPU paths with verified recovery and revision continuity.
