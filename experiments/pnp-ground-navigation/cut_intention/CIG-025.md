# CIG-025 — Chronological rank and selection by signed congruence Grounds

Predecessors: [CIG-023](CIG-023.md), [CIG-024](CIG-024.md). This increment uses the actual admitted CIG-024 CRT diagram, CIG-019 proof-derived circuit and CIG-021 qualified transition/constructive section. It changes the representation used for a chronological query, not the source or law. Receiver ownership remains local. The producer and independent checker implement exact integer arithmetic; no external time or physical realization authority is implied.

## Mathematical construction

Let the periodic indicator at a decision node v with radix b have children F_a, each independent of the current coordinate. Choose a most frequent child H (ties first occurrence). For every integer time t,

```
F_v(t) = H(t) + sum_{a:F_a != H} [t mod b = a] (F_a(t)-H(t)).
```

Recursively express each child as a finite integer linear combination of congruence indicators. A child term with residue r mod m and current digit a mod b joins exactly one class modulo mb: `r + m * ((a-r)*inv(m,b) mod b)`. Coprimality follows from the admitted CRT basis and strict node ordering. Merge equal terms and cancel zero coefficients. Leaves are 0 (empty sum) and 1 (constant class 0 mod 1). This proves by induction that the final sum is a Boolean indicator; the individual signed terms need not be disjoint and are not probabilities. It applies to arbitrary admitted roots, including complemented and shifted roots. The finite transient prefix remains unchanged.

For a term `(r,m,c)`, its contribution to the count on [0,t) is `c * (floor((t-1-r)/m)+1)` with `0<=r<m`. Let `D` be the transient cutoff, `P` the common period, `N` the admitted period cardinality, `A` the number of transient realizations, and `F` the signed floor sum. For `t>=D`, write `t-D=qP+s`, `0<=s<P`. Then

```
R(t) = A + q*N + F(D+s)-F(D).
```

An interval count is `R(hi)-R(lo)`. A one-based ordinal `k` after the prefix has `q,j=divmod(k-A-1,N)`. Find the least phase `s` in [0,P) with `F(D+s+1)-F(D)>j`; the answer is `D+s+qP`. A zero-cardinality tail is unreachable beyond the prefix. The receipt is accepted only when independently checked `R(t)=k-1` and `R(t+1)=k`, or no further occurrence is possible. These two adjacent ranks prove exact ordinal and membership; the checker need not trust search order or the producer's optimization bounds.

## Discrepancy-directed temporal selection

For `a=(D-1-r) mod m`, the term's count on [D,D+s) is `floor((s+a)/m)`. Its scaled error relative to average density is

```
P*(floor((s+a)/m)-s/m) = (a-((s+a) mod m))*(P/m).
```

Multiplying by c and taking the min/max of the endpoints `c*a*(P/m)` and `c*(a-m+1)*(P/m)` gives integer bounds. Sum them over all terms to obtain `L <= P*(R(D+s)-A)-s*N <= U`. At the sought phase, the exclusive rank in the period equals j. Thus the exact phase lies inside

```
ceil((P*j-U)/N) <= s <= floor((P*j-L)/N).
```

Intersect with [0,P-1] and binary search. No floating point or estimate of unknown probabilities is involved. Bounds can be loose, especially for sparse sets. The complete-period binary search remains an explicit comparator. The producer spends O(M) floor operations per residual rank, O(M log P) worst-case selection after compilation, and no iteration proportional to the requested ordinal. Big-integer cost is not constant. Expansion can be exponential, including cases where the earlier MDD is substantially smaller. The exact operation budget limits charged expansion work, not resident bytes or wall time. No general polynomial claim.

## APIs and independent verification

`Rank(lang,i,max_work=...)` recursively compiles only the root cone and preserves the qualified transient and full-period count. `packet()` supplies index, root, canonical signed terms and charged compilation work. `CheckedRank(admission,packet)` takes the existing receiver-owned CIG-024 Admission object, independently collects the live cone, replays the default-child identity bottom-up with separate positive/negative contributions and symmetric CRT, compares every canonical term, and checks the period cardinality. This is a local translation receipt; it is not portable independent authority without source admission. The receiver copies the admitted representation; producer mutations do not establish evidence. `rank(t)` and `select(k,bounded=True)` implement the exact APIs. `verify_select(k,receipt)` checks two adjacent ranks; the probe field is diagnostic metadata rather than a proof of the producer's work. Source identity and index are resolved by the already admitted diagram. Times and ordinal inputs use the existing 4096-bit contract; an out-of-range result is UNKNOWN. Budget exhaustion raises `Budget` on the producer and refuses admission on the checker; no negative result is inferred.

```python
from temporal_rank import Rank
from verify_temporal_rank import CheckedRank
# language, admission are from actual CIG-024 preparation.
r = Rank(language, 0)
c = CheckedRank(admission, r.packet())
k = 10**900 + 173
answer = r.select(k)
assert c.verify_select(k, answer)
assert r.rank(10**1000+173) == c.rank(10**1000+173)
```
