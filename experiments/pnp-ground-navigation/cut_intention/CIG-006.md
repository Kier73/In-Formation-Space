# CIG-006 — Source-selected processor languages and source-certified hard-problem execution

**Checkpoint:** 23 November 2026 · **Repository:** `Kier73/In-Formation-Space` · **Directory:** `experiments/pnp-ground-navigation/cut_intention/` · **Status:** implemented and independently source-verified locally · **Predecessors:** [CIG-001](CIG-001.md), [CIG-002](CIG-002.md), [CIG-003](CIG-003.md), [CIG-004](CIG-004.md), [CIG-005](CIG-005.md). **Source mechanisms:** [SFI-002](../SFI-002.md), [OFG-003](../observer_fibers/OFG-003.md), [PNG-001](../frontier_ground.py), [NCR-007](https://github.com/Kier73/Navigable-Compute/blob/main/docs/NCR-007.md), [VGI partial probe policies](https://github.com/Kier73/Virtual-Ground-Interpreter/blob/main/virtual_ground_interpreter/docs/PARTIAL_PROBE_POLICIES.md).

## Executive result

A source CNF may prove multiple equally valid descriptions of *its satisfying states* while leaving their off-equilibrium dynamics undetermined. CIG-006 makes this a first-class mathematical property. It enumerates a complete **finite, source-proved processor-orientation class**, constructs exact Boolean-polynomial future observers for each candidate, derives an intention-specific minimum-bit nonlinear code, selects a bounded cheapest language, and independently checks the source and every claimed result. It **does not** equate cheapest conditional interpretation with a future observation entailed by the source.

On CIG-005's unchanged **90-variable, 106-clause original CNF**, the source proves **9 local orientation combinations**, of which **4** have conflict-free complete update maps. These have whole-future feature dimensions `10, 8, 9, 9`. For sufficiently late readouts, their exact nonlinear snapshot quotient sizes are `8, 4, 8, 4`, requiring `3, 2, 3, 2` bits. The chosen two-bit language has **8** full-future features. Distinct candidates yield different future observations on the same off-equilibrium initial state: the exact source-certified result is **`INTERPRETATION_AMBIGUOUS`**. At time zero, all candidates yield the same observation and the finite-class result is **`CONSENSUS_IN_DISCOVERED_CLASS`**. The source's original SAT count is still **`2^41`**, and the independent verifier reconstructs an original-CNF-valid witness.

To see the system in action beyond this constructed family, CIG-006 adds exact, bounded SAT/#SAT Grounds for fully detected XOR systems, variable-disjoint CNF components and complete DPLL with checked UNSAT branch trees. It tests nine diverse workloads (up to **480 variables**), **12** held-out near-threshold random 3-CNF sources, and **200/300/500-variable** budget controls. All **87 local regression tests** across CIG-001–006 passed. The independently formulated **SciPy HiGHS MILP** comparison agreed with all decided cases in the reported runs; its infeasibility reports are *not* being presented as checked UNSAT proofs. Native PNG/SFI/OFG/NCR checks are encoded in a separate CI job and must be evaluated from that workflow's results.

## 1. Exact semantic separation: source fixed points versus temporal interpretation

For the source's active coordinates `x ∈ {0,1}^n`, the original clauses form local, complete Boolean relation blocks. For each block `B` and every candidate output variable `o∈B`, independently evaluate the relation on all assignments to the other two variables. Qualify `o` only when the original clauses permit **exactly one** value of `o` for *every* input pair. This proves a total Boolean function `f_{B,o}`. Each of its four truth-table rows is converted into an exact algebraic normal form (ANF) polynomial over the Boolean idempotent ring:

\[
\mathbb B_n=\mathbb F_2[x_0,\ldots,x_{n-1}]/(x_i^2-x_i).
\]

A complete orientation chooses one qualified output per block, with each output variable updated by **at most one** block. Unselected variables retain the identity law. For every conflict-free complete orientation `r`, its synchronous update `T_r` satisfies

\[
\boxed{F(x)\quad\Longleftrightarrow\quad T_r(x)=x.}
\]

This equivalence is checked by a *separate source interpreter on all* `2^7=128` active states in the initial fixture, after independently verifying all original 90-variable endpoint equalities. The source does **not** imply `T_r(x)=T_s(x)` for non-fixed `x`; different choices can yield different temporal observations.

In the CIG-005 source, the independently discovered four ternary blocks have orientation option counts `1, 3, 3, 1`, giving **9** local combinations. Four combinations have distinct outputs and become qualified complete candidate processors. Other combinations collide on an updated variable and are refused rather than arbitrarily composed. If the finite candidate-product budget is exceeded, the selector refuses to assert an exhaustive class or consensus.

This is a **complete search of a declared class**, *not* a search over all possible mathematical dynamics consistent with a fixed-point relation. Even agreement inside the class is explicitly named `CONSENSUS_IN_DISCOVERED_CLASS`, not unqualified source entailment. A real transient dynamics claim additionally requires an authorized temporal model or admissible observation evidence.

## 2. From original intention to exact future language

The declared intention includes original observer variables `O=(O_1,...,O_m)`, a logical time `t`, a chosen initial state `x_0`, and explicit resource budgets. It does not provide an orientation or a gate library.

For each candidate `T_r`, construct its exact pullback `K_r f=f◦T_r`, where Boolean polynomial multiplication uses the support-union/idempotence rule from NCR-007 and CIG-004. The source-derived minimal GF(2)-linear feature language is

\[
W_r(O)=\operatorname{span}_{\mathbb F_2}\{K_r^j O_i:j\ge 0,1\le i\le m\}.
\]

The bounded basis-construction is exact. Independently, the receiver reconstructs a minimal closed orbit using a different GF(2) elimination method, checks equality of spans, proves each matrix row represents the actual ANF pullback, and checks the decoded observation. This minimum refers to the class of linear pullback-invariant ANF feature languages for this `T_r` and `O`, not all computer architectures.

Time navigation uses binary exponentiation of the *feature* matrix, and the same matrix is used to reconstruct the **exact observable ANF polynomials at the requested time**:

\[
P_{r,i,t}(x)=(K_r^tO_i)(x).
\]

There is no step-by-step iteration through an astronomically large `t`; the matrix composition count is measured, and independent source-algebra matrix operations recheck it. CIG-004's prior matrix-orientation regression remains in the complete test suite.

### Intention-specific nonlinear snapshot Ground

The actual required snapshot is the vector `P_{r,t}(x)` rather than an entire time series. Let `U` be the union of original active-variable supports in these exact ANF polynomials. Enumerate at most `2^|U|` local assignments under a declared `|U|≤12` budget to compute its *realizable output image*:

\[
Q_{r,t}=\{P_{r,t}(x):x\in\{0,1\}^n\}.
\]

The least possible lossless **binary** coordinate width for this finite image is

\[
\boxed{b_{r,t}=\lceil\log_2|Q_{r,t}|\rceil.}
\]

CIG-006 then actually **constructs** a canonical encoder: lexicographically order the image, encode each output by its zero-based index, and derive the exact ANF of every binary encoder bit using the Boolean Möbius transform. The decoder is the ordered output-image table. The receiver independently re-derives the coefficients by parity over every submask, reconstructs every source-supported output and rechecks the asserted minimal bit count. It retains the entire exact code rather than only reporting a cardinality bound.

The selected **candidate** is the lexicographic minimum of `(snapshot bits, full-future feature dimension, stored feature-term count, orientation)`. Source equality is proved for each candidate separately. If candidate future ANFs disagree, the result is **`INTERPRETATION_AMBIGUOUS`**, with an independently source-checked counterexample state and divergent output vectors. The chosen candidate is still an executable *conditional* architecture, never a ground-truth claim about off-equilibrium evolution.

## 3. Hard problems: source-formed exact decision and counting

The `heavy_ground.py` dispatcher gives three bounded, source-certified mathematical routes:

1. **Exact recognized XOR/GF(2) Ground**: accept a parity equation only if a *complete* set of ordinary CNF clauses forbids precisely one parity class on a support of arity ≤3. Independently reconstruct the entire original CNF from the recovered equations. Gaussian elimination returns exact rank, `#SAT=2^(n-rank)` and a source-checked witness, or a checkable source-equation XOR combination proving `0=1`.
2. **Source-connected component Ground**: reconstruct the original clause-variable graph, factor its connected components *exactly*, solve each local CNF with bounded DPLL, and multiply independently verified counts. A candidate global UNSAT needs at least one independently checked component UNSAT proof; a candidate global SAT needs a reconstructed original-CNF witness. Exact local #SAT counts are independently enumerated by the receiver for components of at most 18 variables.
3. **Direct complete bounded DPLL**: deterministic unit propagation and explicit binary branching. A SAT result carries an original-clause-verified witness; an UNSAT result carries a source-replayable binary branch tree. The independent verifier recomputes unit propagation, verifies each conflict leaf and checks that all decision branches are covered. Exhausted work/time budget returns `UNKNOWN` and never becomes UNSAT by inference.

The dispatcher chooses based on source structure before seeing any SAT outcome; none of these paths uses an external solver as a hidden oracle. Existing PNG-001, SFI-002 and OFG-003 remain the native complementary implementations; the CI integration checks selected shared sources against their actual APIs. This is a bounded solver portfolio, not a new general SAT algorithm.

### Held-out near-threshold and large random controls

At 3-clauses/variable ratio approximately **4.26**, with four fixed seeds `(201, 202, 203, 204)` each for **50, 75, and 100 source variables**, the system completed **12/12 decisions**: **9 SAT and 3 UNSAT**. All agreed with independently translated SciPy HiGHS outcomes under the reported budgets. Source-ground UNSAT decisions carry full independently replayed DPLL conflict trees. No selection rule was trained on or changed in response to these cases; they are a deterministic held-out campaign rather than a statistically representative industrial SAT benchmark.

For **200, 300, and 500 random 3-SAT source variables**, bounded source DPLL returned **`UNKNOWN`** and the HiGHS comparator also returned **`UNKNOWN`** within its own stated limit. These are explicit unresolved controls, not evidence of a theorem or hidden success.

**Complexity ledger:** source inspection, candidate discovery, structural compilation, solution construction, individual branch work, verifier replay, feature closure, exact ANF multiplication, matrix composition, local image enumeration, and witness/proof materialization are all charged to the corresponding experiments. Reconstructing a reusable representation may dominate navigation. A fast time jump does not itself solve unrestricted SAT.

## 5. Interpretation and next experiments

CIG-006 demonstrates that **the problem and its intention can select a smaller, exact, source-checked computational language within a finite admissible class**, while preserving the difference between a mathematical fixed-point contract and actual physical/temporal authority. The 2-bit snapshot code is proved minimal for its *chosen candidate* over its entire declared active-state domain. Only a consensus observation over the complete discovered class is justified without selecting a temporal interpretation; other source-consistent but undiscovered dynamics remain conceptually possible.

The heavy use pass establishes a practical source-driven portfolio with real verified wins on algebraic and independent-component structures, complete proofs for several UNSAT cases, and honest budget refusals. None of the measured finite source families yields an asymptotic result for arbitrary NP-complete SAT.

**Next builds:** (1) connect an actual VGI-finalized temporal evidence path or receiver-authorized transition model to resolve interpretation ambiguity instead of guessing; (2) add source-proved nested separators and bounded tree decomposition for pigeonhole and coupled nontrivial workloads; (3) compare identical independently sourced DIMACS problems against pinned certified CDCL (DRAT/LRAT) with **matched end-to-end work**; (4) establish machine-checkable Lean source/orientation and nonlinear encoder identities for a bounded first class; (5) hand off accepted, source-pinned pure Grounds to E-CPU/VL-I while keeping mathematical source identity, interpreter identity and execution authorization separate.
