# CIG-013 — Anticipatory regional structural memory

Research checkpoint: 23 November 2026. Predecessors: [CIG-009](CIG-009.md), [CIG-010](CIG-010.md), [CIG-011](CIG-011.md), [CIG-012](CIG-012.md). The implementation directly uses CIG-008 canonical/extract, CIG-009 produce and message verification, CIG-010 audited realization, and CIG-012 receiver-owned Archive. It adds a new independently checked source-strengthening operation; no external physical evidence or host authority is assumed.

## Exact regional translation

For a fixed variable scope V, old CNF C and retained boundary A subset V, the admitted table is M_A(a) = sum over V\\A of [C(a,h)]. Let D be the added local clauses and B the requested boundary. If every variable in D and B belongs to A, the revised function is exactly

```
M_(C AND D,B)(b) = sum_{a|B=b} M_(C,A)(a) [D(a)].
```

This follows by partitioning the original assignments into fibers of A. The source verifier checks identical variable scope, canonical old-clause inclusion, visibility of every added literal and requested variable, descriptor identities, nonnegative canonical integer counts and every sum using assignment tuples. The old message must already be admitted by the receiver. A digest alone is not proof. The producer uses bit masks; the verifier uses a distinct tuple evaluator. A deletion, changed scope or missing coordinate cannot be inferred from the retained marginal; the engine uses a fresh exact route. All actual source/layout and full-witness audits are still performed by CIG-010. This is an exact source transformation, not a general SAT acceleration theorem.

## Finite retention policy

`Portfolio(source,n,tree,price=1,rich=True)` audits the base layout. Each future `(name,source,tree,weight)` is separately audited. A target leaf is matched to a base leaf with identical scope and included clauses (longest clause set, deterministic tie-break). Other regions are charged cold. For each base region select zero or one retained table, considering the current boundary and all subsets of the union of future required coordinates. Width is bounded by the original CIG-010 ten-variable leaf contract. A retained table is actually formed and independently admitted by `Archive.obtain`.

For a candidate A, the leaf-cell objective is

```
J_R(A) = C_build(R,A) + price * 2^|A| + sum_i weight_i * C_i(A).
C_i(A) = 0 if exact source and boundary hit;
         min(2^|A|, C_fresh_i) if requirements fit A;
         C_fresh_i otherwise.
```

The no-retention option has cost `sum weight_i * C_fresh_i`. Exact minimization is separable across regions, within the declared one-table policy and target-to-base matching rule. Costs charge leaf producer evaluations and restriction cells, not wall time, all verifier operations, or physical memory. The runtime uses a cheaper fresh route when a retained projection would cost more. An alternate matching can produce lower realized work than this assigned-group estimate. The planner is not a global budgeted knapsack and does not learn future probabilities. Retention price and frequencies are declared workload inputs. `replace` independently audits the changed forecast, compares group counters, and updates only changed regional objective entries; the full scan and aggregation still cost time.

`Retained` builds a receiver-owned set of seed tables, reporting canonical descriptor+message bytes (not full resident memory; Python indices and the admitted seed archive incur overhead). Every future query receives a fresh transient `RevisionArchive`, so query-derived messages do not silently accumulate across forecasts. On a retained hit it checks original admission and independently verifies the restriction before registering the new source-bound proof. The API is a trusted local Python process, not an authenticated or adversarial process isolation layer. `realize` composes the results and validates the original source witness.

## Heavy measured campaign

Eight explicitly supplied forecast revisions per size, on CIG-011's shuffled cyclic AND/XOR source. Many regions receive pins on previously private coordinates; six cases are SAT and two contain contradictory pins. The independent transfer-matrix oracle checks every count, and every SAT result receives the original source witness audit. Current-only retention restricts candidates to original boundaries; rich retention prices additional coordinates. A cold comparator uses the same realization engine with a fresh Archive per revision. All three paths agree, including the contradictions.

At 2048 variables rich retention admits all 342 selected leaf regions, with 5472 retained cells and 165604 canonical descriptor+message bytes; the current-only policy retains 228 regions, 1824 cells and 101721 bytes. Across eight queries 2736 leaves are reused; all 2728 internal joins are still evaluated. Rich preparation + fresh query + restriction work totals 160072 cells, versus 589696 cold. The independent restriction checker visits another 43776 retained-table cells; original leaf/join verification and source/witness work remain in wall measurements. The declared leaf-only objective falls from 524352 (no memory) to 220584 (current-only) to 100200 (rich). Do not compare that objective directly with end-to-end time.

One local run at 2048 variables: cold queries 2476.00 ms; current-only plan/prepare/queries 400.92/113.76/1945.17 ms; rich 582.44/174.51/1551.87 ms. Rich total 2308.81 ms, including up-front costs, a modest improvement in this workload. Planner cache state and timings are not controlled native-solver benchmarks. At smaller size the up-front costs can exceed savings. One forecast replacement changes one of 342 groups; the incremental selection matches the fresh policy and objective, and the new source counts zero. Measured replacement 29.76 ms versus full replanning 345.71 ms; full-source auditing remains. The attempted 8192-variable campaign did not complete within the available execution budget; no result is claimed for it.

## Next research question

A future constraint can be handled cheaply if its effect is expressible on retained coordinates. A richer interface need not expose all original coordinates: source-proved nonlinear features may suffice if every future required predicate factors through them. Pursue verified predicate-factorization tests and compact sufficient statistics, then a memory-budgeted planner for multiple variants per region. Reduce initial planning and source rebinding overhead; measure against held-out revisions and real E-CPU communication costs without reimplementing the authority/fencing layer.
