# CIG-016 — Proof-directed information acquisition

Research checkpoint: 23 November 2026. Builds on CIG-006, CIG-008, CIG-011, CIG-014 and CIG-015; uses the actual existing proof checkers, count engine, cyclic source/oracle and predicate translator. VGI ProofGround navigation is the related design antecedent.

## Exact refinement

An admitted positive fiber u carries count H(u) and representative r. For a new canonical Boolean clause f, set b=f(r). Construct the opposite obligation E=C AND [q=u] AND [f=1-b]. True clause predicates append their clause; false predicates append one negated unit per literal.

- Verified E UNSAT: decode f=b on this fiber.
- Verified E SAT with no count: SPLIT_UNCOUNTED, both branches have witnesses.
- Verified exact E count m>0: REFINE into counts m and H(u)-m. Both witnesses retained, and 0<m<H(u).
- No admitted proof: UNRESOLVED.

The complementary branch needs no fresh count. The receiver independently reconstructs obligations from its old admitted state and request, checks each status, and admits only a complete counted refinement within the fiber budget. An incomplete attempt leaves its admitted language unchanged, while retaining checked decision proofs for retry. Exact source tuples key the proof-summary archive. Decision witnesses are not counts.

ProofLanguage seeds from a checked CIG-008 count; it attempts bounded CIG-006 DPLL and independently replays conflict trees or checks models. If needed it invokes CIG-008 affine projection and residual factor counting and its independent row-space/factor checker. The new code does not enumerate the complete source assignment space; exhaustive checks occur only in the small-domain tests. The query method calls CIG-014 plan/translate/check_translation using the receiver's own admitted histogram; supported signed unions require no additional proof search or count compilation. Source audit and witness reconstruction still cost work.

Limits: 8192 variables/150000 clauses for counting, 1024/10000 for the decision route, 32 predicates, 4096 realized fibers, per-obligation search and width/cell budgets. Receiver-local proof summaries, not a portable proof archive or authenticated distributed authority. Whole-source prototype, complementary to the CIG-015 local leaf adapter. No general SAT complexity claim.

## Local measured campaign

Six successive observations, full exact histograms checked at each step, then 32 checked retained queries. Affine source: k-variable GF(2) period-three recurrence and k unconstrained bits; independent oracle from two recurrence bits and an observed free bit. Mixed source: CIG-011 cyclic alternating XOR/AND with pinned auxiliary outputs, independent two-state transfer matrix. Labels and clauses shuffled. Cold control counts both branches for each old positive fiber using the same CIG-008 engine and independent checker. Times include initial seed and extension checking/oracle, not subsequent 32 queries. Single CPython 3.13.5 local run.
