## Mathematical construction

The CIG-021 admitted initial code, source-qualified total block transport and constructive total source-image section establish a valid observation trajectory. For each initial lifted location-symbol vertex, let its transient depth and terminal cycle length be d_i and L_i. Take D=max d_i and P=lcm L_i. P is a common period of the tail of the trajectory, not necessarily its minimal global period. Each decoder output yields an exact subset of natural time:

    S_f = { t >= 0 : f(T^t(u_0)) = 1 }.

Represent it by a finite prefix at times [0,D), and a periodic reduced ordered multi-valued decision diagram (MDD) over the CRT coordinates of absolute time t. Factor P into pairwise coprime prime powers b_1,...,b_r, with product P. The Chinese remainder theorem identifies the classes modulo P bijectively with the Cartesian product of residues modulo the b_j. There is no claim that independent time coordinates are distinct times; CRT provides the single common time coordinate.

A primitive bit depends on one spatial permutation cycle. Its eventual period L divides P, and its local residue table is built only over L, not P. Atoms are compiled by reducing relevant CRT coordinates modulo gcd(L,b_j). The producer steps the local transport; the checker reconstructs local phases from the admitted functional-graph cycle positions. The checker proves every atom has no irrelevant coordinate dependency, repeats its children at the appropriate smaller modulus, and matches all L local phases. Every original live decoder gate is then translated by Boolean diagram operations; complement, AND, OR and XOR preserve exact set semantics. Identical ordered nodes are interned; a node with all identical children collapses. Terminal 0 denotes the empty set and terminal 1 the full remaining coordinate space. The canonical identity is relative to the chosen CRT basis and fixed ordering. The finite prefix is retained separately, so equal tail diagrams alone do not imply equal full sets when transients differ.

For a node at level j with children v_a, count of satisfying suffix assignments is

    N(v) = sum_a N(v_a) * product_{j<h<level(v_a)} b_h,
    level(0)=level(1)=r, N(0)=0, N(1)=1.

Multiply by product of skipped levels before the root to count a complete period. The producer recursively visits the root cone; the receiver computes a bottom-up count array. This is exact cardinality over one common period, with arbitrary precision integers. It does not enumerate global time classes. Counts over [D,D+P) equal counts over any P consecutive times in the tail.

A temporal pullback S-delta = {t >= 0 : t+delta in S}, delta >= 0, permutes outgoing arcs at level j by (a+delta) mod b_j and recursively transforms child nodes. Transient entries are translated exactly, including transitions from the finite prefix into the periodic tail. This constructs temporal expressions such as S intersect (S-1) even if neither a new decoder goal nor a raw observation target was supplied. Boolean set algebra and forward-time pullbacks compose.

## Earliest-time and interval navigation

A partial MDD path fixes a CRT class x mod m. The earliest possible coordinate >=t0 within that class is t0+(x-t0) mod m. Best-first traversal expands the smallest bound; a terminal-one path describes an entire satisfying class. A receipt records expanded state indices. The independent checker reconstructs the active cover, independently computes CRT joins by modular inverse, verifies coverage and minimum bound, and evaluates the reported time in the admitted diagram. An empty cover proves unreachability. A transient hit is checked first. A work-budget exhaustion is UNKNOWN, not a negative result.

For interval [lo,hi), count the finite transient prefix, then divide remaining length by P. Each complete period contributes the admitted exact cardinality. Traverse the remaining partial interval by CRT classes: a class whose first coordinate is beyond the interval contributes zero; a terminal-one class contributes its exact arithmetic-progression count. The independent checker uses a breadth-first traversal and floor-quotient differences instead of producer depth-first traversal/first-hit arithmetic. No general polynomial bound on partial-period counting or earliest search is claimed. The finite MDD may also grow exponentially for unsuitable orderings and sources. Budgets cover local cells, diagram producer/checker operations and query states; elapsed time and Python memory are separately measured or unspecified. The archive is local receiver-owned state, not distributed authority or authenticated storage.

## Implementation and use

- `temporal_algebra.py`: `compile_algebra(nav, initial)` creates a diagram and source-bound receipt; `Language` retains roots, finite prefixes and operations. `extend('and'|'or'|'xor'|'not'|'shift',...)`, `count(i)`, `membership(i,t)`, `next(i,start)`, `interval(i,lo,hi)` and `export()`.
- `verify_temporal_algebra.py`: `Admission(receiver,receipt)` rechecks source/initial identity, CRT basis, complete prefix, atom phases, all original live gate relations. It validates gate/operation identities by synchronized DAG traversal rather than importing the producer. `extend(packet)` verifies appended nodes/operation identities with retained relation memoization, refuses modification to admitted prefixes and is idempotent for a repeated cumulative packet. It still scans cumulative node metadata. The caller supplies the intended operation list; the checker qualifies the semantics of that list, not an external user's natural-language intent. `count`, `verify_next`, `verify_interval` operate on admitted roots.
- `test_temporal_algebra.py`: eight new methods, 120 randomized qualified one-/two-bit block laws and five successive new set operations per source; compare every resulting root over the explicit transient and complete period, earliest queries and random interval queries. Includes 1,000-digit shifts, overlapping prime powers, malformed roots/receipts, append-only retention, unreachable roots and budget exhaustion.

```python
# nav and receiver are the actual qualified CIG-021 objects.
d, receipt = compile_algebra(nav, initial)
receiver_algebra = Admission(receiver, receipt)
lang = Language(d, receipt)
shifted = lang.extend('shift', 1, 1)
both = lang.extend('and', 1, shifted)
receiver_algebra.extend(lang.export())
assert lang.count(both) == receiver_algebra.count(both)
r = lang.next(both, 10**1000 + 173)
assert receiver_algebra.verify_next(both, 10**1000 + 173, r)
```
