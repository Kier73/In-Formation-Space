# CIG-017 — Global sufficiency and executable source-proved observation decoders

**Research checkpoint:** 23 November 2026. Predecessors: [CIG-004](CIG-004.md), [CIG-005](CIG-005.md), [CIG-008](CIG-008.md), [CIG-014](CIG-014.md), [CIG-015](CIG-015.md), [CIG-016](CIG-016.md). This experiment implements a bounded exact global sufficiency contract over finite Boolean CNF sources. The checked result is a statement about all satisfying assignments, not an inferred temporal law or physical observation.

## 1. Paired-source theorem

Let `C(x)` be the source, `q(x)` an ordered vector of retained Boolean predicates, and `f(x)` the new requested Boolean predicate. In this implementation each predicate is a canonical nonempty signed-literal clause. A decoder exists on the realized observation image iff

```
E(x,y) = C(x) AND C(y) AND (q(x)=q(y)) AND (f(x)!=f(y))
```

is unsatisfiable. If a decoder exists, every pair with equal observations has equal targets, so no model of E exists. Conversely, if E is unsatisfiable, define `g(u)` by the common f-value of all valid x with q(x)=u. Values outside the realized image are arbitrary. This is vacuously true for an empty model set; the result does not assert that the source has models. A satisfying E has two source-valid assignments witnessing information loss. Insufficient information is not a count of refined states.

The producer creates two disjoint copies of the source plus one fresh Boolean coordinate per q predicate and the target in each copy. For a clause L, the fresh bit z is constrained by `(-z OR L)` and `(z OR -l)` for every l in L, hence uniquely equals its truth. Binary clauses enforce equality for matching observation bits and disequality for the targets. The verifier independently reconstructs this CNF and invokes the actual CIG-008 source checker. A witness of insufficiency is checked directly against the original source, observation equality, and different target values. An exhausted factor/paired-source budget yields UNKNOWN, not an admitted mathematical claim.

## 2. Four decoder routes

`global_sufficiency.synthesize(n, source, q, f, mode='auto', width=12, cells=2000000, decoder_bits=6)` constructs one of these receipts. `verify_global_sufficiency.verify` independently checks it against the caller's actual contract. `mode='paired'` forces the explicit miter as a control. Original source domain <=8192 variables and <=150000 clauses; observer vector <=1024 predicates; predicate width <=63. The explicit pair also must fit the existing CIG-008 domain, including auxiliary coordinates. None of these finite admission bounds imply general SAT efficiency.

1. **Signed union.** Directly use the CIG-014 `covers` function with no exposed raw coordinates. If the target's signed-literal set is exactly the union of selected retained clauses, the decoder is the OR of those observation bits. The receiver checks set equality and input indices independently. This reuses existing translation rather than compiling a gratuitous paired problem.
2. **Affine decoder.** Extract complete parity blocks with the actual CIG-008 `extract` implementation. Reduce equations using hidden-column pivots, tracking XOR combinations of original rows. For each target literal obtain an equality with an affine expression in the observed singleton clauses. Signed observations and target literals are accounted for in the affine constant. The target decoder is an OR of those expressions. Each certificate lists the used parity equations as sparse variable-ID lists, plus explicit source-row indices for each expression. The checker independently re-encodes every parity block, requires all its clauses in the original source, and XORs the listed rows to verify the equality. No enumeration of source assignments or observer codes. Residual nonlinear source constraints may strengthen these identities; they cannot invalidate an equality entailed by a subset of the source. The route is sufficient but not complete for general nonlinear or inconsistent sources.
3. **Nonlinear circuit.** Generalize the local truth-table qualification of CIG-004/006 to ordinary mixed CNFs without a supplied orientation. Enumerate source-supported scopes of 2 or 3 variables; use clauses supported on each scope and its subsets to qualify exact total functions with one output and up to two inputs. Starting from the singleton observation bits, activate gates whose inputs are known and trim the resulting DAG to the requested target. The receiver checks original-clause membership, independently evaluates each small truth table, requires a topological dependency order, and checks that every target variable is determined. This is a static source implication, not a uniquely inferred evolution. The resulting circuit is executable from q and gives a compact nonlinear description even when its fully expanded ANF could be large. It is not claimed to be a minimum circuit.
4. **General paired proof.** Use actual CIG-008 compile/verify over the independently reconstructed paired formula. UNSAT proves global sufficiency. When the supplied observer-bit budget permits (default 6, max 8), construct an explicit decoder by checking `C AND q=u AND f=1` for every bit code u. Its SAT indicator is a valid decoder value (zero on unrealized codes). The producer converts those indicators to ANF using the Boolean Möbius transform; the verifier checks every branch with CIG-008 and evaluates coefficient parity directly. If that additional budgeted construction cannot complete, return a sufficiency proof with `decoder=null`, never a purported executable decoder. This final fallback can require exponentially many code checks; the previous routes avoid this enumeration for the demonstrated structural families.

The receipt binds n, canonical source, ordered observations and requested predicate with the existing canonical JSON SHA-256. A digest binds content, not authority. Timing counters and producer diagnostic work fields are measurements, not independently established proof obligations.

## 3. Existing receiver integration

`GlobalLanguage` subclasses the existing CIG-016 `ProofLanguage` and installs `GlobalReceiver`, a subclass of the existing `Receiver`. Initial counts, per-fiber refinements when necessary, and decision admission reuse their real implementations. `global_extend` creates a receipt bound to the receiver's current language and original source. The receiver verifies that proof and independently evaluates the decoder on its admitted codes. It checks each representative against the original source, old signature and requested value, then relabels the existing positive fibers without changing their exact multiplicities. Insufficiency, missing executable decoder or incomplete proof cannot change the archive. No external unverified histogram is admitted. CIG-014 retained-language queries continue through the existing CIG-016 interface. This is receiver-local trusted Python, not a replacement for E-CPU's authenticated host admission or quorum publication.

### Explicit paired miter and decoder formation

Force the generic paired route on shuffled cyclic sources of 32–512 variables. All seven union/alias-union cases prove sufficiency. A source-dependent 64-variable alias-union case observes three disjunctions over even variables and asks for the disjunction of hidden odd aliases. The direct literal union would not match. The paired proof plus eight checked branch counts constructs ANF masks `[1,2,3,4,5,6,7]`, the OR of three observed bits. The full compile and check take 43.43 and 40.06 ms. At 512 variables the same source-dependent global proof without decoder construction costs 290.68 ms to form and 115.90 ms to verify, using 19214 factor cells. This separates decoder existence from decoder construction. The 4-variable counterexample fixture `q=(x1 OR x2, NOT x3 OR x4), f=x1` returns states 5 and 6 (bitmask encodings, variable 1 is low bit). They agree on q and disagree on f. Four near-threshold random 3-CNF controls with 50, 100, 200 and 500 variables return UNKNOWN at width 8 and 100000 factor cells. No general SAT or P-versus-NP result follows.

## 6. Next mathematical possibility: proof interpolation as decoder synthesis

The general route has established decoder existence through a refutation but may still need to enumerate observation codes to construct an executable decoder. Split the paired problem by sharing only the observer coordinates u:

```
A(x,u) = C(x) AND q(x)=u AND f(x)
B(y,u) = C(y) AND q(y)=u AND NOT f(y)
```

An independently checked Craig interpolant `g(u)` for an UNSAT `A AND B` satisfies `A => g` and `B => NOT g`, so is exactly a sufficient decoder on the realized observation image. Investigate proof-producing resolution/interpolation, reuse existing regional certificates and source-bound proof identities, and compare interpolant circuit complexity and verification cost with the symbolic routes and bounded truth-table construction. For SAT, carry the source-valid separating pair into CIG-016's exact counted refinement rather than promoting a witness to a count. This is a concrete next experiment, not a completed interpolation implementation.
