# CIG-018 — Resolution-derived executable interpolant Grounds

Predecessors: [CIG-014](CIG-014.md), [CIG-016](CIG-016.md), [CIG-017](CIG-017.md). This experiment applies established resolution-based Craig interpolation to the source-qualified observation-language architecture. Reuses CIG-017 canonical observation contracts, CIG-008 source normalizer and witness checker, CIG-016 receiver-owned exact fiber admission and CIG-014 query operations through the actual `ProofLanguage`. VGI proof-obligation separation is a conceptual precedent, not a native kernel integration. No new transport or publication authority is introduced.

## 1. Source contract and theorem

The source is a finite CNF C on n variables, with n <= 8192 and up to 1024 distinct canonical disjunction observations q; f is a new canonical disjunction. Construct A = C(x) AND (q(x)=u) AND f(x), B = C(y) AND (q(y)=u) AND NOT f(y). Copies have disjoint private labels 1..n and n+1..2n, and exactly the shared observation labels 2n+1..2n+k. Each observation equality is encoded by a Tseitin equivalence, not a one-way implication. The paired formula can exceed 8192 variables because the resolution engine has its own occurrence representation. The CIG-017 source contract still bounds original n and source clauses.

If A AND B is satisfiable, the projected witnesses are two valid original states with equal observation codes and opposite f. Otherwise a checked resolution refutation produces a Craig interpolant g over u with A => g and B => NOT g. Thus C => (f = g(q)). This remains correct on an empty source model set (vacuous sufficiency); values outside the realized observation image are arbitrary.

For a proof clause D, let D_a be the disjunction of literals private to A, D_b the disjunction of all remaining literals, and J the partial interpolant. The maintained invariant is:

```
A entails D_a OR J
B entails D_b OR NOT J
```

A-axiom J is its projection to shared literals (empty projection false); B-axiom J is true. When resolving on an A-private pivot, set J = J1 OR J2. The A entailments resolve on that pivot and the B entailments jointly imply the new negated interpolant. Otherwise use J = J1 AND J2, reversing the roles of the two entailments. The empty root yields the two interpolant implications directly. Only shared observation inputs occur in the circuit. This is the standard one-sided resolution interpolation construction, not a new interpolation theorem. The implementation uses binary AND/OR, signed references, constant folding, complement simplification and hash-consing. It does not promise a minimum-size circuit.

## 2. Executable construction and receiver

- `interpolant_ground.partitions`: exact paired source with shared observation IDs; source predicates and signed literals unchanged semantically.
- `synthesize`: bounded Davis-Putnam variable elimination with exact resolution, duplicate removal and tautology filtering. Each retained derived clause names two prior parent nodes and a pivot. Candidate pair attempts, generated resolvents and maximum derived width are bounded. Scope-aware priority is (union of incident variable scopes, positive*negative occurrences, degree, variable ID); pure literals first. Pair-only ordering is an ablation. A heap maintains priorities affected by clause removal/addition. Neither guarantees polynomial resolution size on arbitrary CNFs. No code enumeration. A budget refusal is UNKNOWN. If elimination ends with no contradiction, reverse reconstruction of removed clauses gives a paired SAT witness.
- `verify_interpolant_ground.verify`: independently reconstruct the two colored source partitions; replay every resolution step and exact empty root; independently reconstruct the canonical interpolant gate DAG. Producer-reported search counters are diagnostics, not receiver-verified search effort. The verifier bounds received step count and derived clause width. For INSUFFICIENT, independently verify both original witnesses and opposite target values. UNKNOWN is never admitted. Receipt contract SHA-256 binds source, n, q and f; a changed predicate or source cannot reuse the old receipt as a proof.
- `InterpolantLanguage.interpolate_extend`: existing receiver-owned exact count archive, obtained from the actual CIG-016 seed and count machinery, extends only after verification of the whole global proof and existing representative consistency. Multiplicity and representative are preserved. The counterexample path leaves the admitted archive unchanged. Subsequent queries use the preceding retained-language operations. This is a local trusted Python admission boundary, not an authenticated E-CPU host.

## 3. Measured campaign

Source fixture: k disjoint OR-alias triples (a_i,b_i,z_i), connected by k-1 XOR or alternating AND/XOR gates. Original n=4k-1; observed q_i=(a_i OR b_i), target final gate. Labels and clause order shuffled with seed 73. The compiler receives only ordinary source and observation clauses. No singleton inputs are provided; CIG-017 falls back to the paired route on these cases. Oracle independently evaluates the recurrence over observation codes. All codes at k<=8, 66 selected codes at larger k (zero, all ones, and 64 seeded codes); universal correctness comes from checked refutation and interpolation invariant. No observation codes are enumerated during compilation or receiver proof checking.

### Matched previous compiler

Actual CIG-017 auto compiler, width=10, cells=300000, decoder_bits=6. New route uses default max_pairs=500000, max_steps=200000, max_width=32. Budgets refer to different algorithms, not equal hardware cost. At 15 variables / 4 observed predicates both produce verified decoders: old 21.499 ms (16 decoder obligations), new 1.025 ms (59 resolution steps, 7 gates). At 31,127,511 variables old proves sufficiency but skips decoder construction because k exceeds 6; old total 9.937,85.928,939.543 ms versus new 1.999,10.055,38.485 ms including circuits. The new route is about 24.4x faster at 511 in this matched fixture, **while providing more output**. Not a comparison with optimized CDCL/interpolating SAT tools.

### Proof architecture and negative controls

For the parity fixture at n=127, pair-only ordering tries 203741 candidate pairs and retains 3019 proof nodes; scope-aware ordering tries 1810 and retains 753. Pair-only reaches UNKNOWN at n=511 and n=4095 under 500000 candidate pairs. Scope-aware completes both. This is a concrete application of CIG-011's insight that choosing an architecture can dominate realization cost. A minimum immediate local pair count is not a minimum future proof cost.

Removing all clauses mentioning the final output produces independently checked INSUFFICIENT witnesses at n=127,511,4095. Dense seeded random 3-SAT at 50,100,200,500 variables remains UNKNOWN with 20000 candidate pairs, 10000 generated nodes, derived width 16. General SAT and unrestricted interpolation size remain open research frontiers.

## 5. Next mathematical possibility

Explore incremental multi-output interpolation and proof/circuit architecture optimization. Source-only clauses can be reused when their exact premises and color contract remain valid; goal-dependent conclusions require their assumptions to be preserved or requalified. Independently verify both proof and executable circuit transformations, charge archive construction and communication, and compare against cold proof construction.
