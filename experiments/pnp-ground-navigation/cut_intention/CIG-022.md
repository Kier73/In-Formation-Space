# CIG-022 — Intention as a temporal destination

Predecessor: [CIG-021](CIG-021.md), [CIG-019](CIG-019.md), [CIG-018](CIG-018.md). The mathematical mechanism here composes the actual CIG-019 proof-derived decoder, the CIG-021 source-qualified nonlinear block-transport functional graph and universal observation section, and CIG-021 generalized CRT. No static source is assumed to determine its own temporal law. No host authority or physical clock is inferred from a logical time coordinate.

## 1. Exact statement

For an independently admitted decoder G, transport T, initial observation u0, lower bound t0 and output constraints y (0, 1, or unconstrained), compute

`t* = min { t >= t0 : G(T^t(u0)) agrees with y on every specified output }`.

A CIG-021 `Receiver` must have independently admitted the original decoder proof, transition CNF and constructive total-image section. The latter proves every intermediate observation code has an original-source realization. A terminal witness alone does not qualify the entire orbit, so this verifier explicitly requires the universal section. The receiver's objects are trusted local admitted state; there is no network admission or authentication here.

Each moving symbol has an independently qualified transient depth and cycle. Let D be the maximum transient depth over the initial symbols. Evaluate finite transient times t0 through D-1 in order (if any). After D the state within each spatial permutation cycle j is periodic with a period L_j equal to the LCM of the lifted cycles reached by its symbols. These periods need not be minimal. The full state is periodic with their LCM, potentially vastly larger than any L_j.

## 2. Source-proved circuit factorization

The CIG-019 circuit uses signed references, a true constant and binary AND/OR gates. Normalize desired output values to a conjunction of signed references that must be true. A positive AND or negated OR splits into two required signed children. A disjunctive requirement is not split into independent conjuncts. Remove true constants, retain false constants. Every remaining required reference r has an exact syntactic backward cone; map its input bits to spatial cycle owners. The cone's value after D is periodic with period L_r = lcm of the periods of those owners (1 for a constant).

Enumerate that local period, evaluate only the cone, and record the absolute-time residues S_r for which the requirement is true. If several requirements have exactly the same spatial-cycle support, the default grouped compiler evaluates their conjunction on the union of their circuit cones, once per local time. A separate `grouped=False` mode retains individual factors for a matched comparator. No phase support or gate AST is supplied by the fixture to the temporal solver.

The original output intention now holds iff all temporal factors hold:

`t mod L_r in S_r` for every r.

Join these finite residue sets via generalized CRT. A pair (a mod M, b mod L) is compatible iff a=b mod gcd(M,L); its joint class has modulus lcm(M,L). Universal factors are skipped. Select restrictive factors first. Empty feasible classes prove the periodic target unreachable. Otherwise for each class a mod M the least member >= max(t0,D) is `lo + (a-lo) mod M`; their minimum is the exact earliest periodic solution. If no earlier transient matches, this is the exact earliest solution. The original CIG-021 receiver verifies the terminal code and all outputs at that coordinate.

The producer advances local symbols within their own groups. The independent verifier instead computes each local state from the certified graph positions and reconstructs mandatory requirements using reverse topological traversal. It checks the full factor coverage, residue sets, CRT composition, time minimum, original-source terminal receipt and exact source/initial/intention binding. It reconstructs the expected receipt, not just a candidate time. The proof does not trust the producer's cost statistics. `UNKNOWN` receipts are not admitted as mathematical conclusions.

## 3. Interfaces and budgets

```python
from output_time import seek_outputs
from verify_output_time import verify_output_seek
# nav: CIG-021 Navigator, receiver: separately admitted CIG-021 Receiver
# targets: list of 0, 1 or None, aligned to the full decoder output list
receipt = seek_outputs(nav, initial, targets, start,
                       max_cells=2_000_000, max_pairs=200_000)
assert verify_output_seek(receiver, targets, start, receipt)
```

`FOUND` includes the earliest time and terminal receipt; `UNREACHABLE` proves both finite transient exclusion and empty periodic intersection. `UNKNOWN` denotes exhausted local-period or CRT budget, or result time outside the 4096-bit contract. The verifier accepts only complete mathematical results, and requires the same externally declared mode and budgets. The local-cell estimate charges one term per block transition, input read, cone gate and requested root per local period; finite transient scans charge one unit per block and gate plus one. This is a conservative declared work estimate, not an instruction count or measured wall time. The CRT count charges every candidate pair including incompatible ones. The compiler may refuse before evaluating a factor whose estimated work exceeds the budget; the recorded estimate can exceed actual performed work. Factor formation and graph analysis, large-integer arithmetic and receipt serialization have separate wall costs. Neither local-period expansion nor residue-set joins are guaranteed efficient for unrestricted circuits.

## 4. Heavy campaign (final local run)

`run_output_time.py` uses the real CIG-019 shared interpolant compiler on shuffled original CNF sources, with each observed coordinate an OR predicate over disjoint raw variables. A separate CIG-021 transition CNF describes independent moving three-bit symbols, with one marker in each spatial cycle. Each output intention couples two spatial cycles: the markers must occupy one of two selected phases and their phase choices must agree. Eight requested true outputs at the largest scale admit 128 distinct global time classes. The extra output requires two markers in one cycle, so demanding it true is impossible. The target supplied to the solver is just the output list, not the marker pattern, phase choices or desired time.

At 3110 variables the original decoder source has 3233 clauses and a 54-gate verified circuit. Eight coupled factors, each over two spatial cycles, have maximum period 1517. The lower time bound is `10**1000+173`. The earliest feasible time is `start + 5418922329477735` (i.e. `10**1000+5418922329477908`). A separate fixture-specific Bezout CRT oracle determines the same minimum from the two phase choices per pair without reading the proof circuit or factor tables. A separate binary-composition transition oracle checks the terminal observation and the fixture's direct Boolean AST checks every output. The compiler finds the contradictory output unreachable. Its successful receipt is 7609 serialized bytes.

Without grouping same-support factors, the identical circuit requires 300017 estimated local cells, 80574 CRT pairs and 128 final feasible classes. Grouping requires 281329 cells and 270 pairs (298.42x fewer pair candidates); both modes produce the exact same time and residue classes. Warm grouped seek/check is 28.091/165.175 ms versus 42.375/206.560 ms ungrouped. Smaller 384-bit trial shows the reduction in pairs need not reduce wall latency: grouped producer is 8.311 ms versus 6.367 ms ungrouped. Initial largest-source decoder formation 278.629 ms, section formation 66.933 ms, independent receiver admission 216.167 ms, fixture creation (including transport construction) 140.083 ms. All are reported separately; the warm comparison starts from qualified objects. No claim of a measured comparison against direct traversal of the enormous orbit.

A held-out broad control constructs a single parity output over seven distinct cycles on a 528-variable source with 174 observed bits. It is source-proved and has a known feasible time at offset 255255, independently checked, but its unsplit local factor would cost 50540490 cells. With max_cells=2000000 it returns UNKNOWN, not UNREACHABLE. This exposes the next research opportunity: compile disjunctive requirements as proof obligations and branch over modular constraint alternatives or symbolic residue factors rather than expanding the entire joint period.


The construction extends the earlier source-proved temporal navigator to outputs whose constraints couple multiple cycles; it does not extend the admitted transport family itself. Future work: disjunctive temporal proof search, costed alternative factorization, incremental source-qualified temporal-factor memory, and more general transition dynamics beyond block transport.
