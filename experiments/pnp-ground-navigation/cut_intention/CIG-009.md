# CIG-009 — Source-local structural memory for composed mathematical Grounds

## Result

A connected CNF can be compiled into a balanced tree of exact integer conditional-count functions, with independently verified region messages retained by the receiver. A source change inside one region changes only that leaf and the ancestor dependency path, provided the frozen layout still covers the revised source. This is a mathematical reuse result; the implementation audits the entire current source, walks the tree, and reconstructs a witness on each SAT revision. It does not claim logarithmic end-to-end execution.

## Mechanism

`discover` constructs the primal graph from actual canonical clauses, discovers its biconnected blocks using an iterative Tarjan edge stack, and packs adjacent blocks under a bounded region width (default 8, maximum 10). A region tree is balanced over that discovered order. `bind` assigns each normalized clause once to a leaf owning all of its variables, retains isolated coordinates, and constructs each separator as the intersection of subtree scope with outside scope. The independent `audit_layout` reconstructs clause coverage and checks separators using a top-down recurrence independent of the producer's occurrence counters. Layout changes beyond the admitted scopes are refused; the caller must replan. A dense block exceeding the width budget is also refused.

For region R with boundary B, the message M_R(s) counts assignments to its private variables satisfying its local source with B=s. If R has children L and H, let U=B_L union B_H. Since child-private variables are disjoint and each shared coordinate is included in both child boundaries,

    M_R(s) = sum_{u in {0,1}^U, u|B=s} M_L(u|B_L) M_H(u|B_H).

At the root the boundary is empty; its only table entry is the source count. Induction on the tree proves the result. Affine leaves reuse CIG-008's exact parity extraction and hidden-column projection. Nonlinear leaves use bounded Boolean truth evaluation. Integer message joins are exact; the independent verifier enumerates leaf assignments using a distinct tuple-based oracle and evaluates joins by a relational join on common variables. A positive root count permits witness reconstruction by selecting compatible positive child entries and satisfying leaf assignments; the resulting full witness is checked against the current canonical source.

Each message has a versioned descriptor, canonical SHA-256 key, sorted boundary IDs, and a table of decimal integer counts. Leaf descriptors bind the precise local canonical clauses and region scope; internal descriptors bind the identities of both verified child messages. Receiver-owned `VerifiedMemory` retains canonical bytes only after checking the message against the expected descriptor and independently admitted children. Returning a mutable message cannot mutate the cached bytes. The cache is trusted in-process memory, not a self-authenticating persistent store. A hash alone is not proof, authorization, physical evidence or publication authority.

An unchanged descriptor and child-message identity imply an unchanged local conditional-count function, regardless of the revision's global source hash. A one-leaf edit in a balanced L-leaf layout can therefore require at most 1+ceil(log2 L) newly checked messages; source binding, layout auditing, tree traversal, serialization and witness output remain separate costs. At present all leaves have bounded width, joins have maximum 12 distinct boundary bits, and the region plan is frozen. General dense problems may refuse. There is no general polynomial-time #SAT or P versus NP claim.

## Separate receiver process

`run_regional_memory.py --worker` consumes JSON packets over standard input and holds its own independent receiver memory. At 1793 variables it checks 511 initial messages, then nine new messages and reuses 502. It rejects a forged count in a later contradictory revision and accepts the corrected packet with count zero. Initial total request: 161552 bytes; revised request: 65836 bytes, because the full revised source and layout are still supplied. Message-only delta: 1697 bytes. This is a real separate OS process over a local pipe, not an authenticated E-CPU transport, quorum, distributed host deployment, or durable restart test.

## Cross-repository connection

GRC-001 (IFS `spectral_phase_navigation/GRC-001_SOURCE_REFINEMENT_CONTINUITY.md`) demonstrates source-bound continuity under strengthening by exact lost-model receipts. Here, regional reuse covers both strengthening and weakening that fit the layout, with no reliance on an old global count. IPS-006 (E-CPU `docs/DISTRIBUTED_GENERATED_GROUND_IPS006.md`) already has authenticated peers, durable lineage, rehome and fenced publication; retain that implementation for authority and recovery. VGI's `PROOFGROUND_NAVIGATION.md` supplies typed exact observations and AND/OR proof dependencies. These mechanisms were inspected, not executed in this run. The next seam is a native adapter carrying independently admitted regional messages as pure DAG predecessor receipts, with a receiver-local source/plan commitment and E-CPU's existing publication authority. A persistent archive must be replayed or qualified by the receiver's trusted checkpoint, not trusted merely because its digest matches.
