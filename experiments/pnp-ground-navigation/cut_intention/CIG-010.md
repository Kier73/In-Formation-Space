# CIG-010 — Adaptive structural continuity and semantic quiescence

## Result

CIG-009 preserves source-identical regional messages in a frozen binary tree. CIG-010 changes that tree and separates a derivation's source identity from the exact mathematical function it exposes. The receiver still independently audits full source coverage, current boundaries and every new local computation. This experiment admits exact #SAT counts (nonnegative integer semiring), not arbitrary model semantics or authenticated publication rights.

The local campaign passed 157 combined CIG-001–010 tests (15 new tests, including 500 small evolving CNFs checked by exhaustive enumeration). The heavy campaign covers topology changes through 7,169 variables, 96 successive signed cross-region edits at 897 variables, 1,024 region splits and merges at 4,096 variables, and semantic quiescence at 4,099 variables with exactly 2^2050 models.

## Mathematical contract

A region R has an exact boundary S_R consisting of coordinates appearing both inside and outside its subtree. Its message is the table M_R(s) = sum_h [F_R(s,h)] over private coordinates h. Each normalized source clause belongs to exactly one leaf, all source coordinates (including free variables) are covered, and all shared coordinates appear in both relevant child boundaries. At a parent with children A,B, let U=S_A union S_B. Then M_R(s) is the sum over assignments u to U extending s of M_A(u restricted to S_A) times M_B(u restricted to S_B). Induction on the tree gives the exact root count, including free-variable multiplicities. The root boundary is empty. Positive counts enable a full source-checked witness, reconstructed afresh even on reuse.

CIG-010 uses two distinct identities:

- Derivation: version, boundary, leaf scope and canonical clauses, or the identities of both current child messages. The SHA-256 of this descriptor is the proof key. Every change of source or child proof changes the corresponding derivation key.
- Exact operation: output boundary and the unordered pair of complete child functions (boundary plus exact count table). An independently admitted join can be reused for new derivations with identical exact input functions. The cache compares canonical bytes of this operation, not a sender's claim of equality. No collision-resistance assumption is needed for the semantic operation key itself.

**Semantic quiescence lemma.** If two independently source-verified region messages have identical boundary and exact count table, every parent sum-product join that receives either table and the same other inputs has the same output table. By induction this remains true along every unchanged surrounding operation. The new derivation is still bound to the new source and current verified child messages. This proves preservation of this particular observation contract; it does not establish equivalence of all models, all witnesses, or all future intentions. In particular, equal *total counts* alone do not imply equal conditional tables.

**Projection lemma.** For the same local source and scope, a verified finer boundary T determines any coarser boundary S subset T by summing all entries over T\\S. The receiver independently checks the projection using tuple-based enumeration; the producer's bit-index projection is separate. New exposed coordinates cannot in general be recovered from a coarser count table. Such a refinement requires fresh computation unless an already verified finer table exists.

## Implementation

`adaptive_ground.initial` invokes actual CIG-009 biconnected decomposition and source binding. `revise` retains the tree, removes absent clauses, prunes empty redundant regions only when every variable remains covered, attaches added crossing clauses as new factor leaves at a smallest covering subtree, splits disconnected local clause graphs, and optionally merges sibling leaves under the local width budget. New clauses within an existing leaf remain there. The plan is a deterministic heuristic, not an optimal decomposition. The split/merge workload supplies its initial packed plan explicitly; the connected topology workload starts with a source-discovered plan. A fixed declared domain is required.

`annotate` derives boundaries using occurrence counts. `verify_adaptive_ground.audit` independently reconstructs source clause coverage and top-down outside scopes; it checks every boundary and join scope. `Memory.obtain` requires receiver-admitted child bytes, reuses an exact prior proof if available, otherwise attempts coarser projection or exact operation reuse; on a miss invokes the actual CIG-009 affine/Boolean producer and separate truth-table/relational-join checker. `realize` constructs current derivation identities, returns exact counts and reconstructs the complete source witness. All memory resides in a trusted receiver process; there is no API to import untrusted persistent cache contents as verified. No migration, E-CPU transport or durable restart is claimed by this experiment. The proof and semantic keys are candidates for a future typed receipt adapter, not publication authority.

The declared local width cap is 10, maximum join scope 12; initial discovery defaults to width 8. Dense block discovery and over-width interfaces refuse rather than infer UNSAT. The tree verifier caps depth at 128 and nodes at 32,767. The implementation assumes trusted local tree construction before annotation. Full-source normalization, plan audit, traversal, identity construction, storage, and witness output remain charged. Memory is not yet garbage-collected. Worst-case source edits may force global replanning and exponential local width; no general SAT/#SAT complexity theorem is claimed.

## Heavy measured campaign

Measured with the local Python standard-library implementation. Revision times include independent checking and full witness construction, with replanning measured separately and charged in the combined column. Fresh comparisons use the same already-revised plan (no planning charged). The independent source construction uses CIG-008's shuffled monotone AND/XOR chain; the threshold oracle enumerates only the known fixture's monotone sequences and does not participate in the tested compiler. The first three revised sizes also agree with the actual CIG-008 global affine/factor compiler and its independent verifier. All five original frozen CIG-009 plans refuse the new cross-region clause. At 7,169 variables the full fresh pass uses 270,504 producer cells; the revised pass uses 600 (450.84x fewer). End-to-end reduction is about 3.14x, because the whole source still must be bound, checked and traversed. This distinction is central. These local timings are single measured runs and do not compare with optimized CDCL.

**96-revision stress test.** A connected 897-variable base source receives repeated additions/removals of signed cross-region clauses. All revisions agree with fresh compilation (identical root proof keys) and the separate threshold oracle. 95 positive counts, one UNSAT; 48 bridge leaves inserted, 47 removed; 24,038 proof reuses, 20 semantic join reuses, 614 full new checks. Maximum new full checks for any one revision: 15. Total fresh same-layout realization time 13,517.398 ms; total adaptive realization plus replanning 3,263.817 ms (4.14x). Initial source formation and initial admitted memory are excluded from both repeated-revision totals.

**Semantic quiescence control.** One AND region and 2,048 connected XOR regions, 4,099 variables, 8,195 initial clauses. Original count 2^2050. Add a redundant clause to the AND region. All 4,097 regional derivations remain exact, but 13 identities change: one leaf and 12 ancestors. 4,084 exact proof reuses, one new Boolean check (8 producer cells), 12 semantic join reuses. Fresh compilation performs 24,492 producer cells and 4,097 full checks; fresh 499.971 ms versus revised 231.520 ms plus 34.148 ms replan. The one new leaf check is not a claim of constant total revision cost.

**Structural split/merge control.** 4,096 variables, 2,048 positive binary constraints, initially packed as 1,024 four-variable regions. Source count 3^2048. Discover 1,024 local splits, yielding 2,048 leaves and 4,095 total messages. Exact count is retained. On remerging siblings under width 4, restore all 1,024 regions and all 2,047 original proof identities without new full mathematical checks. This workload is disconnected by construction; it tests reorganization and operation reuse, not difficult connected SAT. Identical scalar subtree counts permit semantic join reuse even on cold realization.

**Negative controls.** Seeded near-threshold random 3-SAT at 50, 100, 200 and 500 variables all return UNKNOWN at the initial biconnected-block width admission. Adversarial tests reject missing/duplicate clauses, omitted coordinates, incorrect separators, invalid projections, mutated cached-result copies, and over-width clauses. A changed parity region becomes a Boolean leaf, with independently verified changed count; reordering child operands is admitted through exact commutative operation reuse.

## Reproduction and next work

Package includes the required CIG-008/009 modules; repository installation uses the actual corresponding files. From this directory:

```
python -m unittest -v test_adaptive_ground
python run_adaptive_ground.py > CIG-010-results.reproduced.json
```

The full regression log is supplied separately. CIG-009's `VerifiedMemory` and independent verifier are directly reused as mathematical building blocks, not replaced by a mock. Prior GRC-001 source-refinement and E-CPU IPS-006 recovery/fencing designs remain relevant. Next: certified source deltas, persistent receiver checkpoint with replayable semantic-operation evidence, adaptive selection among competing decompositions, symbolic boundary compression for high-width regions, and native authenticated E-CPU receipt transport. The largest current improvement is in arithmetic work, not total data-path cost. A key question is whether semantic quiescence can be detected by a proof cheaper than recomputing an entire interface table.
