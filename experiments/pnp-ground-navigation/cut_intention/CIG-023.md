# CIG-023 — Disjunctive temporal proof navigation

Research continuation of [CIG-022](CIG-022.md), CIG-021 transport, CIG-019 shared proof circuits and CIG-018 interpolants. The implementation uses the existing independently admitted CIG-021 Navigator/Receiver contract and requires the universal observation section. Related mathematical lineage: VGI AND/OR proof obligations; CIG-011 costed architecture selection; CIG-020 semantic reuse. The temporal law is declared independently from the static decoder source.

## Mathematical construction

For a qualified initial code u0, let z(t)=T^t(u0), I(t)=the conjunction of signed output roots of G(z(t)). Find the least t >= start with I(t)=true. CIG-022 evaluates factors over the joint periods of their input cones. CIG-023 instead prepares local signed-bit tables on the spatial cycles that appear in the live output cones. A local table is represented by (L,S), meaning t mod L belongs to S. The finite transient is explicitly checked. Beyond its end D, the lcm P of the relevant local periods is a period of I (not necessarily its minimal period). One interval of length P after max(start,D) is complete for feasibility. No table of length P is formed.

For each signed primitive predicate v, the exact next time >= t is min(t+(r-t) mod L for r in S), or infinity. For gates, compute sound lower bounds using max at AND and min at OR; negative gates are dualized. A conjunction of signed output roots uses max. Induction establishes that the interval [t,bound) contains no solution; equality at t implies current truth, and the independent terminal receiver still checks that truth. A bound >= horizon or infinity proves periodic unreachability. These bounds need not equal the next actual joint satisfying time.

After the declared interval-step allowance, perform a best-first cover search. State (r,M,pending) denotes a congruence class t mod M=r intersected with a conjunction of pending signed gates, on the remaining finite interval. A conjunctive gate is replaced by both children; a disjunctive gate branches into two alternatives (overlap is harmless); a signed input is replaced by its exact union of compatible CRT intersections. Contradictory pending literals, empty classes and exact duplicate states can be discarded. The queue key is the earliest possible coordinate in the class, ignoring pending gates; the producer tests the live cone at that coordinate and expands a false root. The receiver checks the submitted expansion cover independently, not the heuristic or queue order. Every expanded region is replaced by an exactly covering union; each remaining region has a certified lower time >= returned time. The terminal CIG-021 receipt proves attainment. An empty cover proves no periodic solution. Unfinished budgeted searches are UNKNOWN, never unreachable.

The checker reconstructs spatial cycles using the forward permutation, local residues via independently admitted graph positions, bounds via direct modular minimization, and CRT via gcd reduction. The producer uses local transition tables, bisect over sorted residues and the existing inverse_time.merge. Proof traces record state IDs and expanded signed roots; interval advances are relative decimal offsets, avoiding duplication of the large absolute time. Exact receipt equality and the original terminal receiver bind source, initial code, requested outputs, time and evidence. A forged trace cannot omit a potentially earlier alternative. The interface accepts only complete results. It is an in-process receiver, not a new distributed authorization protocol.

## Executable API

```python
from disjunctive_time import seek
from verify_disjunctive_time import verify
receipt = seek(nav, initial, targets, start, interval_steps=16,
               max_cells=2_000_000, max_pairs=200_000, max_nodes=50_000)
assert verify(receiver, targets, start, receipt, interval_steps=16)
```

`interval_steps=0` forces the alternative-cover route. Limits are caller-declared and must match the checker. Local-cell work charges local-period preparation (one unit per block and relevant input bit per phase) plus finite transient scans. Pair count charges all candidate CRT pairs. Nodes count interval bound computations and popped search states; generated distinct states also fit the node budget. Point evaluation telemetry separately counts distinct candidate times, live gate evaluations and input reads; it is not an admitted receipt claim. Actual integer, heap, bound, serialization, checker, and source-admission costs are measured separately. CIG-022's local-cell estimate includes full cone gates per joint factor period and is not identical to CIG-023's preparation-cell accounting. Arbitrary broad goals can still exhaust the search, local-period or pair budgets.

## Measured campaign

Actual shuffled CNFs and CIG-019 proof-derived circuits, independently admitted source sections, 3-bit block-transport sources. The old CIG-022 solver is executed on each identical target with its default 2 million-cell budget. Four target cases: wide parity chosen opposite to its value at start; either of two complete marker-pattern conjunctions (rare OR); rare OR plus a broad parity constraint; impossible OR (both alternatives require two markers on one cycle). The independent oracle advances the parity source from a separately binary-composed initial state, derives the two rare marker times from the known fixture phases, and checks terminal codes and Boolean AST values. Neither the phase targets nor oracle result are supplied to the solver. All cases agree with the independent receiver in both modes. ### Optimization from use

Initial implementation reconstructed the entire observation and evaluated all gates at each popped search state. Final implementation computes only live inputs from their already prepared periodic tables, only live gates, and caches the point value for repeated queue lower times. For largest combined branch-only goal, 195 popped states share 29 evaluated times: 928 input reads, 6496 live gate evaluations, compared with 195 full 1023-bit observations and 45435 full gate evaluations in the initial branch-only strategy. Producer time decreased from 86.186 to 5.694 ms (single local measurements, not controlled statistical timing). The relative interval receipt reduces largest hybrid rare-OR serialized bytes from 21118 to 5127. Receipt proofs remain unchanged in substance. The initial measurement ledger records the preceding implementation; final checker expects the relative-offset receipt.
