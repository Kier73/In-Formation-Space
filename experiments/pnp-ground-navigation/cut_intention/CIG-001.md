# CIG-001 — Intention-equivalent Grounds: geometry, exact rank, SAT and model count

**Experiment:** 23 November 2026 · **Host:** local Python 3 standard library · **Status:** executable, source-replayed finite experiment. **Scope:** one syntactically detected, complete-graph equality-CNF family; the same original CNF is used for all intentions. **Research lineage:** PNG-001/002, SFI-001–004, SPN-004/007/008, OFG-001–003, E-CPU INTENT-001, NCR-006/007, VGI ProofGround.

## 1. Question and result

Can the **same source** have an exponentially high exact tensor-flattening rank and yet admit compact, efficiently verified descriptions of a SAT witness and exact model count? Yes, for the structural family below. The compiler **reads the original clauses**, constructs the appropriate observer Ground from the declared intention, and the separate verifier re-derives the source's structure independently. Every symbolic statement is qualified by an exact source-level proof, not by an unverified synthetic annotation.

This is a concrete counterexample to conflating the cost of *retaining an entire cut relation* with the cost of *answering a selected observer intention*. It is not a P-versus-NP resolution or a universal fast SAT compiler.

## 2. One source; three intentions

Let `k≥2` and `ℓ≥1`. Construct one source CNF `F(k,ℓ)` from a complete graph on `k` nodes. For each graph edge `e={a,b}` and each label bit `j∈{1,…,ℓ}`, introduce **two independent source variables** `x_(e,j,a)` and `x_(e,j,b)`, observed by their respective endpoint nodes. The source contains the two ordinary CNF clauses

```
(¬x_(e,j,a) ∨ x_(e,j,b)) ∧ (x_(e,j,a) ∨ ¬x_(e,j,b)).
```

This is exactly the equivalence of two endpoint copies. There are

`m = k(k−1)/2` edges; `n = 2ℓm = ℓk(k−1)` original Boolean variables; `2ℓm = n` binary clauses.

A receiver supplies the **node-observation partition**, which is part of the requested observation contract; it does not supply equation truth, edge labels, or an SAT answer. The compiler reads every original clause and admits the specialized language only after proving all of the following:

- Every clause is one of two opposite implications of a variable equality, with no extras, omissions, or duplicates.
- Every source variable occurs in exactly one equality pair, and each equality connects two distinct observer nodes.
- Every pair of nodes is connected by exactly the same positive number `ℓ` of such disjoint equality pairs. The value `ℓ` is *inferred* from the source, not read from a privileged label annotation.

All three interpretations are then determined by one admitted source:

| Intention | Exact Ground conclusion | Construction/verification justification |
| --- | --- | --- |
| `SAT` | Explicit zero assignment, verified against the original CNF | Every admitted clause is an equality of two bits; all-zero assignment satisfies each |
| `#SAT` | `2^(ℓm)` models | Every equality pair has exactly one free Boolean bit; pairs have disjoint variable supports |
| `CUT_RANK` on node cut `S` | `rank_GF(2)(M_S)=2^(ℓ\|S\|(k−\|S\|))` | Each crossing edge-bit is an independent two-sided equality; internal variables can be fixed, producing an identity submatrix of that size; rows/columns are constant on equal crossing-label configurations, giving matching upper bound |

For the rank, `M_S` is the full `0/1` source-satisfaction coefficient tensor flattened across all original variables observed by nodes in `S` versus its complement. This is the exact relation, not a matrix approximated by floating-point SVD. It has `2^n` entries if explicitly materialized. **Only its certified symbolic rank and proof are constructed** in the large cases.

## 3. The geometric/algebraic identity from the supplied experiments

The original geometric hub construction attaches endpoint positions `+e_a/2` and `−e_a/2` for each graph edge `(a,b)` with `a<b`. For a nontrivial node partition `S`, the hub vector obeys

`2v_S[a] = #{b>a | b∉S}` if `a∈S`; otherwise `−#{b>a | b∈S}`.

No terms cancel within a coordinate, hence

`2‖v_S‖₁ = |S|(k−|S|) = c(S)`, and `log₂ rank(M_S) = ℓ c(S)`.

Therefore the identities connect **the exact same graph cut**:

`log₂ rank(M_S) = 2ℓ ‖v_S‖₁`.

Cauchy–Schwarz gives `‖v_S‖₂ ≥ c(S)/(2√k)`. For balanced cuts `k/3≤|S|≤2k/3`, `‖v_S‖₂≥k^(3/2)/9`. The hub norm itself is recorded as an exact rational square with denominator four. There is also a verified `O(k²)`-state backward dynamic program for the minimum `4‖v_S‖₂²` across balanced subsets, rather than `2^k` enumeration.

**What it does and does not lower-bound:** `rank(M_S)` constrains matrix factorization width over GF(2) and exact cut-label distinguishability under the specified observation contract. It does **not** force an unstructured circuit, SAT decision procedure, or symbolic rank formula to materialize `2^(ℓc(S))` words. Rank is invariant under ordinary row/column basis changes, but the *meaning and charge* of the requested observation contract still matter.

## 4. Algebraic guardrail: Experiment D and C

Experiment D shows why intentional representation changes require semantic proof. In the free polynomial ring, multiplying `x₀x₂x₄` by itself yields `x₀²x₂²x₄²`, which has zero block-linear projection under three selected blocks. In the Boolean **idempotent ring** with `x²=x`, the same product becomes `x₀x₂x₄`, and the complementary-block decomposition misses this overlapping contribution. The test suite retains this minimal counterexample. A compiled algebraic Ground may use the free-ring block projection only when its multiplication hypotheses are met, such as disjoint variable supports.

Experiment C's Boolean **OR/AND semiring** does admit `V=1+V` (with `+` interpreted as `OR`); the Boolean **XOR/AND ring** does not. These are distinct interpretations. An existential observer can intentionally discard multiplicity under OR, while an exact counting observer cannot. CIG-001 therefore represents counts as integers and never treats OR-absorption as a counting proof.

## 5. Source-bound receipts and attacks

`compile_ground(source,intention,cut)` produces a JSON-compatible certificate including the digest of the **entire original** source, the source-derived explicit equality pairs, exact node/edge dimensions, chosen intention and cut, exact answer, and (for `CUT_RANK`) integer hub coefficients and flattening dimensions.

`verify_cut_intention.verify(source,cert)` uses a **separately written reconstruction** of the source-CNF equality graph and recomputes every certificate claim, including the original SAT witness. It does not accept the producer's extracted edges, its rank exponent, or its digest as authoritative. This is an independent source-level verifier, not a kernel-checked mathematical proof. The receiver must bind the source document to the caller's intention and reject replaced source bytes.

Eight test groups cover small original-CNF brute-force counting, all nontrivial cuts at `k=4` with **literal GF(2) Gaussian elimination of the full flattening matrix**, larger exact symbolic cases, modified/missing/extra source clauses, forged certificates, invalid cuts, exact hub DP versus exhaustive subset enumeration, and the ring/semiring counterexample.

## 6. Local measured experiment

Run from this directory:

```sh
python -m unittest discover -s . -p 'test_*.py' -v
python run_cut_intention.py > CIG-001-results.json
```

The included run uses **11 local trials for each intention**, paying for a fresh source scan and Ground construction and for an independent original-source verifier replay; no shared cached Ground and no external host are invoked. Times below are **median end-to-end construction plus verification**, not inference hardware speed or generic SAT performance. Re-run before comparing machines. The `SAT` and `#SAT` answers, and the rank formula, are computed during construction; no separate costly navigation stage is represented.

| `k` | `ℓ` | Original vars | `log₂(#SAT)` | `log₂(rank)` | Explicit matrix entries | SAT ms | #SAT ms | CUT_RANK ms |
| ---: | ---: | ---: | ---: | ---: | --- | ---: | ---: | ---: |
| 3 | 1 | 6 | 3 | 2 | `2^6` | 0.0565 | 0.0452 | 0.0663 |
| 4 | 1 | 12 | 6 | 4 | `2^12` | 0.0754 | 0.0647 | 0.0765 |
| 6 | 1 | 30 | 15 | 9 | `2^30` | 0.1576 | 0.1339 | 0.1586 |
| 12 | 1 | 132 | 66 | 36 | `2^132` | 0.5693 | 0.4852 | 0.5105 |
| 24 | 2 | 1104 | 552 | 288 | `2^1104` | 4.6725 | 3.9544 | 4.0677 |

Small independent oracles: for `k=4,ℓ=1`, direct `2^12` original-assignment enumeration took **7.9644 ms** median, and actual `64×64` CNF-evaluated GF(2) flattening rank took **9.2336 ms** median. The mathematical Ground's high rank is exact even when the full matrix cannot feasibly be built. These small wall-clock differences are an experimental observation, **not** an asymptotic general-SAT speedup.

The full result ledger also includes individual construction and replay times and certificate byte sizes. Example: `k=24,ℓ=2` has exact `2^552` satisfying assignments and cut rank `2^288`, certified by ~6 KiB of source-specific proof metadata. The original source has **1104 Boolean variables and 1104 CNF clauses** and is re-scanned every trial. The compact rank certificate does not represent a low-rank factorization and does not invalidate that flattening's exponential linear-algebraic dimension.

## 7. Interpretation and next implementation step

This gives three verifiable, intention-dependent descriptions of **one unchanged formula**. The research progression is:

`Original CNF + observer partition + intention → structural Ground qualification → exact small certificate → original-source replay → receiver-admitted result`.

The next challenge is to move beyond syntactically disjoint equality copies. Useful candidates:

1. **Source-preserving separator compositions:** one original clause couples two otherwise independent bit-pair components. Reuse OFG-003 separator discovery and SFI-002 heterogeneous construction; derive and audit exact intention-specific Grounds on the modified source. If a synthesis stage fails, return `UNKNOWN`, not an assumed equivalent count.
2. **Rank beyond equalities:** add guarded local Boolean gates, affine parity constraints or spectral interactions. Construct independently checkable rank/cut certificates or an explicit finite refusal where the old `2^(ℓc(S))` formula fails.
3. **Measure uniform total costs:** compare construction, verification, navigation, source bytes, certificate bits and the cost of finding the representation itself against existing PNG/SFI/SPN algorithms and an external SAT baseline. Hold out unfamiliar structured and random CNFs.
4. **Integrate observer-conditioned Ground selection:** use OFG-003's intention/offer policy and VGI's proof/observation attention, then transport an admitted result through VL-I PFI and E-CPU's receiver-authorized execution path. Keep semantic source equivalence separate from network authority.
5. **Formal proof:** translate the exact equality-cut rank theorem into Lean (lower bound by an identity submatrix, upper bound by crossing labels), then consider how proof obligations change when the underlying semiring or operation semantics change.
