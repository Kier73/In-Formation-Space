# CIG-003 — Source-discovered nonlinear observer Grounds and conditional cut-rank navigation

**Checkpoint:** 23 November 2026 · **Implementation:** `experiments/pnp-ground-navigation/cut_intention/` · **Previous:** [CIG-001](CIG-001.md), [CIG-002](CIG-002.md). **Scope:** exact, bounded source-CNF experiment over a family of equality-copy networks with arbitrary additional clauses admitted within declared factor budgets. Python standard library core; native optional integrations are enforced by the cross-repository CI job.

## Research question

Can the **source itself**, rather than an explicitly predeclared operator graph, expose useful nonlinear observer coordinates and the measurements needed to navigate them? Can we derive exact SAT, #SAT and boundary-relation rank for a source whose active-variable count exceeds the previous finite enumerator, while checking every transformation and charging construction cost?

**Observed outcome:** yes for decomposable source instances. A 24-active-label original CNF (132 endpoint variables) previously refused by CIG-002's 14-active-label budget. CIG-003 discovers eight independent local nonlinear functions from the original clauses, conditions one cross-component coupling, and proves the resulting solution count and cut rank with just **112 local truth-table visits in the counting pass** (one 6-variable and six 3-variable components). The 24-bit monolithic space has `2^24=16,777,216` assignments. Further source/rank/policy computation and independent verification are separately charged; 112 is not the full elapsed-work count.

## Source → equality Ground → nonlinear observer features

The input remains the **original** `ifs.cut-intention-coupled-source.v1`: endpoint-equality CNF from CIG-001 plus ordinary additional clauses in original endpoint variables. Neither learned function names nor hidden gate hints appear in the input. The derivation:

1. Reverify both directed implications for every equality-pair label, complete observer graph coverage and source-clause admissibility.
2. Substitute the source-proved equalities into all additional clauses, forming an exact active-label CNF `H(y)`. Normalize tautologies, duplicates and variable identities. The original source digest remains bound to the certificate.
3. Find connected components of the **clause-variable primal graph**. For `H=∧_i H_i(y_i)` with disjoint variable supports, exact model counts factor: `#SAT(H)=∏_i #SAT(H_i)`. Admit a component only when `|y_i|≤9`. Refuse if a coupling destroys this factorization budget; never turn a local budget refusal into UNSAT.
4. Search three-variable source supports for a unique Boolean output for all four assignments to two inputs. A candidate `(u,v,z)` is admitted only if a subset of the **original reduced source clauses** proves `z=f(u,v)` for all eight local states and both inputs are essential. Calculate its unique algebraic normal form (ANF) in the Boolean quotient `GF(2)[u,v]/(u²-u,v²-v)`. Retain the original proof clauses and actual truth table. Require at least one quadratic term. A conservative disjoint-support choice guarantees source-induced gate rewrites have no inter-gate dependency cycles.
5. Build a mathematical nonlinear rewrite `T` that retains each input variable and replaces the proved output by its exact ANF. For each output observer `o(x)=z`, let `f` be its source-derived nonlinear polynomial. Its pullback closure is:

   \[
   T^*z=f,\qquad T^*f=f,\qquad
   [z,f](T(x))=\begin{bmatrix}0&1\\0&1\end{bmatrix}[z,f](x)
   \quad\text{over }\mathbb F_2.
   \]

   This is a **two-dimensional exact nonlinear-observer feature lift** of the kind constructed by [NCR-007](https://github.com/Kier73/Navigable-Compute/blob/main/docs/NCR-007.md). Every satisfying original-source state obeys `z=f`, hence is already fixed by `T`. We make **no** claim that this rewrite solves the residual SAT condition: it corrects only the certified gate equations. The native NCR-007 `BooleanOperator` and `pullback` are invoked in the cross-repository check; they agree on the source-discovered polynomials.
6. Detect useful bridge observations without naming them beforehand: remove each source-derived nonlinear output from the active CNF primal graph and see which removals split a connected source component. Rank candidates by exact increase in connected-component count, crossing-cut relevance, then canonical variable identity. This is a deliberately scoped separator-discovery policy; the native **OFG-003** discovery and source-replay are additionally executed on the same small CNF in the integration check. CIG-003 uses a **different objective** (conditional matrix rank rather than OFG's observer-fiber navigation cost); selected observations therefore need not coincide.

## Exact tensor-rank identity and costed observation policy

A fixed node cut partitions active labels into shared crossing labels `C`, left-private `L`, and right-private `R`. For each independent source component `i`, let `M_i` be the equality-aware flattened relation matrix over `GF(2)`, with one block for each assignment to its crossing labels. The full rank factors exactly:

\[
\boxed{\operatorname{rank} M(H) = 2^{|C_\mathrm{inactive}|}\prod_i\operatorname{rank} M_i(H_i)}.
\]

The proof follows from the original equality constraints, block diagonalization in crossing-label assignments, tensor-product factorization of independent components, and `rank(A⊗B)=rank(A)rank(B)` over `GF(2)`. The receiver uses a **column-based** elimination over each independently reconstructed local matrix; the producer uses row-based elimination. No large full-source tensor is materialized.

An offered observation may inspect a gate output directly, or obtain its **source-equivalent nonlinear ANF** from measurements of the necessary input signals. Both methods give the same observation on original-source solutions; their externally supplied `native_price` and `anf_price` are **declared bundled acquisition costs**, not measured or assumed-free sensors. The finite policy enumerates at most four eligible bridge candidates, selects at most two, and retains every possible observed outcome. With `r(A,a)` the exact rank after conditioning on observations `A=a`, its chosen policy minimizes:

\[
\boxed{ \min_{A,m}\ \lceil\log_2 \max_a r(A,a)\rceil + \sum_{o\in A}c_m(o) }
\]

under a bounded method pool. It breaks ties in favor of fewer acquired observations. This is a **chosen operational cost model** for worst-branch linear-representation size plus observation prices, not a general information-theoretic lower bound on SAT witness generation. A rank of zero indicates an impossible outcome; no possible branch is dropped without evaluation. The policy is computed before any actual observation and is always counterfactual.

## Reproduced measurements

Fixture: `make_gated_source(groups=8,k=12,ell=1)` produces **132 original Boolean variables**, 157 original clauses and 66 semantic edge-label bits. It embeds eight ordinary CNF encodings of `AND` gates, with one ordinary source clause coupling two outputs. No source metadata labels the gate functions. The active-label count is 24, and the balanced cut has 36 crossing label bits.

- `#SAT(original)=7·4^6·2^42 = 126100789566373888`. This is obtained by direct, source-verified local model counts followed by the exact inactive-label factor.
- `rank_GF2(full cut relation)=3·2^34 = 51539607552`.
- With two free bundled ANF observations, the source-derived bridge heuristic selects two nonlinear output coordinates and the worst remaining exact rank becomes `2^34`. The fixed-width bit representation decreases from `ceil(log2(3·2^34))=36` to `34`. For one impossible outcome, rank is zero; three possible outcomes each have rank `2^34`.
- With native measurement price `0` and ANF price `2`, it chooses native outputs instead. With native price `4` and ANF price `3`, it chooses no observations: the two-bit representation saving would cost six declared units.
- On the local Python 3.13 run, nine repetitions per configuration measured about **3.1 ms compilation and 3.1 ms independent source verification** for the eight-gate case. These are local, noisy end-to-end Python process measurements, *not* remote model, Internet host, E-CPU execution, or physical sensor timings. See [CIG-003-results.json](CIG-003-results.json) for all 9 cases and values.

The source-derived support graph has seven independent residual components after the single coupling clause: one component of size six and six components of size three. The exact counting pass visits `2^6 + 6·2^3 = 112` assignments. The complete producer and verifier additionally scan the original 157 clauses, derive and check functional truth tables, build all local rank matrices and evaluate the observation-policy branches. The ledger lists the number of policy outcomes and local count visits separately; construction and verification wall time include those additional costs.

Tests include 25 seeded small random residual CNFs whose SAT count and full cut rank agree with CIG-002, original-clause source witness checks, ANF exactness and a separately evaluated two-feature pullback, counterfeit policy and source mutation rejection, and a deliberately overconnected source that correctly refuses rather than returning an unfounded SAT decision.

## Next construction

The current exact global improvement is from **source-discovered functional decomposition and certified choice of what to observe**, not from solving dense arbitrary SAT. The next technical extension is nested junction-tree messages and source-derived gates with *shared upstream variables* or nonlinear dependency chains. That will require a verified nontrivial Koopman feature closure (rather than today's two-feature idempotent rewrite), exact cost accounting when global support graphs connect, and source-bound revision/host authority if implemented in VL-I/E-CPU. A useful adversarial benchmark is to increase coupling density until all components merge and compare the new symbolically discovered rank/observer coordinate Ground with plain PNG/SFI and proof-carrying SPN, including the exact cost of finding each representation.
