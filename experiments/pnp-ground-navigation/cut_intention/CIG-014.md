# CIG-014 — Anticipatory nonlinear sufficient Grounds

Research checkpoint: 23 November 2026. Predecessors: [CIG-005](CIG-005.md), [CIG-009](CIG-009.md), [CIG-012](CIG-012.md), [CIG-013](CIG-013.md). The experiment uses the actual CIG-008 canonical source, CIG-010 audited realization and witness reconstruction, CIG-012 Archive, and CIG-013 coordinate retention. CIG-005's nonlinear observer quotient supplies the mathematical precedent. No new runtime authority is introduced.

## 1. The source-model quotient

Given a bounded regional scope V, base CNF C, externally visible coordinates B, and a declared catalogue of CNF clause predicates P_i, define q(x) = (x|B, P_1(x), ..., P_k(x)). The retained histogram is H(u) = sum_{x:q(x)=u} [C(x)]. For any future conjunction D whose clauses factor through q, and output coordinates B' contained in B,

```
M_(C AND D,B')(b) = sum_{u: u|B'=b} H(u) [D(u)].
```

This follows by partitioning the source models into fibers. A realized signature groups exactly the source models agreeing on all declared readouts and predicates. For a nonempty source model set, if K signatures occur, the coarsest deterministic partition preserving the whole vector has K classes and the minimum fixed-width binary code is ceil(log2 K) bits. A canonical code is the rank of a signature in the sorted image. For an empty model set we use zero bits by convention. The actual representation is a sparse histogram of signature masks and exact decimal multiplicities, not a packed minimal-bit encoding. It preserves counts, not arbitrary individual hidden assignments. The original source witness is reconstructed separately by the existing audited CIG-010 traversal.

The quotient can serve more queries than those originally declared. A new clause whose signed literal set is an exact union of retained clause literal sets and visible signed literals is the OR of those predicates. The producer constructs that cover; the checker independently validates the literal union and replays all histogram sums using tuples. Every added clause must have a cover, every requested output coordinate must be visible, the full variable scope must be identical, and original clauses must be included. Empty clauses are correctly false. A missing predicate or changed scope falls back to a new exact regional evaluation. Source-dependent semantic equivalences beyond syntactic union are a future route, not assumed here.

The base histogram is independently admitted by enumerating every assignment to the bounded source scope using a separate tuple implementation. Thus the preparation is charged even when a query becomes inexpensive. At most ten variables and 32 predicates per region are admitted; the general CNF size limit comes from CIG-008. The receiver's process-local `PredicateRetained` obtains base/forecast leaves from audited layouts, extracts predicates from actual source additions and retains the independently checked seed JSON. It does not assume forecast probabilities or infer a physical process. It is not an adversarial remote-admission API. `check_translation` assumes an already admitted seed; `check_seed` checks the external source and intention contract. Fresh query sessions prevent query-derived tables from silently accumulating across the comparison. Unsupported translations use the ordinary verified Archive. No global policy optimum or general SAT speedup is asserted.

## 2. Executed connected workload

A chain of m regions has n=9m+1 original Boolean variables, two shared endpoint bits and eight private variables per region. Every region has two base clauses `(-l OR r OR u0)`, `(l OR -r OR u4)`. The fixture gives an explicit region layout, with shuffled variable identities and source clause order. The four forecast CNFs introduce positive and negative disjunctions on each private group of four bits; the compiler is supplied those source revisions, not feature tags. Four further queries are held out from preparation: the conjunction of all four predicates, two unseen eight-literal unions, and an empty-clause contradiction. The independent transfer-matrix oracle counts a region by the number of choices for each four-bit private group (with an optional forced one), subtracting the forbidden all-zero/all-one patterns; it composes the resulting 2x2 integer matrices along the chain. Every query is independently checked against this oracle, and satisfiable executions reconstruct and check the original-CNF witness.

The three paths use identical layouts and source revisions: (1) cold Archive; (2) actual CIG-013 Retained/RevisionArchive with a full-scope coordinate table in each region, a deliberately simple coordinate-retention comparator rather than CIG-013's optimized portfolio; (3) predicate quotient. All preparation times include independent seed checks; query times include source audit, translation or new computation, independent message verification and witness construction. The predicate preparation scans the four forecasts to extract its catalogue. Coordinate preparation is given the full scope; it does not pay forecast-selection costs. Full local regression: 210 tests passed (Python 3.13.5). All five connected scales, eight queries each, and three methods agreed with the independent combinatorial oracle.

```sh
python -m unittest discover -s . -p 'test_*.py' -v

```

The result ledger includes all per-query timings, exact counters and SHA-256 hashes of the independently computed integer counts. The largest test has 4,609 variables, 1,024 base clauses and up to 3,072 revised clauses. No physical measurements or remote CI success are implied by these local runs.

## 4. Next mathematical possibilities

The exact criterion for adding an observation f to an existing quotient without adding information is constancy of f on every source-model fiber of q. A source-qualified decoder can be learned by checking that condition once; a collision of two models with equal q and unequal f proves insufficiency. Existing CIG-005 source-supported decoders, VGI's partial refinement, and NCR-007 Boolean pullbacks are relevant. The next experiment should compare symbolic implication certificates against full source replay, qualify new predicate decoders, and construct the least refinement when a collision is found. Another direction is to distinguish a lossless deterministic observation quotient from a potentially smaller linear sufficient statistic for only a finite set of aggregate count queries. Preserve actual proof and acquisition costs.
