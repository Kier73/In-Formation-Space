# CIG-015 — Self-extending source-conditioned observation languages

## Research question

Can a retained nonlinear Ground establish an unanticipated observation using its existing information, and if it cannot, extend its language by precisely the necessary distinctions? This increment directly uses CIG-014 predicate-fiber retention and its independent translation checker; CIG-013 forecast matching, CIG-012 receiver-owned archive, and CIG-010 source/layout audit and witness reconstruction. VGI's partial refinement and CIG-005's observer decoder are conceptual predecessors. The implementation is local; no new physical observations or E-CPU authority are assumed.

## Exact extension theorem

For a fixed source CNF C and scope V, an admitted signature q contains required visible boundary bits and truth values of retained signed-literal disjunctions. Its sparse histogram H(u) counts C-models in each realized fiber. For a new Boolean clause f, the canonical refinement is q'=(q,f):

```
H'(u,b) = #{x : C(x), q(x)=u, f(x)=b}
H(u) = H'(u,0) + H'(u,1)
```

The new function factors through q iff no realized fiber has two positive refined counts. Each split adds exactly one realized signature; q' is the coarsest partition refining q and determining f. A counterexample pair in every split has equal q, opposite f, and satisfies C. Proof: any partition retaining q and f must separate those pairs and is a refinement of the equality partition for (q,f). The lower bound ceil(log2 K) for K realized signatures is a bound on arbitrary lossless fixed-width binary codes, not the actual stored signature-mask width. Redundant predicates may append a bit without increasing K.

## Executable interpretation paths

1. Exact signed-literal union: CIG-014's `covers` proves a target disjunction from existing clauses or visible literals; no hidden-state enumeration.
2. Source-relative equivalence: every binary source clause (a OR b) entails directed edges -a->b and -b->a. Mutual reachability proves equality of truth values on every C-model. The producer builds per-literal graph reachability; the independent verifier reconstructs transitive closure by a distinct relation algorithm. Replace literals by equivalence-class representatives, prove the exact union identity there, and evaluate retained bins. A negated retained singleton also supplies its complement. Only binary implication equivalences are used, not arbitrary claimed implications.
3. Semantic extension: if neither proof route covers a requested clause, scan the bounded leaf domain, group satisfying assignments by the old signature and the new truth bit, and record one pair per split. The verifier independently enumerates using tuples/dictionaries, reconstructs every refined bin, checks conservation per old fiber, validates both assignments, and binds the new source descriptor and counts. This is a full local scan, not a targeted SAT oracle that skips all unaffected hidden states. It may discover semantic sufficiency with zero splits.

`Language` stores immutable JSON of its independently admitted latest seed. Every extension is checked against the receiver's old seed before replacement. This is trusted process-local admission; standalone portable extension-proof chains and authenticated publication remain future integration. `LanguageRetained` derives initial predicates from the supplied forecast layouts; `LanguageArchive` uses the actual CIG-014 translation verifier to admit each revised message into the existing CIG-012 archive. Fixed scope and visible boundary are required, and target source must include the admitted base clauses; unsupported scopes, deleted base clauses and new hidden boundary coordinates use fresh counting. Removing a query's added constraints is allowed by returning to the unchanged base, not by inverting a marginal. Leaf width <=10, predicates <=32, source n<=8192. Source audit, internal joins, witness reconstruction and original-source checking still execute. The extension does not prove a general SAT acceleration theorem.

Run the same eight intentions twice, using transient destination archives and persistent base-language memory. The static control is actual CIG-014 `PredicateRetained` with the same one forecast; the cold control uses actual CIG-012 `Archive` with no memory.
