# CIG-026 — Proof-carrying temporal state images

Connects [CIG-021](CIG-021.md) source-qualified transport, [CIG-024](CIG-024.md) temporal set algebra and [NCR-008](https://github.com/Kier73/Navigable-Compute/blob/c249a482a0a09e24b3a2af5b39d43a45856e2bc6/docs/NCR-008.md) mixed-radix image encoding. NCR-009's costed portfolio motivates measuring contraction costs, not assuming a smaller code is faster.

## Exact construction

CIG-021 admits a total observation section and a deterministic transport

    T(u)_j = F_j(u_{p(j)})

where p permutes block locations, each alphabet has a=2^w symbols and each F_j is a total possibly nonlinear/noninjective map. Define X_t=T^t(A^m). Because each destination has exactly one predecessor and the spatial permutation never copies or merges blocks, X_t is exactly a Cartesian product of local alphabets A_j(t). This follows by induction, including simultaneous attainability of all local symbols. A total section is essential: without it the initial full cube need not be the source image.

The admitted graph has m*a vertices (location,symbol), each with one outgoing edge E. Every cycle vertex belongs to E^t(V) at every t. For each noncycle vertex v define h(v)=max({0} union {h(u)+1: E(u)=v}). Its predecessors are noncycle vertices in an acyclic graph. Thus v has an incoming path of length t iff t<=h(v). The producer computes h via indegree peeling; the independent receiver reconstructs predecessor lists and checks each recurrence against the existing CIG-021 cycle qualification. A cycle marker is -1. This takes linear graph work for construction and admission (excluding original source/transport proof). At any admitted logical time,

    A_j(t) = {s : h(j,s)=-1 or h(j,s)>=t}
    K_t = product_j |A_j(t)|
    b_t = (K_t-1).bit_length()

No global image or full trajectory is enumerated. The full observation code is recovered by mixed-radix unranking, with the first block the least significant digit. This is minimum fixed-width storage of the *entire endpoint observation code* over X_t, not necessarily minimum for the decoder outputs or a known individual trajectory. Integer multiplication, rank arithmetic, packing and decoder execution are not constant-time with respect to representation size. Images are nested for a fixed law on the full cube and their cardinalities never increase. Once the largest finite h is exceeded, the image is the set of cycle vertices by location; periodic transport may persist forever.

## Migration

At time t retain r_t, the rank of u_t in X_t. To advance to t'>t, unrank using X_t, use the native CIG-021 Navigator.jump for t'-t, then rank in X_t'. A receipt binds the proof, decoder/transport identity and original anchor, prior time and rank, next time and rank, exact logical capacity and decoder output. The receiver independently unpacks the proposed coordinate using positional quotient arithmetic and passes its reconstructed full code to the existing CIG-021 Receiver.accept, which verifies the endpoint directly from the original anchor. Only on acceptance does its local time/rank change. Forged, stale, replayed or out-of-range receipts refuse without mutating admitted state. The producer's commit is a local caller-controlled step following receiver acceptance, not an authenticated distributed commit protocol.

The producer does not retain its initial source code as execution state after construction. The independent receiver deliberately retains the original anchor. Graph, codebook derivation, decoder, source proofs, receiver anchor, Python object overhead and receipt metadata are separate from the logical packed coordinate. Zero bits means a unique endpoint code, not absence of all runtime memory. The JSON receipt includes the previous coordinate and decimal metadata; actual wire sizes are reported separately. No claim of reduced total host memory, network latency, or E-CPU recovery is made.

## Native cross-repository connection

The standalone implementation has its own small mixed-radix codec for dependency-free CIG use. `ncr_image_codec.NCRCodec` invokes the actual `navigable_compute.realized_image.pack/unpack` from the pinned NCR-008 revision c249a482a0a09e24b3a2af5b39d43a45856e2bc6. It adapts each independently qualified CIG alphabet into a radix layout. The NCR ImageCertificate-shaped layout is **not** submitted as an ANF image proof; CIG-026 is the temporal image authority. The required cross-repo CI job executes native-codec migrations through the actual CIG receiver, and checks exact equality to the standalone codec.

    p = Processor(nav, receiver.initial, codec=NCRCodec())
    admission = Admission(receiver, p.proof)
    receipt = p.move(10**1000 + 173)
    assert admission.accept(10**1000 + 173, receipt)
    p.commit(receipt)

## Evidence and reproduction

The original native-codec integration matrix passed on all four Linux/Windows jobs at [the predecessor revision](https://github.com/Kier73/In-Formation-Space/actions/runs/45333540077). This rebased increment retains those tests; the new integrated revision requires its own verification.

A controlled 341-block, 1,023-bit fixture uses the same nonlinear symbol table [0,0,0,1,1,2,3,3] at each rotating destination. The alphabets have sizes 8,4,2,1; hence exact logical retained capacity is 1023,682,341,0 bits at times 0,1,2,3. A bijective Toffoli transport control never contracts. The native mixed CIG-021 law is also benchmarked.

```sh
python -m unittest test_temporal_image -v
python run_temporal_image.py --sizes 24 96 384 1023
# With the pinned NCR checkout on PYTHONPATH:
python run_temporal_image.py --native-ncr --sizes 24 96 384 1023
```

The campaign separately measures decoder/section construction, transport qualification, native receiver admission, image construction/check, producer migration, independent acceptance, producer commit, ideal rank bytes, and actual receipt bytes. It compares every endpoint to the original Navigator and independent binary map-composition oracle, with source-derived decoder outputs checked against the original fixture oracle. Randomized small-state tests compare exact images, all ranks, native decoder continuation, stale/tampered receipts and refusal without total-image admission. The CI job runs the native adapter tests and a 24/96/1023-bit campaign.
