# CIG-002 — A single coupling clause changes observer-cut rank

**Checkpoint:** 23 November 2026 · **Repository:** `In-Formation-Space/experiments/pnp-ground-navigation/cut_intention` · **Status:** executable source-qualified experiment · **Environment:** Python 3, standard library · **Prior:** [CIG-001](CIG-001.md), [PNG-001](../frontier_ground.py), [OFG-003](../observer_fibers/OFG-003.md), [BENCH-01G](../benchmarks/BENCH01_STRUCTURAL_AUDIT.md), [BENCH-01H](../benchmarks/BENCH01_ALGEBRAIC_COORDINATE.md).

## 1. Question and measured answer

Can the same source CNF have the **same exact number of satisfying assignments** but *different* costs for preserving a full observer-cut relation when only one additional constraint is moved between structural coordinates? Yes.

The base is CIG-001's ordinary endpoint-equivalence CNF, with `k` observers, `ℓ` independent equality-pair bits per complete-graph edge. **The additional clause is supplied in original endpoint variables**, not a privileged latent-label language. The source compiler proves the original equality pairs from all base clauses, rewrites each additional clause under those proven equivalences, then constructs source-qualified `SAT`, `#SAT` and `CUT_RANK` Grounds. The verifier separately re-derives the equalities, source digest, reduced clauses and every numerical result.

At `k=24`, `ℓ=2`, `m=552` distinct edge-label bits and the balanced node cut has `C=288` crossing label bits. The baseline has `2^552` source models and GF(2) cut-flattening rank `2^288`.

| One additional original-CNF clause | Exact source model count | GF(2) flattening rank across same node cut | Rank relative to CIG-001 |
| --- | --- | --- | ---: |
| None | `2^552` | `2^288` | `1` |
| OR of two crossing labels | `3·2^550` | `3·2^286` | `3/4` |
| OR of a left-private and right-private label | `3·2^550` | `2^289` | `2` |
| OR of a left-private and crossing label | `3·2^550` | `2^288` | `1` |

**All three constrained sources have the same exact model count, yet their cut ranks differ by a factor of 8/3 between the lowest and highest.** In particular, **adding a constraint can increase the matrix rank** even as it removes models. Thus no monotone relationship between #SAT and exact cut rank is available even in this restricted source family.

## 2. Derived algebraic Ground

Let `F₀` be the original complete-graph equality CNF and `E` the list of added ordinary clauses. Every equality pair in `F₀` creates a source-proved label bit `y_j`, so the *entire* source is exactly equivalent under bijection to

`F₀(x) ∧ E(x) ⇔ H(y_1,...,y_m)` with `x` consisting of two equal copies of each `y_j`.

Only labels mentioned in the reduced residual H are active. Denote the active set by `A`, `a=|A|`, and let `Sat_A` count satisfying assignments of H on its `a` active bits. Then

\[
\boxed{\#\operatorname{SAT}(F)=2^{m-a}\,\operatorname{Sat}_A(H).}
\]

This is exact even when the added CNF contains contradictory unit clauses, duplicated clauses, tautologies created by equality substitution, or several constraints sharing labels. The bounded compiler admits `a≤14` (at most 16,384 assignment checks) and at most 128 added clauses, returning a typed refusal beyond that envelope. The original source remains the authority; it is not the same as assuming a caller-supplied label equivalence.

For a node cut `S`, partition label bits into three groups: `C` crossing the cut, `L` internal to the left side, and `R` internal to the right side. Similarly split **active** labels `A` into `C_A`, `L_A`, `R_A`. For every fixed active crossing assignment `c`, define the Boolean matrix

\[
B_c(l,r)=[H(c,l,r)] \quad (l\in\{0,1\}^{L_A},\; r\in\{0,1\}^{R_A}).
\]

The exact full-source flattening rank over GF(2) is

\[
\boxed{\operatorname{rank}_{\mathbb F_2}M_S(F)
=2^{|C|-|C_A|}\sum_{c\in\{0,1\}^{C_A}}\operatorname{rank}_{\mathbb F_2}(B_c).}
\]

**Proof:** The original equality constraints force a row and column to agree on every crossing label; the full matrix is block diagonal in the crossing values. For each such value, the only nontrivial internal relationship is H on the active left and right labels. Free private variables duplicate rows/columns and do not change rank; each *inactive crossing* bit produces two identical-rank diagonal blocks, doubling the total. Sum the exact ranks of the disjoint blocks. This yields the formula above. (It concerns the zero/one truth-table flattening, *not* the rank of a low-dimensional feature realization or the minimum Boolean circuit size.)

### Three 2-bit controls

For `H(l,r)=l∨r`, `B=[[0,1],[1,1]]`; its GF(2) determinant is one and its rank is **two**, whereas the unrestricted all-one block has rank one. This gives `rank(F)/rank(F₀)=2`.

For `H(c₁,c₂)=c₁∨c₂`, exactly three of four crossing assignments survive, each with rank-one block. This gives relative rank `3/4`.

For `H(l,c)=l∨c`, both values of `c` admit a nonzero left-column vector, so each block has rank one. Relative rank stays `1`, despite the same 1/4 reduction in source model count.

## 3. Execution, source verification and cost

Files:

- [`coupled_ground.py`](coupled_ground.py): synthesizes source-bound latent equalities and bounded exact intention-specific Grounds; emits original-CNF witnesses for SAT; evaluates active Boolean matrices with integer-bitset GF(2) row elimination.
- [`verify_coupled_ground.py`](verify_coupled_ground.py): **separate** structural parser and original-clause replay; independent direct active-CNF evaluation and GF(2) **column** elimination; rejects any difference in the full certificate or replaced source.
- [`test_coupled_ground.py`](test_coupled_ground.py): 9 test groups, including 45 seeded random residual-CNF fixtures, full original-CNF assignment counts and actual full-matrix Gaussian rank at `k=4`, multiple cuts, contradictions and forged certificates.
- [`run_coupled_ground.py`](run_coupled_ground.py): nine cold construction+verification repetitions per intention, 12 fixtures; emits [`CIG-002-results.json`](CIG-002-results.json). If running **inside the full repository checkout**, imports and executes the existing `PNG-001 frontier_ground.solve` on the *source-verified reduced CNF* as a separately charged exact counting control. The isolated environment used for this checkpoint does **not** have that sibling module, so its measured ledger explicitly marks the optional native PNG comparator as unavailable. In repository CI, that comparison executes rather than being simulated.

Reproduce from `experiments/pnp-ground-navigation/cut_intention`:

```sh
python -m unittest discover -s . -p 'test_*.py' -v
python run_coupled_ground.py > CIG-002-results.reproduced.json
```

Local execution: **9 new test groups passed** (plus the pre-existing 8 CIG-001 groups when running all), Python standard library. For `k=24,ℓ=2`, median *complete source construction + independent replay* was approximately **5.3 ms for CUT_RANK** in the single-process environment across the four kinds, versus hundreds or thousands of digits of implicit tensor data. No dense tensor was materialized at large scale. This is a structured-family symbolic proof, not a claim that an arbitrary SAT formula is cheap to decide. The reduced finite search and original source scans are both charged. Rerun to compare hardware or versions.

## 5. Next experiment: move from a bounded residual to discovered transformations

CIG-002's finite active-label bound is an explicit cost safeguard. The next objective is to let the original source *discover* a compact residual transformation even with more than 14 active labels, using PNG-002 parity proofs, SFI-002 verified Boolean DAGs, OFG-003 source-selected separators and SPN-007/BENCH-01H Fourier direct sums. Admit and measure a representation only if a source-level bijection or complete exact proof survives; otherwise return `UNKNOWN` for the requested decision/count/rank. For rank specifically, find efficiently computable conditional matrix ranks instead of enumerating all active assignments. A proof of uniform polynomial end-to-end cost on arbitrary SAT would have direct P-vs-NP consequences, so **do not confuse small observer-appropriate certificates with inexpensive universal certificate discovery**.
