# CIG-027 — Temporal intention under computational capacity

Builds on CIG-021 transport, CIG-024 temporal-set algebra, CIG-025 chronological rank/select, and CIG-026 temporal image (the rebased, cross-platform-tested NCR-008 bridge). This connects the actual implementations rather than replacing them.

## Exact capacity conjunction

For a fixed admitted total block-permutation transport T on the full initial observation cube X, X_t=T^t(X). Since T(X) is a subset of X, X_(t+1) is a subset of X_t. The CIG-026 graph-height proof qualifies every local alphabet; the minimum fixed-width encoding of the *whole endpoint observation image* is b(t)=ceil(log2 |X_t|). It is nonincreasing. This is a uniform capacity across possible initial codes, not the complexity of storing a known single trajectory.

Given a retained-bit budget B, let tau=min{t:b(t)<=B}, or infinity if impossible. Let H=1+max finite graph height (0 if all vertices are cyclic). The image is constant as a set after H even if the states continue evolving. Binary search on [0,H] finds tau using exact arbitrary-precision products of local alphabet sizes. Qualification checks b(tau)<=B and either tau=0 or b(tau-1)>B; impossibility checks b(H)>B. At most O(log(H+1)) image probes, each involving O(number of lifted vertices) local scans and big-integer arithmetic. The independent checker reconstructs the product from admitted heights, not the producer's threshold search.

For an admitted CIG-024 Boolean temporal expression I and start s, the earliest capacity-feasible event is exactly

    next_I(max(s,tau))

if tau is finite. If tau is infinite there is no event, regardless of I. All earlier capacity-infeasible events are excluded by monotonicity. For one-based ordinal j among feasible events from s, CIG-025 exclusive chronological rank R and selection S give

    S(R(max(s,tau)) + j).

This applies to transient events, ongoing periodic processes and derived temporal expressions. A transient event may be lost permanently under a tighter budget. A fixed budget can be infeasible even when the intention recurs forever. Budget exhaustion or time/ordinal outside the existing 4096-bit contract is UNKNOWN, not a proof of unreachability. The two native temporal representations remain separate: the MDD next route and the prepared signed-rank route.

## Implementation

`CapacityNavigator(processor,language)` uses CIG-026 Processor and CIG-024 Language. `CapacityAdmission(receiver,image_proof,algebra_receipt)` admits both independently against the same original CIG-021 receiver. The native rank packet is admitted through CheckedRank. The caller supplies the intended root, lower time bound, capacity, route and ordinal; the receipt binds each of these and the original image/anchor identity. The existing temporal-set or ordinal proof verifies earliest attainment; no exhaustive chronological search is repeated by the new layer.

```python
planner = CapacityNavigator(processor, language)
admitted = CapacityAdmission(receiver, processor.proof, algebra_receipt)
r = planner.query(root, start, budget_bits)
assert admitted.verify(root, start, budget_bits, r)
if r["status"] == "FOUND" and int(r["time"]) > processor.time:
    move = processor.move(int(r["time"]))
    assert admitted.accept_move(root, start, budget_bits, r, move)
    processor.commit(move)

admitted.prepare_rank(planner.prepare_rank(root))
r = planner.query(root, start, budget_bits, route="rank", ordinal=10**900+173)
assert admitted.verify(root, start, budget_bits, r, route="rank", ordinal=10**900+173)
```

`accept_move` first checks the exact intended destination, then delegates compact state admission to CIG-026's native receiver. Failures leave local receiver state unchanged; old migrations cannot replay. The producer advances only after caller acceptance. This is a local proof-qualified process, not a distributed atomic commit or physical scheduler. Retained state capacity excludes source law, graph, codebook, decoder, verification anchor, working memory and serialized metadata.

## Executed independent mathematical control

A separate JavaScript equation-level oracle in the research session checked 180 seeded small block-transport laws, 2,424 exact image comparisons and 1,800 combined earliest-intention/capacity comparisons against full source-state stepping and explicit transient/cycle trajectories. All matched. 132 laws had nonstationary periodic anchor trajectories; 1,463 of the sampled queries were unreachable and 12 found destinations whose capacity threshold exceeded the requested start. This is a mathematical control, not a run of the new Python package.

## Native tests and scale campaign

`test_capacity_time.py` checks 80 seeded source-qualified laws against exhaustive full images, every integer bit budget, earliest events via both native routes and third ordinal events. It covers delayed events, insufficient periodic capacity, expired transient intent, derived intentions, repeated migrations, stale and tampered proofs, rank budget refusal, 1,001-digit starts and 901-digit ordinals.

`run_capacity_time.py` constructs ordinary shuffled source CNFs through the original CIG compiler. In a 3-bit-symbol processor, independent irreversible lanes use [0,0,0,1,1,2,3,3] and periodic lanes use Toffoli symbol permutations and rotating marker cycles. All marker bits are set at the original phase, so the rare conjunction holds exactly at multiples of P=product of the distinct prime cycle lengths. Each irreversible lane loses one bit of capacity per step until zero; periodic lanes retain three bits each indefinitely. The decoder remains active. The analytic oracle predicts the jth capacity-feasible event as (ceil(max(s,tau)/P)+j-1)*P. The campaign checks both routes at ordinary and huge times, then uses a derived tautology to migrate at every intermediate contraction and continues to realize periodic events. It independently checks native observation coordinates against the binary-composition oracle and decoder outputs against the original Boolean expression; the next state after each recurring event is different. Actual source preparation, joint admission, rank compilation, query, verification and migration costs and receipt bytes are logged separately. No inferred physical memory or speedup.

```sh
python -m unittest test_temporal_image test_capacity_time -v
python run_capacity_time.py --sizes 24 96 384 1023
# pinned NCR checkout on PYTHONPATH:
python run_capacity_time.py --native-ncr --sizes 24 96 1023
```

## Continuous process frontier

For a piecewise constant external capacity schedule, intersect each schedule interval with [tau(B),infinity) and the admitted temporal set; rank differences give exact counts per interval and select gives the earliest or kth feasible event. Under future edits to intention or source law, images need not remain nested across the edit; retain or acquire exactly the missing distinctions via CIG-015/017/018, and qualify a new image/decoder epoch before retiring old state. E-CPU admission and recovery can supply actual host leases and resource allocation. This is the next integration rather than a claim about real-time host memory.
