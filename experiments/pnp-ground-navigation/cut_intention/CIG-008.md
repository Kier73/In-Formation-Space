# CIG-008 — Composed affine, Boolean and matching Grounds

**Checkpoint:** 23 November 2026 · **Predecessor:** [CIG-007](CIG-007.md) · **Scope:** exact source-qualified mixed-language SAT/#SAT with bounded Boolean interfaces. Standard-library Python. No general polynomial-time SAT claim.

## Source and interface contract

`composed_ground.compile_ground(clauses,n,max_width=12,max_cells=2_000_000)` consumes ordinary CNF. It recognizes a parity equation only when all clauses excluding the opposite parity class occur on the same support (arity ≤3). It partitions every normalized clause into a recovered parity block or the residual. Both parity classes may occur, producing an exact contradiction. Tautologies and duplicate clauses are removed without changing the Boolean relation. The interface is the union of residual-clause variables; every other source variable is private, including isolated free bits.

Write the resulting relation as `R(s) AND (Ah+Bs=b)`. Eliminate the private columns of the augmented equation matrix over GF(2). Retain triangular pivot rows for reconstruction, plus remaining projected rows `Cs=d` on `s`. Every admitted interface has exactly `2^(|h|-rank(A))` private extensions, and every inadmissible interface has zero. Thus

```
#SAT(F) = 2^(|h|-rank(A)) * sum_s [R(s)] [Cs=d].
```

This is exact even when affine and nonlinear clause regions overlap on shared variables. It follows from the uniform cardinality of affine fibers, not from an independence assumption about shared coordinates.

The Boolean phase makes one 0/1 factor per residual clause and projected parity row. Min-current-neighborhood variable elimination combines factors incident to a pivot and sums over its two values. The new factor is an exact integer conditional count, a message over the remaining interface. Reverse traversal chooses nonzero-support values, then reverse triangular substitution extends the witness to all original variables. All local tables are budgeted before allocation, including both pivot values. `UNKNOWN` means a factor exceeded its finite width/cell budget; it does not establish a negative SAT result. The width heuristic is not an optimal decomposition algorithm.

`verify_composed_ground.verify` independently reconstructs the original source clause partition by truth-table enumeration of each claimed parity block. It compares canonical augmented GF(2) row spaces using set-based elimination, checks the hidden triangular pivots and free-coordinate multiplicity, then replays the integer interface factors using explicit assignment-tuple dictionaries rather than producer packed tables. The checker verifies the final count and an original-CNF witness; a zero count is justified by complete bounded interface replay. Source identity is a canonical CNF digest. Receiver budgets are external arguments, not producer-selected authority. This is an independent Python checker, not a formal kernel proof.

## Decision-only matching interface

`decide_with_hall` directly imports CIG-007's `hall_ground.compile_hall`, operates on the residual **original** clauses after affine extraction, and either:

- emits a Hall subsource refutation, which also refutes the full source and is checked using the original `verify_hall` on all original clauses; or
- obtains a matching witness, checks projected parity, reconstructs private coordinates and checks every original clause; or
- returns `UNKNOWN` when the matching witness cannot be extended or the matching method refuses.

The result carries **no model count**. Matching feasibility is not a #SAT oracle. This interface is a separate decision route, not a full multi-region matching-count message algebra. It can resolve a Hall obstruction despite additional affine constraints without searching those constraints.

## Reproducible heavy workload

The connected fixture has `m` stages, original bits `x_0,...,x_m`, nonlinear outputs `y_i=x_i AND x_(i+1)`, an XOR `h_i=x_i XOR y_i`, four affine equality copies terminating at `z_i`, and a clause `(NOT z_i OR x_(i+1))`. Each stage forbids transition 10. The only possible original x sequences are nondecreasing, hence `m+2` solutions; all other values are uniquely determined. Adding `x_0=1, x_m=0` creates a contradiction. Variable IDs and clause order are shuffled with seed 73. No such metadata is supplied to the compiler. The source primal graph is connected.

On the recorded local run the largest SAT source took 416.107 ms to compile and 209.579 ms to independently verify. The producer visited 786,944 affine projection rows and 15,170 factor-table cells (not an operation count or total CPU work). The source-qualified receipt was 982,403 JSON bytes; global-width integer masks are expensive to serialize. A sparse index encoding is a clear next improvement. The actual CIG-006 direct DPLL counting control, 1200 nodes/1.5 seconds, agreed at 57 and 225 variables and returned UNKNOWN on 897 and 1793 variables; both methods resolved the contradictory endpoint control. DPLL timing excludes independent count verification, while the composed timings include it. This is a local structured benchmark, not a comparison to optimized CDCL.

The decision-only Hall interface additionally proves 8/7 and 32/31 pigeonhole obstructions with extra affine coupling attached to the original source (58 and 994 variables), and extends a 4/4 matching witness through the affine region. Seeded random 3-CNFs at 50/75/100 variables all return UNKNOWN under the present factor-width budget. No claim that those formulas are UNSAT is made.

## Evidence and usage

The 107 predecessor tests and 18 new tests passed locally. The new suite covers 350 small randomized CNFs against direct exhaustive truth tables, exact free-hidden multiplicity, connected SAT/UNSAT, both parity classes, source mutation, forged count/projected row/pivot/elimination order, source partition changes, budget refusal, and the real CIG-007 Hall decision routes. `CIG-008-results.json` preserves the recorded matched campaign (timing naturally varies). Run from the combined CIG directory:

```sh
python -m unittest discover -s . -p 'test_*.py' -v
python run_composed_ground.py
```

The implementation invokes actual CIG-006 `heavy_ground.dpll` and CIG-007 `hall_ground`; it does not copy their logic or substitute mock results. Conceptual antecedents: PNG-001 factor elimination, PNG-002 source parity lifting, OFG-003 conditioned fibers, and VGI's proof-qualified observer contracts. Those separate modules were inspected in the research sequence, not executed as native dependencies in this particular benchmark.
