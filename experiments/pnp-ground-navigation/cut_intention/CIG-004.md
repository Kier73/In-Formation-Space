## 1. Question and result

Can an observer's declared *time-indexed intention* select a smaller **exact** processor than the one required to preserve its whole temporal behavior? Can the representation be constructed directly from the source CNF and independently audited, including nonlinear overlapping variables, without assuming a pre-labelled gate DAG?

**Result for the bounded admitted source family:** yes. The original source is a complete-graph equality-copy CNF plus 3-literal coupling clauses. CIG-004 source-replays the endpoint equalities, discovers total Boolean gate relationships via all local truth tables, chooses a **declared canonical orientation** (the maximum-index variable as each local output), forms a simultaneous nonlinear source repair map `T`, and constructs the least `GF(2)`-linear space closed under pulling back a selected observer. Then it synthesizes an **eventual-time observer**, the fixed polynomial `O∘T^h`, and proves it delivers `O(T^t(x))` for every initial state and all `t≥h`.

For the four-stage source:

\[
\begin{aligned}
 a',b',c',d' &= a,b,c,d,\\
 z_1'&=ab,\\
 z_2'&=z_1\oplus c,\\
 z_3'&=a z_2,\\
 z_4'&=z_3\oplus d,\qquad O(x)=z_4.
\end{aligned}
\]

The original clauses define the fixed-point predicate **exactly**: `F(x) ⇔ T(x)=x`. This does not mean arbitrary initial states satisfy the CNF: outside the fixed points, `T` is a *chosen repair dynamics* built from proven local constraints. The source CNF by itself does not determine a unique temporal direction for invertible XOR constraints. The maximum-variable orientation is explicit and source-checked, and a different admissible orientation can produce a different `T` while preserving the same fixed points.

For the raw output observer `O=z₄`, symbolic pullbacks give five linearly independent Boolean functions:

\[
\begin{aligned}
f_0 &= z_4,\\
f_1 &= z_3\oplus d,\\
f_2 &= a z_2\oplus d,\\
f_3 &= a z_1\oplus ac\oplus d,\\
f_4 &= ab\oplus ac\oplus d.
\end{aligned}
\]

Exact Boolean-ring multiplication includes `a²=a`. Consequently:

\[
 T^*f_0=f_1,\quad T^*f_1=f_2,\quad T^*f_2=f_3,\quad T^*f_3=f_4,\quad T^*f_4=f_4.
\]

The full temporal-feature Ground has the **minimum invariant linear dimension 5** for this observer and law. The independent verifier reconstructs its orbit `span{O,(T*)O,...}`, proves the five polynomials are independent, and checks every matrix row over exact Boolean ANF. Matrix binary exponentiation navigates arbitrary admitted integer logical time with `O(log t)` matrix compositions; the feature constructor's own nontrivial cost is fully included in the experiment.

The future-aligned intention deliberately asks a *different* question from preserving the whole trajectory:

\[
\boxed{\forall t\ge4:\quad O(T^t(x))=ab\oplus ac\oplus d.}
\]

The polynomial `g=ab⊕ac⊕d` satisfies `T*g=g`, so the eventual-observation Ground is **one invariant feature**, directly evaluated from the supplied initial state after a finite, source-derived proof of stabilization. At times `t<4` it is **not** equivalent to the raw observer `O(T^t(x))`; this scope is carried in the receipt.

## 2. Source law and exact certificates

1. Original source: `make_source(k=10,label_bits=1)` creates 90 endpoint variables and 90 equality clauses; the four-gate fixture adds 16 ordinary three-literal CNF clauses. The source contract supplies a graph and original clause list, **not gate annotations**. Replaying the equality claims yields 45 exact independent edge labels, with eight labels active in four gate clauses. Other labels remain free.
2. Every three-variable source support must prove a unique output bit for each input pair; each clause must be attributed to exactly one proved function. The compiler refuses unsupported residual clauses, changed source identities, nonfunctional blocks, incompatible orientation, or excessive budgets. The independent receiver repeats this from *original endpoint CNF*, not the compiled Ground.
3. Four local gate proofs form a directed acyclic source rewrite under the declared index-based orientation. Every assignment of four free input bits admits exactly one fixed point; the 37 inactive edge labels remain free. Thus `#SAT(original)=2^(4+37)=2^41`, with an original-clause-checked witness. This is standard structural #SAT for a functional circuit family; no general algorithm for unstructured SAT is implied.
4. Each update row is an ANF polynomial with monomials represented as variable-support bitmasks. Multiplication uses union of monomial supports (Boolean idempotence), and addition is symmetric difference (characteristic two), never arithmetic addition of exponents. Both terms and expansion operations have explicit admission budgets.
5. The compiler closes the observer under exact ANF pullback, retaining a basis, `GF(2)` feature transition rows and observer decoder. The receiver independently recomputes all gate truth tables and substitutions, reconstructs the Krylov orbit and verifies its equality to the supplied feature span, the matrix equation and exact navigation result.
6. The **intention switch** synthesizes the eventual polynomial by repeated symbolic substitution until it is fixed; this adds explicit construction and verification work. The receiver independently checks first stabilization time, exact polynomial, invariant identity, eventual-time scope, and source-state trajectory on the admitted small fixture.
7. Receipts separate `source_digest`, elected `T` orientation, original SAT count/witness, observer feature basis, logical navigation time, stable-observer certificate and construction ledger. A new observer intention cannot borrow a proof of a different observation contract.

## 4. Distinct scientific claims and their scopes

| Claim | Mathematical observer contract | Evidence |
|---|---|---|
| Source SAT/#SAT | Satisfying **original endpoint clauses** | Original equality reconstruction + functional CNF source replay, free-variable count and witness |
| Exact nonlinear dynamics | A particular declared oriented repair map `T` | Full local truth-table and ANF verification, all small states independently replayed |
| Minimum whole-future linear dimension | All `O(T^t(x))`, `t≥0` | Independent Krylov span over `GF(2)`, exact ANF span equality and closed transition matrix |
| One-feature eventual Ground | **Only** `O(T^t(x))` for `t≥h` | Exact first fixed pullback polynomial, independent `T*g=g` and audit of time horizon |
| Long logical-time navigation | Given source state and `t`, compute observed output | Independently recomputed matrix exponentiation plus bounded direct trajectory |

The initial state of navigation can violate the CNF; it is an arbitrary instantaneous configuration on which the *source-derived* map operates. Only fixed points are satisfying CNF models. No host or external sensor is authenticated by the mathematical Ground. None of these claims supplies a P-versus-NP resolution.
