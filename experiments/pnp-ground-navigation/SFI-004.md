# SFI-004 — Structural memory of verified interpreter construction under changing SAT intentions

**Status:** Bounded, executable research; 22 November 2026. **Research family:** SFI-001 direct source-checked SAT → SFI-002 non-affine and heterogeneous interpreter construction → SFI-003 meta-SAT self-refinement → **SFI-004 qualified structural memory**. No P versus NP claim and no authenticated remote execution claim.

## What was missing

SFI-003 demonstrated that the system could use its existing SAT interpreter to improve its own Boolean-function selection, but each fresh request reconstructed the source-derived processor and its bounded optimization problem. Separately, [GRC-001](spectral_phase_navigation/GRC-001_SOURCE_REFINEMENT_CONTINUITY.md) already checks SAT / #SAT *result continuity* across strengthened CNF clauses, and [SPN-010](spectral_phase_navigation/SPN-010_SELF_USE_GROUND_COMPILATION.md) already constructs and rejects/adopts self-selected *solver policies*. Rather than duplicate those, SFI-004 asks:

> Can a previously verified, meta-SAT-improved **computational architecture** survive a change in the source description, and be used again without retaining a stale answer or silently inheriting execution authority?

We implement one exact, intentionally narrow answer for source strengthening, not arbitrary source edits or variable isomorphisms.

## Exact continuity contract

Let `F` be the canonical original CNF, and let `G_F` be the SFI-003 verified Boolean interpreter: a DAG of local truth-table functions with disjoint defining clause blocks `B_i` and residual clauses `R`. Each satisfying assignment of the free registers determines precisely one assignment satisfying all `B_i`, and the residual filters those assignments; SFI-002's independent verifier rechecks this equivalence.

For a new CNF `F'` over the **same declared variables**, this prototype admits architecture reuse only when `Clauses(F) ⊆ Clauses(F')` after independently checking normalization. This is a strengthening, not a guarantee that the old answer still holds. Since every `B_i` is still present in `F'`, we retain the same gate DAG but replace the residual with `Clauses(F') \ ⋃ B_i`. The independent source verifier then establishes

`#F' = Σ_{z ∈ {0,1}^d} [ F'(Decode_G(z)) ]`.

This is elementary exact functional substitution plus source filtering, not a general compression theorem. Source **weakening** or variable-count changes require a fresh compile; a reused interpreter never carries a SAT witness, UNSAT claim or #SAT result into a new source. Original clauses are re-evaluated when a new observation is produced. A strengthening can therefore turn a previously satisfiable formula into UNSAT while keeping the same four-register processor.

The memory selects a reusable architecture only if it has **strictly fewer free registers than a freshly constructed, independently checked SFI-002 greedy Ground on the new source**. This admission objective is a deterministic complete-coordinate search-space comparison, *not* a proof of lower real-world wall time. When no source-qualified strict improvement exists, the memory records a fresh baseline instead of claiming reuse. The reused architecture need not be optimal among all programs or all candidate gates.

## Source and memory identity

`construction_memory.py` retains a content-addressed local JSON image:

- **Construction records:** source count and normalized original CNF; exact generated Ground and its full clauses/truth tables; the original SFI-003 meta-SAT proof receipt for the initial self-refinement; source-lineage ancestor ID; a deterministic fresh greedy reference dimension; and observed construction milliseconds.
- **Observation records:** intention (`SAT` or `#SAT`), coordinate and partition budgets, source-bound partition receipts, exact observed result and measured wall time. Observation data is accepted only after full independent result replay. `UNKNOWN` remains explicit under insufficient budget.
- **Append lineage:** fixed schema; predecessor digest, sequential ordinal and content hash. A new Python process reconstructs and rechecks every historic source proof, meta-SAT optimization receipt, extension relation and stored observation before it can use the image.

The local single-writer appends use a staged temporary file, flush, `fsync`, atomic replace and (on supported Unix) directory `fsync`. These are local crash-protection measures, **not** distributed consensus or process fencing. The content digest is not a signature; a capable actor can alter producer timing and recompute hashes, so **performance measurements are untrusted observations, never mathematical proofs or external execution permissions**.

### Using its own measurements to improve memory verification

The first implementation replayed every historical mathematical proof on *every append*. On the benchmark source this cost roughly **14–15 ms** per reused construction, more than a fresh bounded meta-SAT compile of approximately **4 ms** before its independent audit. That negative result motivated a targeted revision.

The current process pins the **exact bytes** of one already independently checked image. It compares the on-disk SHA-256 to the pin, deep-copies any state returned to callers, and verifies **only the proposed new record** when appending. It refuses a missing or out-of-band rewritten file; a newly launched process must perform a full independent audit before adopting it. For any new construction, the source-rewrite and greedy-reference proofs are still checked independently. An append that imports an unproven old result is impossible under the declared interface.

This reduces repeat append cost, while retaining the measured cost of source proof reconstruction on cold process recovery. A crash during local replacement leaves the last committed image or the next complete image, subject to filesystem guarantees. No multiwriter concurrency, mTLS identity, or E-CPU quorum claim is made.

## Reproducible experiment

Run from `experiments/pnp-ground-navigation`:

```bash
python -m unittest -v test_construction_memory.py test_recursive_sat_compiler.py test_self_selecting_sat.py test_morphic_sat.py test_self_forming_sat.py test_derived_ground.py test_algebraic_ground.py test_frontier_ground.py
python run_construction_memory.py
```

**Local regression:** 89 tests passed, including 15 new memory tests, 96 randomized clause-strengthenings with exhaustive reference counts, meta-SAT witness forgery, recomputed-digest truth-table forgery, altered observations, disappearance/change of a previously verified file, and a fresh Python worker process reopening the memory. The other tests are the existing SFI and PNG regression suite.

The 17-variable benchmark uses the same satisfiable six-variable `REPAIRABLE` source as SFI-003, plus 11 unused variables and a new two-literal source constraint. The prior meta-SAT Ground has 15 registers; a fresh greedy Ground has 16. A complete #SAT execution evaluates 32,768 vs. 65,536 source assignments and returns 8,192 models by both routes.

One local Linux CPython timing campaign (three independently source-verified execution samples per architecture; exact run numbers recorded in `SFI-004-results.json`):

| Case | Fresh greedy → remembered free registers | Source models | Verified execution (median) | Construction with source audit |
| --- | --- | ---: | --- | --- |
| Six-variable strengthening | 5 → 4 | 4 | ~0.47 → ~0.39 ms | Memory append ~5.2 ms; fresh meta+audit ~7.3 ms |
| Seventeen-variable strengthening | 16 → 15 | 8,192 | ~481 → ~296 ms | Memory append ~5.4 ms; fresh meta+audit ~7.0 ms |
| New explicit contradiction | 5 → 4 | 0 | ~0.39 → ~0.32 ms | Memory append ~5.3 ms; fresh meta+audit ~6.6 ms |

The construction cost is **not** always recovered by one small SAT query. The larger source has more repeated evaluation work, making the reduced search space consequential; these are not statistically established speedups or complexity bounds. Reuse transfers prior computation, so fair end-to-end analysis must count the original self-refinement and the storage investment as precomputation. We do not label this a uniform SAT shortcut.

**Independent checks:** All exact counts come from the *current* original source; the producer cannot authorize a SAT or #SAT result based on its previous observation. When the coordinate budget cannot cover complete checking, the new observation is explicitly `UNKNOWN`, not UNSAT.

## Connections and next question

- **GRC-001:** may provide separately verified *result deltas* under strengthening. SFI-004 instead reuses a compiler architecture; these two mathematical certificates are complementary and must never substitute for one another.
- **SPN-010:** its train/validation/final policy method can later decide whether, for an unseen source family, the observed cost of constructing and auditing memory is justified. This experiment does not train on its own held-out benchmarks and does not claim optimal dispatch.
- **VL-I PFI-001–004:** the rebuilt Ground and source identity are suitable as **candidate semantic objects**, subject to the receiver's own independent acceptance; this code does not issue PFI execution authority.
- **E-CPU:** live authenticated host authority remains entirely owned by E-CPU's existing Hypervisor, quorum-fenced claims and receiver handoff protocols. Copying a file to a new process preserves a reconstructable description, not an authorization lease or proof of physical remote execution.

The next difficulty is more general **structural navigation between not-monotonically-related descriptions**: e.g. syntactic variable renamings, related local function blocks, or mixed Boolean/affine subgrounds whose interface constraints evolve. Any such reuse will need a new exact semantic mapping, independent verification, workload-isolated evaluation, and complete accounting of discovering the mapping itself.
