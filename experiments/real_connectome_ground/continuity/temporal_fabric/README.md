## Body, mind and continuity

**Body** is the E-CPU observer-host fabric: authenticated TCP/TLS and ReliableChannel paths, receiver process and capability identity, in-transit operations, measured route costs, and recoverable state. **Mind** is the procedural computational Ground: source-pinned typed operators, trained or generated representations, temporal navigation, and evidence-validated observations. The OpenWorm connectome is **real heterogeneous topology data** used to construct a mathematical operator; it is not the intended body, a proposed spiking animal brain or a trained intelligence.

This experiment adds a source-bound **one-observable distant-time Ground** rather than another scheduler, mTLS implementation or model authority. It reuses:

- **RCG-002/003:** persistent research state, synthetic workload/host policy and proposed training curriculum.

- **VGI typed_operator_navigation.PreparedTemporalOperator:** already supports exact temporal powering of a dense operator. RCG-004 specializes to a selected observable to avoid preparing a dense operator.
- **IFS response-equivalence:** observer-specific minimal response dynamics rather than unverified claims about a unique physical realization.
- **IFS TCR-002:** established E-CPU mTLS/ReliableChannel worker pattern and test certificate generator; RCG-004 uses the original E-CPU transport modules directly.
- **E-CPU M1/M3/Hypervisor:** existing session and execution authorities; not yet integrated into this experiment and not claimed as newly implemented.

## A mathematical Ground for extremely distant time

OpenWorm source revision: d542a44bf2662f79e0ad23342a959a181a920877; original connectome Git blob: 89ffc2a2d9e1934ddc462d51032acead5e4cfc91. There are 448 connected node labels and 4,681 directed chemical records; not every label is a biological neuron.

Define a **new** GF(p) mathematical operator, with p=1,000,000,007. For chemical (or separately, electrical) edge u→v, let A[v,u] be its synapse count divided by the full outgoing count of u *in the finite field*. Any denominator without a modular inverse is refused. The requested scalar observation at source s, target t and logical tick T is:

h(T) = e_t^T A^T e_s (mod p).

This is **not** RCG-001's exact rational transfer, nor a neuronal firing probability. A changed field or edge type changes the Ground identity.

1. Prepare exactly 2N sparse observations h(0) through h(2N−1), where N is the actual number of connected source labels.
2. Derive a degree-r linear recurrence using E-CPU's already implemented Berlekamp–Massey, or the independent reference in pure-math tests.
3. Reconstruct the original source and **verify N consecutive residuals** of the candidate recurrence, not merely a source hash or a few spot checks.
4. Let q(A) represent the recurrence polynomial applied to the N×N source operator A. The residual sequence g(k)=e_t^T A^k q(A)e_s is itself generated by an N-dimensional linear system. By Cayley–Hamilton, if N consecutive initial g values are zero, all later values are zero. Therefore the receiver-owned finite test **certifies recurrence correctness at every future tick** under the precise GF(p) model.
5. Compute x^T modulo q(x) with repeated polynomial squaring and combine it with the first r scalar values. This costs **O(r² log T)** after **O(N·E + N²)** preparation, rather than O(T·E) iteration.

This is a well-established Krylov / scalar Wiedemann / Berlekamp–Massey method applied to source-pinned E-CPU Grounds, not a newly invented mathematical theorem. The original finite-dimensional proof is the important distinction from merely fitting a sequence to examples. It does not extend without additional evidence to arbitrary nonlinear activations or pretrained neural models.

## Locally measured scale

On a **synthetic** 448-node, 3,559-edge recurrent graph (not the OpenWorm CSV), Python 3.13 produced a degree-448 recurrence using 896 source observations. An exact query at logical tick **72,057,594,037,928,009 (2^56 + 73)** used 60 quotient-polynomial products, with result **665,424,168** modulo p.

| Local stage | Single observed time |
| --- | ---: |
| Sparse preparation and independent Berlekamp–Massey reference | 0.380 s |
| Independent source and all-time recurrence verification | 0.346 s |
| Distant-tick polynomial navigation | 2.223 s |

The test also checks tiny graphs against an **independent dense matrix-power oracle** at the same distant coordinate, plus rejects forged recurrence coefficients rehashed by the sender. The numbers exclude mTLS, Hypervisor, actual original source data and process recovery. They must not be presented as an original-OpenWorm result or as a network speedup.

## Real mTLS observer-path test (CI required)

The native experiment creates three separately running Python observer-host processes under **E-CPU's own mTLS and ReliableChannel**, using TCR-002's existing ephemeral per-worker SAN certificate generator. Every receiver loads **its own** pinned original connectivity data, verifies its E-CPU recurrence, navigates the requested logical time and returns a typed receipt. The sender pins the actual peer certificate and independently verifies the output against the original Ground.

A bounded EWMA policy learns only from **real sender-clock elapsed durations** of completed requests, and periodically probes less-used eligible hosts. It records TLS setup, request round-trip, receiver-local compute, and application bytes separately. To test adaptation under differences, the fixture deliberately injects **synthetic 0/70/160-ms service queue delays**. Mid-run it **hard-kills one receiver** and refuses to select it again.

These are genuine authenticated connections when the native job runs, but are **loopback processes on one physical runner**, not independent hardware trust domains. The in-process replay fence is not E-CPU M3 durable quorum; the receiver admission policy is not Hypervisor execution authority. No physical link or passive packet stream is claimed to perform neural arithmetic on its own. Native success is **not established** until the exact-branch GitHub Actions results pass.
