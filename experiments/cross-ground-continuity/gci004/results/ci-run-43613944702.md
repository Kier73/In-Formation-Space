## Live experiment

They advertised two parity loci and one low2 locus, each with a distinct ephemeral server certificate under one job-local test CA. ## Trust and physical scope

- Loopback TCP on one GitHub runner is genuine TLS networking but not a multi-machine or independently administered deployment.
- Signed receipts authenticate a key holder, not whether its reading is true.
- The ephemeral test CA is generated within the same test job, not by an independent trust administrator.
- Nanosecond elapsed times and serialized MailCPU frame bytes are local measurements only; no internet latency, energy or total TLS ciphertext claims follow.
- The coordinator's information-flow policy does not cryptographically conceal the private phase from the test runner administrator.
- GitHub's main branch is not branch-protected; the attestations establish only GitHub workflow provenance.
