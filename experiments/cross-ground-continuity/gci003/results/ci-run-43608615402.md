## Phase-blind input separation

The receiver-owned phase holder samples one of eight valid logical phases
using pinned E-CPU law navigation, records the complete held state in a
separate private artifact, and exports a public threshold and salted
commitment. The planner **does not download** the private artifact. It
must choose a plan from the four candidate states still compatible with
the current threshold. The controlled receiver later checks and returns
only its plan-authorized feature values. The blind resolver likewise
**does not download** the private artifact. Only the independent auditor
receives the original phase, allowing it to compare realized values and
declared measurements to their actual mathematical witness.

The information-flow separation is enforced by the declared workflow
inputs, with explicit file-absence assertions in blind jobs. It does
**not** claim secure hardware isolation, cryptographic secrecy from the
GitHub provider or artifact readers, or independent administrative
authorities. The phase and observed properties are mathematical states,
not live physical sensor readings.
