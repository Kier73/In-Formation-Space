# CLT-014 — Exact arithmetic over hierarchical selector Grounds

Stacked on CLT-013 (PR #388, commit b032a3886a04c27d2fb8554aab974f5a2499f1a9). Export its existing fixture/compiler/decoder through an optional API mode; original CLI unchanged. Evaluate exact byte range sums directly on decoded selector blocks without expanding their model records. Literal blocks use a flat index. The finite source campaign actually invokes CLT-013's formation and decode on its 60 original objects, then compares 128 ranges per object with independently accumulated raw-byte prefix sums.

For each slot with positive integer length n(t)=a+dt and coefficients v(t)=v+et mod 256, a ramp has local byte period 256, a periodic leaf has its payload length m. Let L=lcm(m/gcd(m,d), 256/gcd(256,e_i) for every payload coordinate i). For t=r+Lq the local pattern and length remainder modulo m are fixed; full leaf sum is A_r+q D_r with D_r=(dL/m)*sum(pattern_r). Compile prefix tables over at most L residues, truncating to the admitted count if smaller. For T=LQ+R the sum of the first T leaves is Q sum(A)+Q(Q-1)/2 sum(D)+prefixA(R)+Q prefixD(R). Signed d supported while all lengths are positive and periodic payloads fit. Sum slots, binary search the quadratic cycle geometry for endpoint, then compute at most p partial slot sums. No model records materialized; big integer arithmetic, not constant bit complexity. Setup and query counts separate. Each partial evaluates a bounded local pattern, not each byte. Tables and literal index have real memory cost, not included in CLT-013 wire.

The large fixture is a separately declared mathematical source, with 10^12+39 cycles, three slots, length slopes 3,2,1 and varying byte parameters. It is not extrapolated from the finite CLT-013 data or represented by the 64 KiB HSG1 wire. An independent arithmetic oracle uses a deliberately nonminimal residue stride and first/last leaf sums to verify interior and boundary prefixes, plus total. This is an independent implementation of the same mathematical decomposition, not a trillion-step raw replay. Shrinking and short-period cases checked against expanded bytes; invalid lengths and overlarge count refused. No native VLM/C/E-CPU runtime claim. No empirical speedup claim, and flat indexed ranges have O(1) prefix lookup after their own setup. Full bit complexity, memory bytes, authentication and generalized nonlinear lengths not measured.

Reproduce: node experiments/selector_arithmetic/clt014.js. CI also reproduces unchanged CLT-013 results. Next: compile weighted aggregates, integrate actual VLM source admission, and compare amortized arithmetic cost to native Composite.total.
