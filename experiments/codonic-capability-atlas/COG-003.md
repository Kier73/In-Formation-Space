## Why this experiment is different

COG-001 compiles any known invertible affine map in \(\operatorname{AGL}(2,257)\) into four or five algebraic region operations. Its capacity of 287,011,307,126,784 maps is a count of genuinely different finite-state functions, not empty addresses.

COG-002 learns which **registered** capability and which **predefined feature** to use from observations. Its 27-policy initial class does not discover novel transformation parameters.

**COG-003 asks:** Can the system infer an affine transformation *not present in the registry* from geometry-guided observations, admit a new Ground with reconstructible evidence, then hand it to COG-002 so its contextual arbiter can reuse it?

Yes, for the explicit family of **invertible 2D affine maps over F257**, conditional on the target actually belonging to this family.

## Exact structural identification

Given observations \(y_i=A x_i+b\) in \(F_p^2\), an affine transformation has six coefficients. Three observations at affinely independent input positions have rank three in the augmented coordinates \((x_i,y_i,1)\). An exact finite-field linear solve reconstructs the candidate \(A,b\).

COG-003's selector measures the rank of the actual **coordinate geometry**. It preferentially requests points that increase the observation span. After the basis is full rank, it chooses a geometrically distant challenge point to test that candidate. This is **not** enumeration of the 287-trillion-map space.

- A rank-deficient witness set is marked **underdetermined**, with no invented map.
- A singular inferred \(A\) cannot be registered in the existing invertible atlas.
- A fourth observation disagreeing with the candidate rejects the proposed affine Ground.
- The original \`compile_regions\` reconstructs each newly inferred map and retains its exact COG-001 address.
- A seed-labelled hash does not substitute for the geometry, algorithm proof, or source authenticity.

**Critical logical qualification:** Three independent input/output pairs uniquely determine a map *assuming affine behavior*. A fourth consistent pair is an independent falsification opportunity, **not a universal proof** that arbitrary unseen external inputs obey an affine law. Source-model admission and external observer authentication require independent evidence.

## Measured local result

Deterministic source: \`python experiments/codonic-capability-atlas/run_discovery.py\`.

100 seeded trials, each with two previously unregistered invertible maps (one for each supplied context tag). The acquisition pool has **60 points on an affine line** and four other points; four input/output observations per context are allowed. This makes a geometric rank test informative.

| Same four-observation budget per context | Both unknown maps identified and recompiled |
| --- | ---: |
| Rank-directed acquisition | **100/100 trials** |
| Uniform random acquisition | **4/100 trials** |

Each successful trial also verifies 100 held-out exact mathematical input/output pairs (50 per context). That is 10,000 unseen sample comparisons in the active cases, all exact. The trial generators are **known to lie in the admitted affine family**; the experiment does not evaluate arbitrary algorithms or noisy observations.

### Hierarchical transfer back into COG-002

A second seeded task uses two COG-003-discovered maps as the zero/one branches of a previously known **parity-sum** predicate. The system hands its expanded five-capability Atlas to COG-002's unmodified \`VersionSpace\`:

- 12 active task observations to infer which feature/branch combination is needed.
- Discovered exact policy: \`parity-sum → learned_left / learned_right\`.
- **300/300** held-out contextual output comparisons exact.

Thus **law discovery → Ground registration → existing contextual arbitration** works without a new inference runtime.

## Portable evidence, provenance, and refusals

\`structural_discovery.py\` persists a schema-tagged, hash-chained observation stream, the independent registry root, two context labels, the exact generated affine maps, coordinates, and basis/challenge indices. \`restore\` regenerates the same learned Grounds from first principles, checks each predecessor and digest, and refuses stale externally supplied roots. Tests include changed, reordered, truncated, rehashed, or recontextualized evidence.

**SHA-256 binds contents, not the authenticity of a claimed source.** The independent expected head and fingerprint must come from a receiving authority (future integration with existing E-CPU M3/Hypervisor). The cached learned model is a falsifiable, sample-consistent **candidate Ground**, not an externally proven universal law.

## The next meaningful frontier

1. **Discover operational *types***, not merely unknown coefficients of a predefined affine class: use VGI's partial Grounds / equivalence classes to choose candidate algebraic families, search for counterexamples, and refuse when no family is supported.
2. **Separate external teacher from model predictor.** Qualify source observations over E-CPU's authenticated communication paths and retain receiver-owned provenance.
3. Move learned Grounds through an actual durable E-CPU session and switch observer-hosts without replaying source measurements. Use M3 quorum lineage, not a new state-recovery ledger.
4. Evaluate noisy and changed environments and genuinely out-of-family tasks. Compare feature acquisition, retained state size, representational diversity, task value, and realized communication cost.

The research goal is a **persistent, mappable geometry of verified capabilities**, not a giant pseudorandom address set or the assertion that arbitrary computation is free.
