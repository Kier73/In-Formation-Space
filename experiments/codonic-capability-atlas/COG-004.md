**Date:** 2026-11-16. **Research scope:** mathematical exact experiment; no attested external observer-host execution. **Repository:** In-Formation-Space `experiments/codonic-capability-atlas/`. This experiment extends COG-001→002→003 and remains stacked until native tests are verified.

## The genuinely new capability region

One new, explicit, algebraically invertible nonlinear family:

```
F(x,y) = A (x, y + q*x^2) + b   mod p,  q != 0, det(A) != 0.
```

The old affine family is `F(x,y)=A(x,y)+b`. Both have infinite task-relative descriptions in terms of their input coordinates but finite, exactly checkable parameterization on the admitted `F_p^2` domains. This is *not* a new learned neural expert or an enumeration of all functions. It is a new functional class extending the strictly affine COG-001 atlas.

A 4-feature monomial embedding `(1,x,y,x²)` gives two exact output polynomials. If the `x²` coefficients vanish, delegate to COG-003's affine solver. Otherwise admit a shear only if those coefficients are **one common nonzero multiple** of the `y`-column of an invertible affine transform. This checks that the result belongs to exactly the declared nonlinear family. Other quadratic maps and noninvertible maps are refused. The candidate must have four independent monomial probes and at least one additional unfit challenge. Those challenges may refute, but do not establish a law beyond the admitted two-family class.

For a `ShearGround`, the runtime executes one true nonlinear `quadratic-shear` step before the *existing* COG-001 compiled affine path, and verifies a separate closed-form inverse. No distant-time shortcut is claimed for a state-dependent arbiter.

## Acquisition and persistence

The selector maximizes the rank increase of monomial features and uses the existing COG-003 augmented affine rank for ties. After rank 4, further observations are explicit independent challenges. Its only source of observations is COG-003 `EvidenceAtlas`. The typed catalogue is reconstructed from that witness stream; an external receiver must independently pin the witness head and atlas fingerprint. Hash digests prove content integrity relative to those pins, **not source authentication**. No new source-of-truth state is introduced.

`MixedFamilyAtlas` exposes the read-only `.choices`, `.by_name`, `.p`, `.fingerprint` and `.point` subset expected by COG-002's `VersionSpace`, preserving its full active learning and witness rebuilding. Because the old `Policy.certificate` method assumes affine-only operators, the mixed adapter provides a separate typed certificate that explicitly distinguishes the nonlinear step. This is an experimental adapter, not a claim that the earlier COG-002 `Atlas` itself has gained nonlinear semantics.

## Local exact evidence

```sh
python -m unittest discover -s experiments/codonic-capability-atlas -p 'test_*.py' -v
python experiments/codonic-capability-atlas/run_family_discovery.py
```

Across 100 seeded synthetic tasks with two independently selected unknown family capabilities and six observations each, active geometric query selection recovered both models **100/100**, while six random queries per context recovered both **19/100**. The pool intentionally concentrates 90 points on one line with seven out-of-line alternatives; the 100-versus-19 result is a **controlled identifiability** experiment, not natural-task generalization. The active models matched **10,000/10,000** sampled held-out source outputs. After discovery, COG-002's existing `VersionSpace` recovered `parity-sum` arbitration between affine and nonlinear models from 12 contextual examples, matching **500/500** held-out outputs.

Local repository-scale run (all COG-001 to 004 tests): **36 tests, 33 passed, 3 skipped** due to missing native VGI package. The new tests additionally enumerate all 25 points of F_5² for both family types, independently check inverse reconstruction, prove the three-probe affine-interpolant trap, and refuse cubic/non-shear observations, inadequate rank/challenges and mismatched source pins.

The dedicated CI workflow installs a pinned real VGI package on Python 3.11/3.13 and requires native imports. Native CI results are a **separate gate** and should not be asserted before checking the exact HEAD.

## What has and has not been learned

**Established:** the atlas can discover which of two independently typed generative families explains witnessed behavior, admit a new nonlinear realization family, and reuse its existing arbiter and evidence ledger to select it. This is real growth of *functional diversity*, not an increase in meaningless expert IDs.

**Not established:** universal family discovery, independent real-world oracle reliability, arbitrary nonlinear law proof from finite samples, general intelligence, native VGI nonlinear execution, E-CPU mTLS/Hypervisor realization, crash recovery, or hardware-independent physical execution.
