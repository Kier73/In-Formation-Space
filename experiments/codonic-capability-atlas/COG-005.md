## The precise new computational class

For a prime p=257, let AGL(2,p) denote the invertible 2D affine group. A capability at order D is

    F_(A,P)(x,y) = A(x, y + P(x)) + b,   P(x)=c2*x^2+...+cD*x^D,

with 2<=D<=32, coefficients in Fp, and invertible 2x2 A. The canonical polynomial has zero degree-0/1 coefficients, absorbed into affine A,b. Each function has exact inverse: undo A,b, then subtract P(x). There are

    |AGL(2,257)| * 257^(D-1)

**different mathematical functions**, not different symbolic aliases, because the difference F(x,y+1)-F(x,y) identifies the y-column of A, the linear coefficient in x identifies its x-column, and the remaining coefficients of polynomials degree <=32<257 are unique as functions of x. At D=32 there are **146496021316068964177697100939654664509940756846263280047895395372636291706111470799552512** functions (297-bit address space). This is an exact combinatorial count, not an observed AI-quality measurement.

`encode_capability` and `decode_capability` are inverse over the complete admitted function space, generalizing COG-001's affine rank/unrank. A **2^48-element indexed subset** maps each expert ID into a disjoint interval of this complete function-address space, using SHA256 only to choose the position *within* its interval. This is injective by construction: any two expert IDs map to different function addresses and therefore different functions. It does not rely on SHA collision assumptions for uniqueness. High-order coefficients vary because the chosen intervals span the full function-address range, unlike the repeating `%17` VP-005 synthetic template.

The router uses a certified modular affine orbit center at logical time `2^56+73`, with at most 63 binary-jump iterations, then materializes exactly eight selected functions. Each observed output is the exact finite-field mean of eight vectors; finite-field averaging is **not** a pretrained neural MoE, learned router, or usual real-valued expectation. The independent output checker evaluates powers by a different algorithm than the forward Horner evaluation.

## Discover, do not assume known coefficients or degree

A feature row `(1,x,y,x^2,...,x^D)` is measured for each observation. The incremental finite-field basis planner chooses probes that add algebraic rank, not probes with a known label. With D+2 independent observations and >=2 unfit challenges, exact field elimination uniquely identifies a polynomial of degree <=D. A typed shear-consistency condition requires **every output's nonlinear coefficients to be collinear with the affine y-column**; otherwise the law is rejected. The reconstructed candidate is validated on *all* observed points. An affine discovery independently calls COG-003; the degree-two case independently calls COG-004. The evidence ledger is COG-003's original `EvidenceAtlas`, including exact replay with receiver-provided high-water pins.

These are **hypotheses conditional on the admitted degree<=D grammar**, not a proof about arbitrary unseen external processes. If the source is of degree 33, if the outputs contradict the shear structure, or if the available observations do not span the basis, the admission must fail (or remain unknown), never synthesize a familiar answer.

## Native E-CPU observer path, exact evidence gates

`native_atlas_observer.py` defines a strictly bound typed plan: an exactly sourced polynomial Ground learned from 37 observations; a distant logical-time selected frontier of eight functions; a receiver-fixed model/atlas fingerprint; and a request ID. Its original COG-003 source-witness stream is reconstructed and checked independently by the receiver. The GitHub workflow runs three **different ephemeral runner jobs**:

1. Planner: writes source Ground/claim and exports expected source high-water through a separate job-output channel.
2. Realizer: installs pinned **real E-CPU** and **VP-003 NativeInferenceHost** sources, revalidates both pins, executes the requested function through the native Hypervisor/VirtualLayer operator ledger, and verifies that exact replay does not re-execute the operation. It also tests that removing compute authority denies the operation before the handler runs.
3. Independent verifier: recovers the plan/report from a GitHub workflow artifact, receives expected source head/fingerprint from the planner job's separate output, independently derives the function Ground, recomputes eight exact outputs with a different polynomial evaluator, and refuses rehashed tampering and stale source identities. It does **not** claim to cryptographically attest the GitHub runner's honest behavior.

These integrations remain **unverified until the exact-head CI is green**. GitHub artifacts are observed inter-job communication and retention, but not physical computation by a passive TCP/TLS fiber. The native Hypervisor is an existing authority for local execution, not proof of an externally signed quorum; no E-CPU M3 session checkpoint/recoverable authority is implemented here. Neither SHA hashes nor self-pinned evidence authenticate an untrusted external source.
