# COG-007 — Learn the distinctions necessary for future computation

## Objective and continuity

COG-001–005 developed addressable algebraic capacity; COG-006 learned a small typed relation-composition program and retained evidence-bound conversational reference. COG-007 asks whether an observer can **learn the organization of predictive memory itself**, from future behavior, instead of retaining every history or naively erasing the history.

Before implementation, we examined the existing In-Formation-Space [Observation Equivalence bridge](../../bridges/observation-equivalence/README.md), its real `transition_congruence.py` refiner, RIV-001–004 task-relative memory, and the COG-006 state/evidence interpreter. The new implementation does **not** duplicate the finite-congruence refiner. Hosted CI imports that existing module and compares its exact quotient with the learned machine's number of states. VGI's typed observations and E-CPU's authenticated session/Hypervisor/recovery lineage remain separate authorities; no replacement layer is introduced here.

The external PyBot architecture was inspected at `huggingface/pybot`, pinned source commit `7d63c7fbebb44c7e466e5c8b5c1f341ab767929e`. The concept of shared `observe`, independent proposal, arbiter and commit informs this experiment. A **separate optional hosted job** now collects real PyBot conversations as source-pinned evidence; such evidence is not claimed equivalent to this synthetic machine.

## Core mechanism: behavioral indistinguishability

Let histories `h1` and `h2` be behaviorally equivalent relative to a permitted action alphabet `A` and future observable response contract `O` if **every finite continuation `z` over A** produces the same projected output sequence after `h1` and `h2`. This is a Mealy-machine observation quotient. It is not merely agreement on the *next* answer; a later `repeat` can expose a difference that a direct `minutes` request hides.

The source is COG-006's **actual `Session.perform` interpreter** and its learned `steps → sum` capability. A finite symbolic alphabet has `mention:<subject>`, `minutes`, `seconds`, `repeat`, `clear`, `noise`, and optionally `who`. The additional `repeat` is a small reference-to-last-answer presentation operation in the *observer adapter*, not a new PyBot operation. The source is entirely synthetic: topic names, durations and knowledge are supplied by the fixture.

The active learner sees only black-box query/answer traces; it does not receive the source-state representation. It builds an observation table of past prefixes and future distinguishing suffixes. Closure and consistency reveal new states; an independent conformance oracle finds the shortest counterexample to a candidate machine. The counterexample's suffixes refine future observations. In this bounded protocol, each admitted state corresponds to a distinguishable future behavior class.

## Exactness: independence and scope

A separate source evaluator computes a reachable-state × learned-state product by breadth-first search. A mismatched output yields a concrete shortest counterexample; completing the product without mismatch establishes exact behavioral equivalence for **this supplied closed finite source and complete action alphabet**. All learned states are required reachable and pairwise distinguishable before publishing a minimality claim. This is stronger than finite random test agreement but not a proof about a larger or unknown world.

A receiver reconstructs the machine from serialized tables with an **externally supplied head pin** and independently checks all reachable transitions. It does not re-run active learning or the original COG-006 `Session.perform` training calls to restore the model. A separate runner can resume from a retained state ID. The current CI jobs share GitHub infrastructure and do not provide a physically independent E-CPU quorum, TLS authentication, or effectful recovery guarantee.

## Demonstration and negative controls

The finite source contains many named records whose durations are behaviorally identical. When only future duration/repetition matters, subject names are not observable and can legitimately be merged. If the contract additionally includes `who`, the named identities must be kept. This is **task-relative** memory; neither always preserving identity nor always merging it is universally correct.

The reference's reachable state count for `N` subjects is `1+3N` (no referent plus subject × {no last unit, last minutes, last seconds}). The minimal answer-only quotient is `1+3K`, where `K` is the number of behaviorally distinct durations. With `N=512`, `K=8`, this is **1,537 → 25** states, a 61.48× state-count compression. This counts semantic states, not bytes or physical memory usage.

The test suite covers missing future distinctions, held-out continuations, source substitution, contract expansion, tampered/rehashed receipts, stale external head pins, unreachable states, and fresh-process continuation. It includes a native repository-refiner integration check (must run on GitHub). The source facts, predicate grammar and action alphabet are supplied, and the learner uses full finite equivalence queries. Its cost grows with the source alphabet and conformance product; this is **not** a sublinear discovery algorithm.

## Next genuine advance

Apply the same learner to **real source behavior** with a partial observation contract and explicit unknown outcomes; move beyond a supplied finite hidden-state reference. On a failed equivalence query, request a new counterexample from independent observers, not a synthetic omniscient source. Next integrate admitted typed state and structural evidence with existing E-CPU `RecoveryLineage` and mutually authenticated `ReliableChannel`, then test failure and rebinding. Compare useful capability acquisition and trusted information cost instead of maximizing symbolic address cardinality.

No unrestricted cognition, benchmark parity with PyBot, trained neural inference, or operation outside a physical computation substrate is claimed.
