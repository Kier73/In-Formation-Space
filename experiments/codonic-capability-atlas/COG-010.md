# COG-010 — Intention-conditioned transit navigation of an acquired cognitive Ground

**Status:** actual local multi-process experiment and cross-process verification. Native E-CPU IOS-001/002/003 mTLS test has been implemented and queued as a separate GitHub gate, not represented as locally completed.

## Research question

Can a cognitive state-space **already acquired through COG-006→009** be navigated from an intention so that the receiver resolves an observation immediately, requests only the information necessary to distinguish remaining possibilities, or refuses to claim an answer—and can it directly navigate a far-away logical state without executing every intermediate transition?

This is a direct consequence of E-CPU's [Computational State-Space Architecture](https://github.com/Kier73/E-CPU/blob/main/docs/COMPUTATIONAL_STATE_SPACE_ARCHITECTURE.md), [State-Space Navigation](https://github.com/Kier73/E-CPU/blob/main/docs/STATE_SPACE_NAVIGATION.md), [Intention-relative Observation Sufficiency IOS-001](https://github.com/Kier73/E-CPU/blob/main/docs/INTENTION_RELATIVE_OBSERVATION_SUFFICIENCY.md), [IOS-002 Observer Bridge](https://github.com/Kier73/E-CPU/blob/main/docs/INTENTION_OBSERVER_BRIDGE.md), [IOS-003 mTLS Measurement](https://github.com/Kier73/E-CPU/blob/main/docs/INTENTION_MEASUREMENT_FABRIC.md), and [Contextual Orbit Fabric](https://github.com/Kier73/E-CPU/blob/main/docs/CONTEXTUAL_ORBIT_FABRIC.md). It does not equate possible mathematical states with pre-computed physical outputs or with quantum superposition.

## Acquired cognitive Ground as the state-space

For an already learned `Machine`, each state has a declared reply for actions `minutes`, `seconds`, `repeat`, and a task-relative public projection `anchored`/`empty`. A `CognitiveProjection` binds the machine's exact source root and model fingerprint, the public observation, the requested *intention*, and the available feature catalogue. E-CPU's native IOS-001 model is made from those exact 7 or 25 states. It contains no hidden source topic identifying which state is current.

Tested intentions:

1. **READY:** `has_anchor`, given public `anchored`. Every possible anchored state has the same target `true`. Zero new observer queries are warranted.
2. **MEASURE:** `seconds`, given public `anchored`. Several durations remain possible. The receiver selects the lower-cost **`minutes` feature only**; a qualified observer returns a signed minute reading, while the admitted cognitive Ground determines the requested seconds result by structural composition. This is different from simply requesting the target itself.
3. **REFUSE:** `repeat`, given public `anchored` and only the `minutes` feature. Different predictive states can produce distinct repeat answers despite identical minutes. IOS-001 refuses and preserves the unresolved distinction without reading a host.

During the COG-009 stdio experiment, a missing honest worker leaves the surviving honest/faulty sources in disagreement, and the measured request remains `unknown`. Replacing the worker provides a genuinely different process boot and one additional agreeing signed observation; a repeated query reuses the retained accepted result with zero new host messages.

**Important:** The COG-009 worker interface uses authenticated Ed25519 signed replies over local stdio, not native mTLS. The signed observer adapter does not privately recompute the hidden state before accepting a host report. Signatures prove the enrolled keys reported that value; colluding source lies remain possible. `resolve_sufficiency` additionally checks the *model*, not real-world honesty. Its `receipt_digest` argument is a correlation digest, not a native IOS-002 attestation. The native test uses real IOS-003 independently and does not mistake the two mechanisms for the same evidence tier.

## Direct logical-time navigation

`FiniteCognitiveOrbit` forms an explicit deterministic finite product of *(learned Mealy state, recurring program phase)*. It explores each **reachable** product state once, detects the first repeated state and records the preperiod `mu` and cycle length `lambda`. It independently validates every reachable successor arc and the closing cycle edge. Its immutable Ground digest covers the actual learned source fingerprint, program, reachable states, cycle, and initial state.

The addressed observation at `t=10^30+11` needs no preceding `10^30` turns. A locally verified repeated ten-action program forms a **ten-state periodic orbit** (`mu=0`, `lambda=10`). The single distant state can be calculated from the finite orbit index. The native gate also calls **E-CPU's real `Law('fgraph')` / `navigate_guarded`** and compares results with the independent orbit constructor. This is navigation over an exactly known *finite synthetic* machine, not a universal solver for arbitrary incomplete state-spaces or literal physical work happening without a realizer.

## Local direct evidence

`run_intention_transit.py` separately invokes signed worker preparation, actual fault/rehome, the intention gateway and a **fresh Python interpreter** that checks every original COG-009 Ed25519 witness and every new signed observer receipt against public keys and externally supplied high-water pins. No observer private keys or new host calls are required by that receiver. Source acquisition costs are separate from resolved-intention costs.

## What it establishes and what it does not

**Established locally:** task-relative `READY/MEASURE/REFUSE` over an acquired predictive cognitive Ground with a reproducible source ledger; signed host disagreement and replacement; repeated result reuse; exact finite-orbit addressing at huge logical coordinates; and source-free reconstruction in a new process. No claim that all possible conversation states exist physically, that 10^30 operations were executed by the network, or that the mathematical algebra alone revealed unknown real-world facts.

**Native verification outstanding:** real E-CPU IOS-001 and IOS-003 mTLS/`ReliableChannel` contracts integrated with the learned cognitive Ground must pass exact-head hosted CI. This is not a demonstration of untrusted public-network compute, physical passive-path arithmetic, E-CPU Hypervisor authority for arbitrary operators, independent M3 recovery quorum, or neural language-model inference.

**Next step:** first establish the full hosted mTLS gate, then explicitly bind the COG-009 signed source Ground's version/evidence high-water to E-CPU M3/`RecoveryLineageCoordinator` and repeat the receiver death/rehome between *measured-but-not-yet-committed* and *acknowledged* states. Only then promote the signed-stdio provenance into a qualified network realization class, and keep independent external audit pins.
