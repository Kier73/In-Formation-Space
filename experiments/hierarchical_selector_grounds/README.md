# CLT-013 — Hierarchical selector Grounds

VLM-009 (IFS PR #383, pinned commit 1109f58989af91aca58289d27a8363687c344d9a) learns literal vocabularies and equal-length byte templates. CLT-012 discovers local interpretations via mismatch boundaries. This experiment treats the ordered sequence of already formed local Ground descriptors as the source of a new mathematical law. It takes local record boundaries and kinds as supplied input; it does not repeat CLT-012 raw-byte segmentation or claim those boundaries can be discovered for arbitrary bytes. The synthetic record generator produces 60 framed byte environments (12 per family, seeded). The source bytes are constructed from the original local records before selector discovery.

For a proposed period p, infer each slot j's length n_j(t)=n_j(0)+d_j*t and each payload coefficient v_j(t)=v_j(0)+e_j*t modulo 256, from two initial cycles. Check every subsequent original record, requiring at least three complete matching cycles. A failed candidate yields its first differing record; retain only a complete qualified prefix, and retry on the suffix. Search p=1..8 and choose longest profitable prefix, breaking ties by descriptor size. Bound model blocks to six, then literal suffix; if no useful prefix exists, retain literal remainder. This is a greedy bounded grammar, not optimal segmentation; a discrepancy inside a cycle may leave a partial cycle at the next boundary. Compare exact constant-cycle-only grammar, VLG1-equivalent flat size (12-byte header, five-byte leaf headers, actual payload), and a hypothetical dictionary size (12-byte header, two-byte IDs per record, one stored copy of each distinct leaf; not serialized). Use actual HSG1 binary bytes for the candidate, fall back to VLG1 when no smaller. All stored extents bounded by 65536 bytes. HSG1 is experimental, not an existing native wire protocol.

A model block's cycle prefix is P(t)=sum_j(n_j*t+d_j*t*(t-1)/2). Since admitted lengths are positive, locate an absolute byte by binary search over cycle coordinates, then at most p local lengths. No per-leaf offset index needed for model blocks; this implementation sums slot lengths during each search probe and scans literal blocks, not a general O(log n) runtime guarantee across all representations. The query fixture evaluates 128 coordinates per object, including endpoints. Flat VLG1 has its own binary-search offset index and may be faster in practice. This experiment does not implement a closed-form range sum over varying model cycles; the native adapter expands descriptors and uses existing Composite.total as an independent control.

Decode the actual wire with extent, tag, payload, and truncation checks; compare every decoded byte with original fixture bytes and every tested coordinate. Check constant-only and adaptive candidates even if they lose to the flat route. Tampered selected HSG1 wires must fail decoding or source comparison. No cryptographic source authentication in JS; native replay separately uses original VLM SHA-256 certification. Byte counts exclude source identity, transient storage, input record acquisition, audit costs, and model runtime/index overhead. Candidate record reads/checks separately metered; no physical I/O or speedup claim. A prefix fitted to current records never authorizes extrapolation past the certified extent.
