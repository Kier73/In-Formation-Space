## Observed outcomes

All four *semantic-source* transfers used a different Python process to
receive an actual E-CPU ReliableChannel stream over mutually authenticated
TLSv1.3 on localhost. Each receiver constructed a fresh rational ReLU
network and checked the complete mathematical semantics independently.
Each *parameter baseline* transmitted the generated COE-002 certificate
and independently verified it without reconstructing weights. Source and
parameter modes agreed on the **exact generated-network SHA-256** for
every case, not just output values at finite probes.

**What these observations establish**

- The receiver can construct the complete executable neural parameter
  description *after* the source mathematical function travels over the
  E-CPU communication channel. The sender's semantic transfer contains
  no neural weights or COE certificate.
- The source description used **roughly 27–40%** of the application bytes
  of the matched parameter-plus-proof certificate for these four
  examples. That is a relative reduction of **60–73%**.
- Four out of four receiver-owned source pins and independently verified
  model-identity comparisons passed. The receiver did not treat channel
  ACKs or sender-owned hashes as semantic proof authority.
- Measured local neural compilation cost was below 8 ms in each case.
  This is an observation on these four test functions, not a general
  complexity or hardware performance result.
- No reliable end-to-end latency advantage has been established: these
  same-host runs take approximately one second, dominated by fresh
  process setup and handshake, and may be slower for source reconstruction.
  Sender and receiver monotonic clocks were kept distinct.

## Boundaries and comparison fairness

The parameter reference is **canonical JSON carrying full explicit
weights and a COE-002 proof certificate**. Comparing source against
unverified binary tensor arrays would yield a different ratio, and
TCP/TLS packet overhead has not been measured. This experiment confirms
*source-only reconstructability and verifiability*, not universal
compression or speed.

The TLS issuer is an ephemeral local test CA. Sender and receiver are
different processes on the same GitHub runner; they are not separate
physical machines. The trusted source hash is supplied by the test
coordinator using the original mathematical description, not the wire.
No independent external source authentication, Lean kernel replay,
VGI Ground admission, stateful E-CPU VM effect, or GPU execution occurred.
