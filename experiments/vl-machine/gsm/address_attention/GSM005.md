# GSM-005 — Witness-directed interaction Grounds

Continue GSM-003 and GSM-004. Move beyond independent address dimensions: pairwise interactions in both keys and values, exact ordinary softmax via variable elimination, and acquisition of source witnesses chosen according to competing representations. This is a constructed numerical experiment, not a pretrained Transformer conversion or E-CPU transport test.

## Mathematical Ground

Four radix-R address digits. Each unary table and pair table contains a key contribution k_f and an additive value contribution v_f. Let s_f=q dot k_f/sqrt(d_k), K(a)=sum_f k_f(a_f), V(a)=sum_f v_f(a_f). Each local factor is (z,m)=(exp(s_f),exp(s_f)v_f). Combine factors by

    (z,m) * (w,n) = (zw, mw+zn).

Sum over eliminated coordinates componentwise. Distributivity and the product rule for additive value contributions prove that the final pair is (sum_a exp(sum_f s_f), sum_a exp(sum_f s_f)V(a)). Divide m/z. Factor score maxima are removed locally; add their shifts back to rectangle log masses, combine disjoint causal prefix rectangles with stable normalized weights. This preserves the real-arithmetic exponential normalization, not a linear kernel or approximate attention pruning. Floating numerical behavior is tested at finite moderate scores; no bound near underflow or overflow.

Enumerate all 24 elimination orders to minimize total combined-scope cells, with peak cells as a secondary objective. Four variables allow a complete schedule search. The cell count is a structural work proxy, not operation count or measured memory. Chain width one uses R^2-sized largest scope; cycle width two uses R^3; full clique uses R^4. Dense interactions can erase the computational reduction. Generalize to arbitrary graphs only with explicit cost/width analysis. Pair-factor values are additive, not GSM-003's multiplicative term; the model is a different qualified family. No private overrides, training gradient, source digest admission API or revision authority added here.

## Source witness acquisition

For discovery only, use radix 4, 256 addresses and eight scalar channels (four key/four value). Seven candidate structures: additive (13 coefficients/channel), or additive plus one of six pair interactions (22 coefficients/channel). Unknown integer coefficients are generated in [-4,4]; integer rounding is only performed on that declared source family. Candidate fitting uses acquired rows, least squares and singular value nullspaces. Candidates within 1e-8 of best observed max residual remain live. Adaptive selection scores each available coordinate by normalized between-candidate prediction variance plus mean unresolved nullspace leverage. The rank baseline chooses by nullspace leverage across all seven candidates, independent of values (implementation still computes fits); random baseline uses uniform unobserved coordinates. All routes start with identical 12 observations and choose only from a fixed 192-address pool. Remaining 64 rows are disjoint for held-out scoring. Exact admission separately compares all 256 rows; this is not an independent host or sublinear verification. Refused cases retain source representation; no fallback runtime or residual encoding added.

21 structured sources (three instances per family) and seven random Gaussian negative controls, each seed-fixed. Final campaign budget 32. All three routes refuse the seven negative controls, while adaptive and rank recover 21/21, random 6/21. Separate budget sweep on the same 21 structured cases:

These are paired, designed synthetic cases, not independent unseen task families. The adaptive advantage is small over rank; at 20–22 observations adaptive and rank also have worse mean held-out MSE than random because underdetermined coefficients are unstable. No universal acquisition superiority. At 32 observations median search costs on structured sources were 25.203 ms adaptive, 22.212 ms rank, 22.266 ms random. Full-source verification remains extra; no total speedup claimed for discovery. All accepted candidates reconstructed original values exactly and contracted softmax matched independent streaming enumeration within 1e-10.
