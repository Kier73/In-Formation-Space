# GSM-004 — adaptive predictive geometry

Discover a useful virtual address geometry from observed key/value rows, rather than imposing the factorization in advance. Connect to VL-I PBG-002 (goal-event surprisal), PBG-004 (evidence-adaptive source-law revisions), and PBG-005 (source-observed predictive construction). These were studied at VL-I revision 9ccd0efa3037da6f5709ffd0865a517a2f3c9a65; no code imported. Unlike the exact rational predictive operators of PBG, geometry proposals here use numerical least squares; independent source reconstruction is the exact admission gate.

For 256 logical addresses, partition eight address bits into four unordered pairs: 105 possibilities. Each pair forms a radix-4 coordinate. Fit a 13-row additive coefficient table (intercept + three nonbaseline categories per axis) on 128 observed rows, iteratively retaining the 90% lowest residual rows for robust fitting. Round coefficients only for declared integer sources. Choose geometry by mean squared reconstruction error on 64 validation rows, then evaluate the frozen choice on 64 separate held-out rows. Fixed prior geometry, refitted on the same new observations, is the comparison. The previous admitted geometry is retained on fallback; this is a full finite search each epoch, not yet adaptive choice of which observations to request or neural continual training.

For 64 independent random queries, compare the attention distributions on the held-out subset by KL(P||Q) and exp(KL), the geometric excess cross-entropy perplexity ratio. This ratio is one for identical distributions; it is not conventional language-model token perplexity or PBG's goal-event inverse probability. Also record value-output MSE. Neither metric authorizes exact reconstruction.

Independent qualification observes the full 256-row source, retains all numerically unequal rows as exact overrides, compares modeled binary representation payload (float64 coefficients + eight geometry bytes + four-byte addresses and dense float64 override rows) with the original 32768 bytes, and falls back to dense if not smaller. Reconstruct and check the receiver-pinned source digest before using an admitted record. Compact_query consumes a locally trusted, already-checked record, not untrusted wire data. It translates the geometry and overrides into GSM-003's actual factorized softmax operator, compares with the full dense source on 64 queries. Its construction currently computes the small address mapping explicitly; this is not a scalable 24-bit geometry discovery implementation. Full-population attention only: permutations need a separate causal membership law before ordered prefixes can be inferred. Payload is modeled rather than serialized JSON size, and excludes metadata, search and temporary memory.

## Local evidence

Python 3.13.5, NumPy 2.3.5, torch 2.10.0 CPU. Four tests passed (0.157 s). Two constructed integer sources with different hidden bit pairings, second with eight sparse changes; a dense random negative control; and a real trained GSM-001 model's controlled first-head K/V projections. The latter are computed using pinned sensor-1.pt weights, 256 possible payload bytes in a fixed feature context, actual first norm and projection parameters promoted to float64. This is not a pretrained LLM or observed natural language causal KV history.

Both constructed hidden pairings recovered exactly; all 256 source rows reconstructed exactly after qualification, compact attention maximum absolute error 8.882e-15 on each. Both negative controls have 256 mismatching rows and refuse compact storage. The trained tensor's validation MSE improves from 0.064416 to 0.061704 but held-out row and distribution metrics worsen; no promotion. Held-out output MSE is a separate metric (trained tensor 0.001730 -> 0.001565). Search ~31–35 ms/source in one run; no end-to-end speedup or sublinear acquisition claim. Initial full table and all 105 candidate designs reside in memory. This is a small source-bound experiment, not learned geometry at 16 million addresses.
