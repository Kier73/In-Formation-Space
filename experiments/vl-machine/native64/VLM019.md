# VLM-019 — learned rewrite scheduling and replayable proofs

Use the six-rule VLM-018 catalogue, independently recertified at every proof replay. Optional --parent verifies the exact retained VLM-018 report and the copied catalogue. Generate 120 training, 120 validation and 240 final programs with distinct identities. Learn rule success frequency in 14 encountered contexts (operator, child operators, equal operands). Compare static root-op dispatch, deterministic syntactic prefilter, and context-frequency ordering after prefilter. The learner only selects ordering; it cannot introduce an unchecked rewrite. Exact compatibility checks are separately counted.

Proof format: source identity, target identity, rule catalogue digest and ordered source-node positions with applied rule indices. Independent replay reconstructs the live source DAG, validates all rule identities via universal bit certificates, checks each substitution using an independent iterative matcher and checks the reconstructed target identity. No requirement that a supplied trace exhaust all possible rewrites. Proofs establish source/target equivalence in the bounded pure word32 language, not authentication, optimization optimality or correctness outside this domain. Replayed graphs are then checked by the bounded polynomial source inspector. Tamper tests reject wrong identities, wrong rule applications, duplicated positions, noninteger rules and missing events when target identity changes.
