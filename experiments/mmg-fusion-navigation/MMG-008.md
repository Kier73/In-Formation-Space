# MMG-008 — Relax rank saturation while preserving exponent two

Set a positive constraint: exact AB, arbitrary dense B, A in a hidden permuted direct sum of full 2x2 block algebras, ≤7n²/4 nonscalar products and ≤5n²+5n/2 field operations. The support relation is supplied as pairs of physical positions; discover connected components and admit only complete size-two components. Admit dense A by checking all off-block entries. A contains independent noncommuting 2x2 blocks; B is unrestricted.

Each block multiplies two rows of B, with output columns paired. Apply the seven-product Strassen identity per tile. Share the five left linear forms across all column pairs. The right encoder uses five additions/subtractions per tile, decoder eight. Counts are 7n²/4 products, 13n²/4+5n/2 additions, total 5n²+5n/2. Classical block evaluation uses 2n² products and 3n² total operations, so it is faster by total scalar count but fails this deliberately imposed product cap. This is a constrained multiobjective experiment, not a speed claim. Strict O(n²) total arithmetic is achieved; n² dense source checks and permutation observations are separately charged. Reproduce: node mmg008_block_constraint.js.

A lower bound for the noncommuting space: the identity slice has dimension m=n². For any rank-r bilinear decomposition with invertible normalized identity slice, write normalized slices as C D_A V with CV=I_m and diagonal D_A. Set E=I_r-VC, rank r-m. The commutator equals C(D_B E D_A-D_A E D_B)V and has rank at most 2(r-m). If some rank term vanishes on I, work over a rational function extension and choose a generic slice I+tX on which every nonzero left form is nonzero; apply the bound to normalized slices and specialize t→0 using vanishing minors. This proves r ≥ n²+ceil(n rank([A,D])/2). For independent 2x2 blocks choose A and D as off-diagonal matrix units E12 and E21 in each block: their commutator is diag(1,-1), invertible in every characteristic, so r≥3n²/2. Our upper bound 7n²/4 lies within the exact interval [1.5,1.75] n². This bound is for the declared bilinear model, and the direct-sum upper bound does not presume rank additivity.

Next: replace fixed pairs with growing blocks and use an admission budget with explicit constants. Determine whether alternative representations can avoid growth of the coefficient multiplying n² without restricting A or B. Exact n² rank saturation excludes noncommuting spaces, but fixed slack admits some. Neither result establishes an unrestricted square exponent below 9/4.
