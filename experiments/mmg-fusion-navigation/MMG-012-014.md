# MMG-012–014 — Hot-start, overconstrained ground discovery

## Intention

An incumbent is a certified feasible witness, not a search objective. Keep the unrestricted formal polynomial identity AB=C. The requested aspirational exponent is <2, while the strict improvement gate against the November 24 manuscript is r⁴<n⁹ for an exact fixed square rank-r decomposition. In the standard scalar arithmetic model the n² distinct degree-two output polynomials require n² computed registers; hence exponent <2 is infeasible for explicit unrestricted outputs. The quadratic rank floor is also independently supplied by flattening. Use the impossible intention as a negative control and prioritize anomalous reductions below the verified incumbent; never report a compact descriptor or hardware speedup as a smaller scalar exponent. Separate online realization, search/build, verification and communication.

## MMG-012 — verified public incumbents

Source-pinned published decompositions (GF(2)), from Jakob Moosbauer's [flips repository](https://github.com/jakobmoosbauer/flips/tree/e31a0a0f0d2577cee5da047ca7dcae0c61992e40/solutions), revision e31a0a0f0d2577cee5da047ca7dcae0c61992e40. The exact coefficient data, source paths and blob hashes are in mmg012_seeds.json. Parse all triples, check formal polynomial coefficients in output convention (try transpose of third leg only if required by source convention), reject a deliberately changed term. Seeds: 4×4 rank 47 (strict improvement target 22), 5×5 rank 95 (strict target 37). These are known constructions, not new bounds. An October 2026 preprint [arXiv:2610.11823](https://arxiv.org/abs/2610.11823) reports rank 23 exact for 3×3 over GF(2); do not spend the campaign seeking rank 22 there without specifically testing that theorem.

Choose a free leg a and keep a set of pair atoms v_i=b_i⊗c_i on the other two legs. Let K be their span and S the target slice space. The quotient residual D=(S+K)/K is exact. Remove multiple incumbent atoms, search rank-one projected atoms in D, then solve the complete free-leg coefficients over GF(2). Independently verify each reconstructed full tensor. One atom can be replaced by a different exact representative; allow equal-rank exploration but preserve the best incumbent. Expanded dictionaries include coordinate atoms and randomized XORs, rather than only atoms from the seed. 240 trials, 1,686,039 pair queries, 197 completed repairs, 43 incomplete, 14 completed repairs with novel pair atoms (16 novel atoms counted), max deletion sizes 18 and 27. No rank reduction. This is a bounded dictionary experiment; no infeasibility conclusion for incomplete trials.

## MMG-013 — overclock the target, not the incumbent curve

Any completion with retained independent pair atoms and rank budget R must have dim(K+S)=dim K+dim D ≤R. This is a span-preserving necessary condition; if retained atoms have dependent vectors or may be dropped, the retained-span condition must be interpreted accordingly. For each seed and each of six retention sizes, screen 30 samples. For n=4 retaining 22 atoms gave floors 37–38, not target 22; for n=5 retaining 37 gave floor 62, not target 37. Retaining 6 or 12, respectively, gave the target floor in all samples. These are samples, not a global optimum.

The minimal completion may use atoms outside D. For one extra quotient dimension, group projected rank-one atoms by their nonzero coset modulo D; any two atoms in a class have XOR in D. Choose an anchor, build independent differences, solve all coefficients from the resulting original atoms. A completion costs dim D+1 projected atoms when the inside atoms and differences span D. Synthetic control over GF(2)^2 checks that two atoms outside span(e1) can sum to e1. On the real grounds: 96 large-deletion trials, 1,158,784 pair queries, all showed some nonzero-coset gain, with largest gain 9 and 8 extra residual directions, respectively. No full rank-reducing completion. The test covers one additional outside dimension and a finite sampled dictionary, not all possible rank-one completions.

## MMG-014 — exact retention certificate from an incumbent slice code

For a fixed leg, verify that all r incumbent pair atoms on the other legs are linearly independent. The map from a slice functional x to the vector of its r coefficients is an injective binary linear code C of dimension d=n². In the pair-atom coordinates the target slice space is C. For any retained index set J of size k, its intersection with the target slice space is precisely the shortened code supported in J. Write h=dim(C supported in J). Then the exact completion floor is k+d-h. Equivalently h=d-rank of the free-leg coefficient vectors at the discarded indices, giving a cheap finite-ground screen verified against explicit pair/slice ranks in 1,800 sampled comparisons.

Enumerate every nonzero codeword via Gray code and count Hamming weights. For each possible k, if h-dimensional subcode is supported in k coordinates then 2^h ≤ 1 + number of nonzero codewords of weight ≤ k; also the binary Griesmer bound gives k ≥ sum_{i=0}^{h-1} ceil(d_min/2^i), where d_min is the parent code minimum distance. Both bounds hold for every retained set, regardless of how it was chosen. Thus bound h above and derive a certified upper bound on k under the strict target. The code does not assume that a feasible k actually occurs, and these certificates do not exclude decompositions that replace the retained pair-atom span.

Results for n=4, rank 47, target 22: minimum distances across legs 4,4,5; maximum retained counts bounded by 18,18,8, hence at least 29,29,39 pair atoms respectively must be discarded in a span-preserving repair. For n=5, rank 95, target 37: distances 9,6,5; retained counts bounded by 14,28,23; at least 81,67,72 discarded. Exactly 3*(65535+33554431)=100859898 nonzero codewords enumerated. All three pair-atom spaces verified independent for both seeds. These bounds apply only to these particular fixed source witnesses and chosen legs, not the true minimum tensor rank.

## Next direction

Use the exact target to control retained spans before searching. A seed can supply algebraic invariants, code distances and local translation dictionaries without requiring that a successful new ground share most of its atoms. Build candidates from independently generated structured pair spaces, e.g. symmetry orbit dictionaries, rectangular tensor compositions and coupled coset dimensions, with the same exact coefficient verifier. Maintain a Pareto archive of rank, slice overlap, circuit cost and independent representation novelty, but never call novelty a rank improvement. Local execution only: no remote E-CPU run. The published matrix multiplication exponent claim has not been refuted.
