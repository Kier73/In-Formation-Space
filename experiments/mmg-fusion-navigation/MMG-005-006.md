## MMG-005 rank-ground navigation
A witness is a sum of rank-one triples over GF(2). Common-factor flips are exact by bilinearity: a⊗b⊗c + a⊗d⊗e = a⊗b⊗(c+e) + a⊗(d-b)⊗e. Split a factor using the matching factor of a second term before a flip to expand the navigation graph; merge terms sharing two factors. All best witnesses checked against all formal coefficients; periodic walk checks and corrupted-witness rejection included. 280,000 navigation steps (five runs), n=2,3,4,8. Best ranks 7,26,49,343. The n=3 result improves a naive 27-term seed, not the known rank-23 baseline. No admitted sub-9/4 witness. Exact admission uses r^4 < n^9: tensor powers of a fixed identity yield exponent ≤ log_n(r). A merely faster host or compressed description cannot pass this gate.

## MMG-006: new exact partition ground
For N=2^w independent words of 2w bits, split each word into high and low w-bit labels. Let P,Q be the equality partitions they induce on the N record positions. A full word repeats iff a pair of positions belongs to the same block of both P and Q. Thus D(P,Q)=1 if and only if P∧Q is the discrete partition 0. Every partition is attainable, since each label alphabet has N values.

Order the partition lattice by refinement, with bottom 0. The zeta matrix Z[P,R]=1[R≤P] is unit triangular in a linear extension. Möbius inversion gives D=Z diag(μ(0,R)) Z^T, with μ(0,R)=∏_{B∈R} (-1)^(|B|-1)(|B|-1)!. Hence over characteristic p the rank of this exact bit-plane flattening is the number of partitions all of whose blocks have size ≤p. Over characteristic zero it is the Bell number. Repeated identical label-assignment rows and columns do not change rank. In characteristic 2 only singletons and pairs survive: the exact rank is the involution count I_N=I_(N-1)+(N-1)I_(N-2). For t independent lists the flattening is the tensor product and ranks multiply. 31 direct modular rank checks for N≤6 in five fields and N=7 in GF(2); 65,536 exhaustive actual four-record word tests. Counts for N≤256 computed by recurrence, not by enumerating all partitions. At N=16 GF(2) rank 46,206,736 instead of Bell 10,480,142,147. At N=32 GF(2) rank 22,481,059,424,730,751,232. This gives an exact characteristic-dependent change of basis, and an adversarial bond-dimension requirement for a tensor train with this cut.

A second cut, grouping first and last N/2 records, contains a permutation submatrix: choose both halves as sorted N/2-subsets of the same N-word universe, so acceptance means complementary sets. Thus rank ≥ binom(N,N/2) over every field. These statements constrain specific cuts, not arbitrary trivalent network topologies. They neither prove nor disprove the manuscript's independent-list volume theorem. Next: exploit Möbius support as an implicit matching/partition generating ground, accounting for the cost of contracting all independent inputs and for nonlocal network ordering; seek an explicit trivalent network family with volume per exterior bit below the claimed superconstant power, or a strict matrix-rank witness.

## Fermionic return path: exact distinctness Pfaffian over GF(2)
For an even number N of records let K_ij=1[x_i ≠ x_j]. In characteristic two K is alternating (symmetric with zero diagonal). If two records coincide, the corresponding rows coincide, det K=0 and Pf(K)^2=det K gives Pf(K)=0. If all records are distinct, K is the off-diagonal all-ones matrix, whose Pfaffian modulo 2 is the odd count (N-1)!! of perfect matchings. Thus D_w=Pf(K) identically over GF(2). This connects the obstruction tensor directly to the fermionic matching primitive used in MMG-002. mmg006_pfaffian.py invokes the actual prior Pfaffian verifier: 65,536 exhaustive four-record assignments and 540 mixed random/forced-collision/distinct cases for N=2..64, all exact. Measured local execution 0.447 s. The direct method materializes O(N^2) entries and uses cubic elimination; it does not yet save network volume. The next ground is an implicit Pfaffian kernel representation based on the equality partitions, followed by contraction-order discovery with all bit wires charged. Run python mmg006_pfaffian.py.
