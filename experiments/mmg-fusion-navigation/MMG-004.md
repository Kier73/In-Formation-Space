# MMG-004 — Correlated core translation

Run `python mmg004_core.py > mmg004_results.json` from this directory (numpy, sympy).

The source tensor train A has k cores, A_i[l,s,r] over F_p, with scalar coordinates given by contraction along the bond indices. Apply each local fusion transform M to its physical coordinate: B_i[l,o,r] = sum_s M[o,s] A_i[l,s,r]. Distributivity proves that contracting B realizes (tensor_i M)A exactly. The core transforms are independent tasks, even though the represented state is correlated. A nonzero minor of the actual large train's central flattening certifies that it is not a rank-one product across that cut.

For k=64, physical dimension 6, bond dimension 4, the state space contains 6^64 (~6.334e49) logical coordinates. Both input and transformed output have 6,000 explicitly stored field elements. Dense local core contraction charges 36,000 scalar product terms; sparse realization could use 19,000 but was not executed here. This is exact compact realization, not dense output enumeration. Coordinate observation costs O(k r^2), and dense input to low-bond tensor-train conversion is not assumed free. Arbitrary tensors may have exponentially large bond rank. The maximum temporary RAM is not measured.

Verification: 7,740 exhaustive small-coordinate comparisons across five fields, 200 independent large-coordinate comparisons, complete inverse roundtrip of all cores, and nonzero cut minors. Four local worker processes produce exactly the same core digest as serial execution. Serial time 0.565 ms, process pool 41.6 ms including creation and collection; this experiment is too small for distribution to pay off. No remote network, E-CPU admission or quorum recovery was exercised. Next: batch many core trains per host and compare input-dependent rank growth, routing and verification costs. The target remains the discovery of a useful decomposition or counterexample for general matrix multiplication; this experiment is not a rank decomposition of T_n and does not lower omega.

The core-level identity, not process parallelism, supplies the main compression.
