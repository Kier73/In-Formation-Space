The hosted integration executed an **actual HTTPS fetch** against the
public GitHub raw content service, with paths bound to the immutable
Git commit SHA and this repository's public object directory. A
separately launched, temporary read-only loopback HTTP process
provided a deliberately incomplete subset of the operation graph.
No external provider credentials or server-side executable functions
were used.

The receiver did not infer or invent missing operations; it used

The CAG-001 deterministic reconstruction digest was identical
between the two routes.

**What this establishes:** ordinary, noncomputing public/static HTTP
hosting plus a short-lived opt-in passive holder can expose parts
of a computation description. A separate observing program can
retrieve, verify and navigate those parts to locally reconstruct
a bounded pure arithmetic result, including after one holder
expires.

**What it does not establish:** content executing inside routers,
memory residing in any specific ISP device or CDN cache, independent
physical network paths, IPFS data placement, Tailscale live
networking, persistent multi-provider availability guarantees,
an externally signed source or operational E-CPU effect authority.
The public host is one authorized GitHub repository object provider;
the temporary host is local to the single GitHub Actions runner.
The fixture is five small exact-integer CAG-001 operations, not a
general neural network or verified E-CPU VM.
