## Aggregate size comparison

| Representation | Total bytes | Difference vs raw standalone |
|---|---:|---:|
| Raw PRC-001 standalone capsules | 1,376,809 | baseline |
| Zlib-compressed standalone capsules | 1,007,754 | 369,055 fewer (26.8%) |
| Global shared-provenance bundle | 1,301,948 | 74,861 fewer (5.4%) |

The global bundle is **294,194 bytes larger** than the zlib-compressed standalone set (29.2% larger relative to the compressed set). Its payload bytes are 652,349; manifest and local-entry metadata/framing account for the remaining **649,599 bytes**.

This is the central result: sharing the invariant source/toolchain manifest does save space versus repeating raw PRC-001 headers, but the local entry JSON still repeats a large amount of per-model and verification data. Header-only zlib compression of standalone capsules is substantially more compact in this experiment.

## Integrity and provenance

The shared bundle manifest binds the common IFS/E-CPU repositories and revisions, toolchain pins, and codec schema registry. Each entry retains its source Ground and typed-program digests, dense/sparse model digests, compiler route, interface, verification receipt, codec identity and payload digest. Bundle decoding uses the manifest to reconstruct the original standalone PRC-001 capsule and then invokes the original capsule validator.

SHA-256 provides integrity and identity checks, not author authentication or execution authorization. Verification receipts are replayable experiment evidence, not formal proof certificates.

## Follow-on direction

A better shared bundle needs to reduce the local entry overhead, not only store the common manifest once. The next design should compress or field-pack the local per-model headers and receipts while preserving:
- one independently verified shared manifest;
- per-entry source/model/codec identity;
- replay receipt digests;
- deterministic byte-identical reconstruction of the standalone PRC-001 capsule.

It should also retain a random-access option so one realization can be extracted and verified without decoding unrelated payloads.
