## Integrity and canonical metadata

The integrated run used PRC Canonical Metadata Profile v1: safe integers only, ASCII object keys, Unicode scalar strings, canonical compact UTF-8 JSON, and strict digest layers. The Node.js receiver independently validated framing, metadata, identity and payload digest on Python-generated capsule bytes.

SHA-256 remains an integrity/identity primitive, not author authentication or authorization. The embedded receipt is replayable experiment evidence, not a formal proof certificate.
