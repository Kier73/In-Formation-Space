# RGF-007 — Generative morphological algebra

Continuation of [RGF-006](RGF-006.md). Rather than assume uniform homogeneity, discover compatible nonlinear scaling operations from explicit polynomial morphology descriptions. This is an algebraic Gielis-inspired variation, not a continuous supershape test.

## Formation theorem

Let Q_k(x)=sum_e c_{k,e} x^e over F_p, p=2^61-1. Canonicalize and remove cancellations. A nonnegative integer weight vector w is a grading if every exponent in each nonzero Q_k has the same dot product d_k=e·w. Thus construct integer constraints (e-e_0)·w=0 for each polynomial and derive a rational nullspace using fraction-free integer elimination. Generate bounded nonnegative primitive candidate weights from null basis, signs and pairwise sums/differences; require some positive degree. This is a restricted search, not a complete nonnegative-cone solver. No candidate means refusal within this grammar, not proof no compatible action exists. For each weight and nonzero morphology Q_j, generate action F_{w,j}(x)_i=x_i Q_j(x)^w_i. Its observation dynamics z_k=Q_k(x) satisfy z'_k=z_k z_j^d_k. The identity follows monomial by monomial including zero using exponent-zero convention. Each action independently checks canonical source identity and every monomial weight. Verifier checks soundness of emitted operations, not completeness of the generator or arbitrary nonlinear closure.

Repeated action t times: let a=1+d_j and S_t=sum_{i=0}^{t-1}a^i. Then x_i(t)=x_i(0) z_j(0)^(w_i S_t), z_k(t)=z_k(0) z_j(0)^(d_k S_t). Compute S_t modulo p-1 by binary geometric composition (no division by a-1). For a zero base, positive exponent is tested from t>0 and w_i or d_k>0, not reduced residue. Zero exponent preserves the value. Different generated actions can be composed in order. This builds executable operations from a morphology, not just a description of a supplied action.
