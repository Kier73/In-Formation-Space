## Phase-indexed morphology

Q(x,y)=x^4+y^4 over p=2^61-1. Feature carrier h=(x^4,x^3y,x^2y^2,xy^3,y^4). Each linear source action A induces exact feature pullback h(Ax)=L_A h(x), by homogeneous polynomial expansion. An allowed mode graph has calm (rotation/scale) and rich (rotation/scale/shear). Rich -> calm uses identity, calm -> rich requires zero reset. A separately supplied external reseed may then initialize the rich phase; the benchmark explicitly charges projections for new coordinates, but is not live acquisition.

For each phase i, form W_i=span(Q, union over i->j edges of W_j L_A). Iterate to a simultaneous fixed point. The least tuple of row spaces is minimal among closed linear feature processors on this graph; polynomial degree remains fixed and the graph is finite. B_i basis, z_i=B_i h(x), edge action M satisfies B_j L_A=M B_i. Observation decoder factors Q through B_i. Verification derives independent projective evaluations at five distinct t with (1,t), checks each lift, each decoder and each edge identity; equality is exact for homogeneous quartics since degree < p. Independent raw-word queue and separate right-column rank elimination check minimality in this feature class. Static closure over all actions is a strong fixed nonlinear-feature baseline. Full two-coordinate source baseline uses same cached matrix powers. Cross-mode edges applied once; within-mode actions use logarithmic power jumps. State initialized per task. No claim of minimum arbitrary nonlinear processor, or of minimum phase graph. A surprise shear is refused by graph policy; to support it requires a different chart or external evidence. Equality of scalar Q alone cannot determine the post-shear value.

Independent oracle uses direct rotation/scale/shear/reset formulas, not feature matrices. Tests compare full source state, static projected feature state and fluid chart with scalar output at each block. Small F_17 enumerated independently: 289 states, 867 morph transitions, future-equivalence partition 13 -> 73 when shear admitted. This count is finite-field-specific.

## Nonlinear radial action

F(x)=Q(x)x, a nonlinear degree-five vector action, gives Q(F(x))=Q(x)^5 by homogeneity. Thus z_t=z_0^(5^t), navigated by exponent reduction modulo p-1 for nonzero z; zero remains zero. Compare against strong full-state formula F^t(x)=Q(x)^((5^t-1)/4) x. Compute exponent modulo 4(p-1) before exact division, handle zero separately. Independent raw eager reference at small t and direct feature evaluation at huge t, including 10^24. This is a separate exactly admitted operation, not included in the linear feature closure graph. The homogeneity identity is analytic; no general nonlinear action compiler or automatic discovery of radial operation in this increment.
