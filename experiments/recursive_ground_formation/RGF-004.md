# RGF-004 — Semantic geometry formation

Continuation of [RGF-003](RGF-003.md). The factor-span chart preserves each factor, not necessarily the meaning of a nonlinear expression. This round finds the minimum rank **linear** coordinate map for the polynomial observation. The source is a bounded explicit sum of monomials in k <= 16 linear factor coordinates w=Cx, p=2^61-1, degree <=3; C has an identity block in generated fixtures and is therefore surjective. Nonlinear coordinate maps or trajectory-restricted minimality are separate questions.

## Theorem (exact, on the declared full field domain)

Write grad f(w)=sum_m g_m w^m with coefficient covectors g_m. Let B be a row basis of the g_m. For u in ker B, D_u f=0 identically. Since total degree < p, the polynomial f(w+t u) has identically zero t derivative, hence is constant in t. Conversely translation invariance implies D_u f=0 as a formal polynomial: a bounded-degree polynomial vanishing on the full field grid is zero. Thus ker B is precisely the translation-invariance subspace. If f=q(Aw) as a function for any linear A, ker A lies in ker B; rank A >= rank B. A section S with BS=I yields q(z)=f(Sz), f(w)=q(Bw). In the full ambient x space the minimal linear rank is the same since C is surjective. This is not a claim of smallest arbitrary nonlinear encoding (for example a scalar observation can trivially be its own nonlinear coordinate without necessarily preserving future motion).

Implementation: canonicalize monomials, derive gradient coefficient rows, eliminate to pivot chart, form q via a coordinate section. Independent verifier derives gradients using grouped multiplicities on raw terms, checks rank via right-to-left elimination, expands q(Bw) by a recursive substitution distinct from construction, and checks every coefficient against independently grouped source terms. Bound degree and terms and expansion visits; refusal is not a proof of nonexistence. The chart is qualified once for an identical immutable-in-experiment source and reused across changing states, velocities and event histories. No cache of answers. Source law changes require requalification, not reuse by rank alone.
