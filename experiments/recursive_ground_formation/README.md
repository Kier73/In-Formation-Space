# RGF-001 — Recursive Ground Formation: transfer and external information

Question: does a reusable mathematical description improve independent tasks without retaining their answers? This is a bounded first experiment, not the full cross-repository integration.

Source dynamics over F_257: x' = x+1, y' = y+f(x)+u_t. Source f is supplied as an opaque finite table generated in the ordinary power basis; u is a separate ordered sparse event journal. An observer samples six entries, infers Newton coefficients by finite differences, and independently verifies all 257 source values. For a degree d <= 5, the reusable basis B_j(x)=binom(x,j) satisfies B_{j+1}(x+1)-B_{j+1}(x)=B_j(x) even across the modular boundary. Construction uses Pascal recurrence; independent qualification checks the falling-factorial identity and all cyclic differences. Therefore the sum is the difference of two antiderivative evaluations, plus the external prefix contribution. No individual source answers are retained across tasks.

Five comparisons: eager replay; fixed degree <=1 basis with eager fallback; cold discovery and compilation per task; warm reusable basis tables keyed by degree (admitted after source qualification); and a strong generic periodic prefix baseline, which works even on adversarial tables. All use identical tasks. Warm storage counts packed uint16 basis payload only, not JS object overhead. External event index verifies ordered unique times and every delta, then supplies prefix observations. Source and events are synthetic fixtures supplied by the test, not remote or physical measurements; an index is built per task and its work charged. Source generation is shared setup outside the compared costs. No other repo code is copied or imported.

Run: node rgf001.js > results.json (Node supporting Array.at). The experiment was actually executed as JavaScript in the authoring tool's V8 isolate using the exact serialized experiment function; results.json records that execution. It checks each output against an independent period-and-tail oracle, not the Newton basis or periodic prefix implementation. Tests include corruption away from the sampled prefix, duplicate event times, omission of an event, and a trillion-tick coordinate. The absence of an event is not detectable from an incomplete but internally consistent journal: the control demonstrates why source completeness is an external obligation.

Work is a declared unit model, not a wall-clock or FLOP measure: source reads, modular additions/multiplications, basis/prefix lookups, explicit comparisons, event reads and writes. It includes basis construction, mathematical qualification, source binding, index construction/verification, fallback and navigation; loop overhead, allocations, indexing arithmetic, degree-map access and actual byte transfer are not measured. The independent experimental oracle is separately reported and also included in withAudit, so that the conclusions can be inspected with or without repeated experimental validation. Storage is basis payload estimate, not total memory. No general nonlinear or P vs NP result.

Prior context: IFS translation discovery (reports/TRANSLATION_DISCOVERY_LOG.md), VL-K PAC-001 (https://github.com/Kier73/VL-K/blob/283c8cb0381a4e5491b5b47e8fabf573bfa44593/docs/PROCEDURAL_APPLICATION_CONTINUITY.md), E-CPU DATA-GROUND-001, and Navigable-Compute NCR-023 inspired the distinction between source binding, reusable description, and external information. Independent implementation.

Results:
- transfer-long: eager=3602820 units (0 basis compilations); fixed=2914133 units (1 basis compilations); cold=1299190 units (42 basis compilations); warm=717902 units (4 basis compilations); periodic=95298 units (0 basis compilations)
- short-horizon: eager=2258 units (0 basis compilations); fixed=23871 units (1 basis compilations); cold=455092 units (24 basis compilations); warm=144422 units (4 basis compilations); periodic=53784 units (0 basis compilations)
- unfamiliar-degree: eager=462608 units (0 basis compilations); fixed=369719 units (1 basis compilations); cold=479009 units (24 basis compilations); warm=215579 units (6 basis compilations); periodic=54096 units (0 basis compilations)

Interpretation: a universal mathematical vocabulary can transfer across distinct source coefficients, but source admission and external observations remain necessary. The generic periodic baseline is essential: on this finite cyclic source it can defeat the specialized vocabulary. Short horizons test discovery overhead. Future work: compare nonperiodic or exponentially large source spaces using symbolic certificates, and acquire external information through a native authenticated observer. Do not present these finite results as evidence of autonomous general-purpose discovery.
