## Compared formats

| Format | Representation |
|---|---|
| COO JSON | Existing sparse snapshot with per-row coordinate/value pairs |
| CSR JSON | Row offsets, flat input indices and values, separate bias arrays |
| Row-mask JSON | One integer bitmask per output row plus flattened values |
| CSR binary | Packed row pointers, indices and exact scalar values |
| Row-mask binary | Fixed-width row masks and packed scalar values |
| Hybrid binary | Per-row dense or bitmask representation, chosen by exact encoded size |

The dense baseline is provided in both canonical JSON and exact binary form. Signed int8 is used only when all coefficients in that tensor family are exact integers in [-128, 127]; otherwise IEEE-754 float64 is used. This is exact scalar representation selection, not quantization.

The values above are explicitly marked as pre-header-integrity pilot measurements; the final integrity-checked run adds a header SHA-256 field to each binary envelope. Use the final workflow artifact, not this pilot table, for exact final byte counts and timing samples.

The pilot's smallest-format choice varied by model density rather than following one universal encoding. The final result retains each of the 48 model artifacts separately so the byte comparison can be recomputed for every workload/compiler pair.

## Measurement semantics and limits

- JSON byte counts use sorted, compact UTF-8 serialization.
- Binary byte counts include the metadata header, header digest, body digest, and exact scalar body.
- Encode/decode timings are five-sample local Python measurements on the Actions host.
- Payload bytes are not Python heap or resident memory.
- The formats are prototypes and are not yet integrated into E-CPU runtime, durable session storage, or communication transport.
- Results cover the selected finite Boolean workload domains only. They do not establish a universally best encoding or general performance benefit on other hosts.

The full output artifact contains source revisions, exact per-model encoded byte lengths, selected coefficient dtypes, encode/decode samples, model digests, translation contract digests, and the aggregate result digest.
