# GLA-001 — Generative closure discovery

Build-to-learn experiment: can a matrix representation be assembled from multiple independently useful mathematical families, with the unknown part retained exactly?

## Contract
Over F_257, for square matrices of power-of-two side n, search for A = sum of circulant and rank-one terms + explicit sparse residual. Discover modal cyclic diagonals or a rank-one cross from observations of the supplied matrix. Select the candidate with greatest positive reduction in estimated application cost, up to four accepted rounds. Every coefficient is independently checked against A. Apply the representation to new vectors via exact NTT convolution or outer products plus sparse remainder. No input-family labels are available to the dispatcher.

Compare sparse-only (no law search), cyclic-only, rank-only, and joint greedy discovery on three seeded instances per size/family. The mixed family is a dense circulant plus a rank-one perturbation supported on half the rows and columns; random and identity controls expose failed discovery and costs. Five new RHS vectors per instance are tested against direct field multiplication. Independent direct convolution and transform round-trip tests cover eight transform lengths. Use `node experiment.js > results.json` to reproduce.

## Cost model
Setup is an explicit approximate ledger of cell scans, candidate construction, inverse/root preparation allowances and coefficient verification; application counts field additions/multiplications plus conservative NTT root-preparation allowance. It does not price JS allocation, map access, indexing, zero scans in the apply loop or wall time. All losing candidates are charged. The cost of q RHS columns is setup + q * perColumn; q may refer to one matrix product or reuse of a fixed A across several products. Break-even is computed from mean setup and per-column costs, not a measured time. Greedy search is not horizon-aware or guaranteed optimal. The baseline is sparse direct multiplication, not a best available general matrix algorithm.

## Results
The retained JSON is generated by executing the same experiment function in a JavaScript runtime. 916 independent product/transform comparisons passed; coefficient checks also ran in every discovered representation. This is finite exact evidence, not an asymptotic result. In particular this is a structured fixed-operand application experiment, not a counterexample to a lower bound for universal formal arithmetic circuits. Dense input observation and fitting are charged; full arbitrary residuals remain explicit.
