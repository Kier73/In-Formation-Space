# PGI-005 — Factored nonlinear rank memory and contextual transformation discovery

## Purpose and existing mechanisms

Extends PGI-003's `family_rank.seed_packet` / `RankSeedAdmission`, PGI-004's `CoordinateSkill` and independent pullback verifier, and CIG-034A's `View` / source-admission adapter. Uses CIG-025's canonical signed congruence expansion as the original memory. These are exact observation-language constructions; neither the nonlinear maps nor the contextual maps assert a processor transition homomorphism. Actual CIG campaigns qualify the original nonlinear source and independently check the mapped original endpoint. Derived target Views are mathematical observations of that source under the admitted pullback, not separately authenticated physical processors.

## 1. Nonlinear preimages, retained as factors

A canonical signed tail expression has terms `(r,m,c)` with `m | P`. For the ordered coprime prime-power basis `b_j`, let `d_j=gcd(m,b_j)`. Under a PGI-004 map `phi_j` the term pulls back to the rectangle

```
c * product_j [x_j in S_j]
S_j = {x in [0,b_j): phi_j(x) mod d_j = r mod d_j}
```

A full factor may be omitted; an empty factor annihilates the term. Complement contributes the constant one and negates the other coefficients. Identical factored terms merge, zero coefficients cancel. A term with a smaller prime-power divisor uses the preimage of the *congruence class*, not merely the inverse image of one radix value. The finite prefix follows the original PGI-004 contract (copy, or global complement); only the periodic tail uses the coordinate map.

`FactoredRank(source,target,packet,skill,max_work=4000000)` proposes this transport. `CheckedFactoredRank(admitted_seed,target,recipe)` requires a receiver-owned `RankSeedAdmission`, independently verifies the complete nonlinear relation and reconstructs the rectangles. The two implementations compute CRT preimages differently (gcd versus prime-power division, bit masks versus explicit local sets). The receiver reconstructs its arithmetic from the independently admitted original terms; it does not trust producer target arithmetic. Both check the exact period cardinality. Python objects are trusted within their process; this is not a secure external checkpoint or authority protocol.

## 2. Exact meet-in-the-middle chronological rank

For each rectangle let M be the product of the nontrivial radices. Split its factors into two groups by greedy cardinality balancing. For each group store the sorted CRT contributions A and B modulo M. A complete CRT phase is `(a+b) mod M`, with each admissible residue assignment represented exactly once. No full Cartesian product is constructed. If `F(z)=#{(a,b):a+b<z}`, the exclusive residual count for `0<=s<M` is

```
H(s) = F(s) + F(M+s) - F(M).
H(q*M+s) = q*|A|*|B| + H(s).
```

Producer uses a monotone sweep; independent checker constructs local CRT representatives by successive joins, embeds each half by its CRT idempotent, then uses three binary searches per element of the smaller half. Rank of the whole signed expression adds the weighted rectangle counts, handles the finite prefix and skips complete periods. Selection reduces a one-based ordinal into a period and residual ordinal; binary search yields the earliest phase reaching it. Receiver checks adjacent exact ranks `R(t)=k-1, R(t+1)=k`. Finite exhaustion is checked from exact prefix/period cardinality. Work exhaustion is UNKNOWN (preparation raises the existing budget exception); it never establishes nonexistence. The 4096-bit integer contract applies.

For half cardinalities L,R, index construction retains L+R entries (plus terms and local factors). The producer residual count uses O(L+R) sweeps; the checker uses O(min(L,R) log(max(L,R)+1)) comparisons. This is per rectangle per rank probe, plus big-integer arithmetic; preparation itself can still grow exponentially in support size, and an arbitrary signed sum may contain many distinct rectangles. Work counters charge cells, joins, sorting estimates and traversal operations; they are not CPU instructions or energy. The budget is per preparation/query/check, not a universal aggregate memory ceiling. The largest factored case below is a deliberately structured rectangle; a direct fresh factored compiler could also exploit that target structure. Fresh signed expansion and native CRT traversal are the tested existing baselines, not all possible algorithms.

## 4. Exploration outside separable coordinate transformations

PGI-004's separable map cannot introduce a new essential coordinate into a unary source observation. We first explore one dependent coordinate (`ConditionalSkill`) and then induce a context set (`ContextSkill`):

```
y_j = phi(x_j; x_C),   y_i = x_i for i != j
new_tail(x) = old_tail(y) XOR c
```

C contains at most three distinct controller coordinates (excludes j). Context rows are in lexicographic order. Discovery compares canonical restricted cofactors of source and target at every controller tuple and output residue. It matches target cofactors to source cofactors, allowing repetition for noninjective maps; the bijective option consumes matching source residues once per row. The independent verifier fixes each context tuple and traverses the synchronized pair of original diagrams, selecting mapped output arcs. Prefixes follow the same copy/complement contract. No discovery or compilation history is consulted.

An essential-support set is the set of live levels of the canonical reduced ordered MDD. For this grammar, `support(target) - support(source)` must be contained in C: the changed coordinate j must already affect the source, and no other new coordinate can influence it except the controllers. This supplies a necessary lower bound before trying maps, not a sufficient criterion or a minimum over arbitrary transformations. Search examines increasing controller count under a supplied maximum (<=3) and cell/work ceilings. No candidate skipped for resource cost establishes impossibility; UNKNOWN is the result. Control candidates and full rows can grow exponentially with controller count. The single-controller utility is retained as a simpler baseline.

Hold-out coupled Boolean functions (210 phases): 24 examples each generated with one, two, or three hidden controllers. PGI-004 separable discovery finds none; single-controller finds 24/24, 0/24, 0/24; the contextual search finds 72/72, with inferred controller counts matching all supplied counts in this sample. Full explicit small trajectories agree. An unrelated-pair control independently samples 24 source/target functions: 18 admit exact contextual maps, six remain UNKNOWN. The successful maps are essentially truth-table-sized (median 530 serialized bytes, median target diagram 739 bytes), so relation existence is not evidence of a transferable explanatory law or improvement over direct encoding. The grammar is highly expressive when most coordinates can control the output. This is an important negative control, not 18 newly established laws about real systems.

## 5. From a table to a compact contextual family

For a unary one-event source at output modulus m (odd), the target gives one event residue for each relevant context. Its event displacement determines a shift h(ctx). Propose a supplied low-degree family

```
h(x) = b + sum_i (l_i*x_i + q_i*x_i*x_i) mod m
y_j = (x_j + h(x_C)) mod m
```

Sample the origin and first/second offsets along each axis (one offset only for a binary axis); derive linear and quadratic coefficients by exact finite differences, using the modular inverse of 2. A binary controller has indistinguishable x and x^2 and is retained as linear. Try the linear recipe then quadratic. These samples propose a model; the independent verifier reconstructs the entire map and qualifies it against both admitted Views. A cross-term control `x0*x1+x2` defeats this additive grammar, and returns UNKNOWN. Sixty randomized quadratic examples also test reapplication to a different two-event unary source; every new source/target pair is independently checked. Compact recipes bind source and target IDs; changing the source requires new qualification.

In the actual CIG campaign, the original source is a single selected marker on a prime-power spatial cycle, and the target is a hidden nonlinear local displacement controlled by three other radices. The target is independently constructed from its explicit local law; discovery receives only the two Views. The target depends on three coordinates absent from the original observation. Separable and one-/two-controller grammars cannot express this particular relationship. A three-controller search examines one controller/output candidate after support analysis, then builds a qualified map. The quadratic recipe is inferred with six or seven context probes, and independently qualified on the full tail language. Each largest-scale target has a much smaller local observation period than the common processor period; the target's 1,410 local phase domain is intentionally tractable, despite the enormous common period. Eight huge ordinals per source scale agree with independently enumerated local CRT phases, native rank verification, and mapped original CIG terminal admission.
