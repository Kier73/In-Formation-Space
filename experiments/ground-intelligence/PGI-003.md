# PGI-003 — Parametric skill families and transported rank memory

## Implementation and scope

Builds on [PGI-002](PGI-002.md), [CIG-025](../pnp-ground-navigation/cut_intention/CIG-025.md), [CIG-032A](../pnp-ground-navigation/cut_intention/CIG-032A.md) and [CIG-034A](../pnp-ground-navigation/cut_intention/CIG-034A.md). VL-I's problem-formed interpreter and Navigable-Compute's exact nonlinear Grounds informed separation of mathematical language, source admission and realization. The initial family grammar is supplied by the implementation, not invented by training: positive integral affine time pullbacks with optional Boolean complement. Training activates reusable discovery methods from independently qualified demonstrations with varying coefficients and distinct source identities. It does not fit a finite list of coefficients or learn a new arbitrary program language. All proposed relationships receive the existing PGI-002 synchronized whole-language check. Training views must already be admitted by the caller; no external authority is inferred from a digest.

`FamilyIntelligence.observe(source,target,trace)` checks the trace normal form against the whole target; `induce()` requires at least three source identities and distinct strides and offsets. `discover(source,target)` sees only the mathematical View, not its construction history or namespace. `instantiate(source,method,form)` constructs and independently checks a new View with no target supplied. `express` and `verify_expression` implement source/target/parameter/ordinal-bound exact selection for the native CRT navigation route. A recipe `packet()` retains training-example references and qualified method identities; `restore(packet,views)` replays every demonstration and family eligibility check using separately supplied Views. Packet bytes exclude these Views. The learning state is advisory; correctness of future activation is independently established. `UNKNOWN` means the offered grammar/budget did not resolve the relationship. The primitive-first option tries the five PGI-002 primitives before family search.

## Sparse parametric discovery

For source period P and compact target period Q=P/gcd(a,P), let d=P/Q. The map t -> at+b modulo P has image b mod d, and is injective on Q consecutive target phases. With sparse source phases S and target phases U (or their complemented counterparts), every ordered correspondence r1,r2 in U to s1,s2 in S must satisfy

```
a = d*u, gcd(u,Q)=1
u*(r2-r1) = (s2-s1)/d (mod Q),  d divides s2-s1
b = s1-a*r1 (mod P).
```

Solve the linear congruence by gcd and modular inverse, enumerate remaining residues only under the work/candidate budget. The source/target event tables are extracted using CRT decision-diagram paths, not iteration across P. At most 32 phases/holes per set are offered. For a single target phase, try canonical stride d and corresponding offset; arbitrary unit multiples may be necessary for finite-prefix matching and are not exhaustively searched. For an empty target minority set, find a residue class modulo d containing no source event, without enumerating all classes. Try a canonical missing class and finite-prefix offsets. Constant source tails and larger/alternative basis relationships need further routes. The full checker is decisive; neither a failed proposal nor refusal proves global nonexistence. Residue-equivalent coefficients are lifted to finite representatives relative to the source cutoff so that a periodic equality does not silently erase a transient. Historical coefficient recovery is not required; any exactly equivalent map is useful.

## Dense parametric discovery

For an ordered reduced MDD and CRT coordinate j, two digits r,s have identical cofactors iff they have equal child IDs at every reachable node of level j. This is an exact equivalence relation, not sampled similarity. A bijective local affine map preserves this partition up to a permutation of its classes. For identical bases and unit stride, derive local candidate pairs (a_j,b_j) by matching partition classes and class cardinalities. Choose a representative of a least-populated target class to generate translations; enumerate local unit strides, check the class bijection and combine the surviving coordinate pairs by CRT. Infer polarity from one periodic sample; independently verify the complete relation including finite prefix. Complexity depends on local radix sizes, reachable diagram size, and potentially exponential cross-coordinate ambiguity. A random coupled truth table control needs multiple global candidates; an unrelated table on the same basis with the same cardinality is refused. This is a sound proposal method, not a general polynomial-time equivalence algorithm. Dense nonunit discovery is future work; supplied nonunit forms can still be independently compiled and checked by PGI-002.

## Signed-rank memory as a parametric family

Reuse CIG-025's signed expansion of an admitted View:

```
f(t) = sum_i c_i [t = r_i (mod m_i)]     on the periodic tail.
```

For target f(a*t+b) xor c, each term has no solution if g=gcd(a,m_i) does not divide r_i-b. Otherwise it becomes one progression with modulus m_i/g and residue ((r_i-b)/g)*(a/g)^(-1) modulo m_i/g. For complement, negate the signed coefficients and add the constant 1 progression. Combine duplicate terms. Prefix is separately obtained and qualified through the actual target View. The transformed period is P/gcd(a,P). An exact rank is the finite prefix count plus full-period counts plus floor-sum rank of a residual period. Reuse CIG-025 discrepancy-directed binary selection. `seed_packet` uses the actual CIG-025 expansion; `RankSeedAdmission` independently reconstructs it bottom-up on the live View and checks source binding, arithmetic and work record. `TransportedRank` produces derived terms; the receiver independently solves each congruence using extended Euclid after rechecking the complete pullback relation, then verifies adjacent ranks for each FOUND ordinal. It independently qualifies finite exhaustion. A recipe contains only identities and coefficients; the receiver needs both source memory and target View already admitted. This transports proof arithmetic, not a precomputed absolute result. Receiver and producer still do work; the transported representation can be larger/slower than fresh expansion. No physical energy measured. Term work excludes sorting, gcd/inverse bit complexity, Python overhead, target construction and independent terminal audits.

## Verification and reproduction

From this directory set PYTHONPATH to the CIG cut_intention directory and use the preceding PGI files on the same path.

```sh
python -m unittest test_family_language test_family_rank test_skill_language test_ground_intelligence test_ground_network test_seed_network -v
python run_family_language.py
python run_family_rank.py
```

37 focused tests passed (12 new test methods plus 25 previous); 420 CIG predecessor tests separately passed (overlap, not additive). New tests include 100 randomized sparse laws, 60 dense random laws, 25 cofactor partitions checked across all explicit states, random coupled truth-table and same-basis negative controls, finite prefix lifts, constant contraction, recipe restoration and tampering, 300 randomized signed-rank transformations with explicit ranks and 1,200 ordinal checks, and 20 complement/extraction controls. The signed rank test verifies both finite and recurring outcomes. Full JSON ledgers and regression logs accompany the source. Dedicated Linux/Windows workflow runs focused tests and smaller source campaigns. Remote CI separate.
