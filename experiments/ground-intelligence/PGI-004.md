# PGI-004 — Induced nonlinear coordinate transformation spaces

## Contract and connection

PGI-003 discovers global affine time pullbacks and transports signed rank memory. PGI-004 discovers a wider family of callable transformations using the actual immutable CIG-034A `View` and its native rank/select/independent ordinal checker. It follows the exact-cofactor idea in PGI-003, VGI's sparse refinement of observed equivalence classes, and NCR-007's distinction between a source operator and a qualified observation operator. This iteration supplies the separable map grammar; it discovers the maps from a requested source/target pair, not the grammar from unstructured data. It does not claim a neural model, universal synthesis, or a physical-time transformation.

For a common ordered coprime prime-power basis `(m_0,...,m_(L-1))`, the tail of a Boolean observation view is a reduced MDD function `f` on the entire product of residue coordinates. The callable skill is

```
Phi = (phi_0,...,phi_(L-1), c)
phi_i : Z/m_i -> Z/m_i
c in {0,1}
g(x) = f(phi_0(x_0),...,phi_(L-1)(x_(L-1))) xor c
```

The CRT is a bijection from one common period to that product. The coordinate image of a time is an arithmetic phase, not necessarily a time-respecting state transition. Both views have the same declared basis and cutoff. The finite prefix is copied and optionally complemented, not shifted or silently remapped. This preserves exact semantics even when the phase image falls numerically before the cutoff. No minimum period claim: the compiled view retains its original common basis; reduction removes unnecessary MDD nodes. Distinct bases, cutoff changes, coupled coordinate functions, and time-order-preserving state-map claims are separate contracts.

`compile_view` reindexes MDD children and canonicalizes bottom up. The independent `verify_pullback` uses a synchronized traversal of the original and target diagrams, validates every local table, prefix and reachable terminal pair; it neither calls the discovery search nor trusts the compiler. It traverses reachable paired subgraphs, not all global times. A skill can be retained and activated on a new compatible view. `Vocabulary.restore` requires independently supplied original views and replays each stored example before restoring the skill; a hash is not evidence or authenticated host identity. On activation, a newly compiled view must independently qualify again. `compose(first,second)` is a callable operation on skills: local tables are `first.maps[j][second.maps[j][r]]`, polarity XOR. An independent composition checker recomputes every entry. Example records are local, not E-CPU durable authority.

## Discovery: bijective maps

At a given level j, earlier choices give a finite set Q of paired source/target cofactors. For every residue r define the joint child vector `V(r)=(child(u,r) for (u,v) in Q)` on the source and analogously on the target. Skipped levels have a constant child. For a common bijection on the remaining coordinates, distinct functions remain distinct, so equality of joint child vectors is preserved by the map, even under output complement. Each class must therefore match a source class of equal size, with equal suffix counts (or complemented counts). Those counts are computed exactly from the reduced diagram and remaining radix products. Counts are necessary constraints, not final proofs. Match one-to-one classes by signature; choose an arbitrary bijection inside a matched class since it induces identical successor constraints. The union of paired children is Q for the next level. Backtrack when needed. At the terminal check all required Boolean pairs; then independently replay the completed relation. The finite grammar is exhaustively searched if the budget permits, but the number of matchings can grow combinatorially. `UNKNOWN` includes exhausted or unsupported searches; it is not a proof of impossibility. This uses no target namespace, construction trace or hidden generating permutation.

## Discovery: noninjective coordinate maps

Cardinalities and cofactor distinctions can change. The stronger equality-class and count constraints above must be abandoned. For fixed common suffix maps, every occurrence of a given source cofactor must yield one and the same target cofactor. Thus the relation of paired cofactors must be functional from source node to target node. If the source is terminal, the target must be its (possibly complemented) terminal. For every joint target child class, try a representative joint source child class. Any satisfying map can be normalized to one source representative per identical target vector without changing what remains to qualify. Retain the union of induced constraints, reject nonfunctional unions immediately, and recurse. Source class reuse is permitted; unlike the permutation route, multiple residues can map to one source phase. The independent whole-view checker is identical for both discovery routes. This supports exact induced many-to-one maps, including erasure of an entire observation distinction. Search cost can be much higher than permutation matching.

## Actual usage

The controlled held-out synthetic campaign uses disjoint new seeds, no training traces supplied. The previous PGI-003 family is trained with its original 12 demonstration fixture; it uses a 128-candidate/100,000-work limit. New routes have a 2,000,000-work limit. Every successful synthetic relationship is qualified globally; small periods additionally use direct explicit trajectories, the enormous-period controls use 64 independently constructed CRT-phase samples per task. The 60 coupled controls are arbitrary truth tables on 3*5*7*11=1155 states, not merely XOR products. The 24 large parity controls use a 15-prime common period of 16,294,579,238,595,022,365. The 40 many-to-one controls use random functions and random local tables on 105 phases.

On each of four actual CIG source sizes, derive a source-qualified CNF/transport observation that is true at exactly three successive marker phases of the original common period. Generate a hidden local permutation mapping the selected three residues at prime 7 to the target set {0,1,3}. These are not an arithmetic progression modulo 7, whereas the original projected event set is. A unit affine map at prime 7 would preserve progression; a zero multiplier at that prime cannot create dependence on it. Any successful noncomplemented affine mapping must include all three original residue values in its preimage, since the target projects to three distinct residues there. A complemented affine mapping cannot match: for a unit at prime 7, each fiber with other coordinates fixed contains at least four ones, while the target has at most three; a zero multiplier again cannot produce the target's dependence. Consequently this is a genuinely non-affine observation relationship, not merely a non-affine representation of an affine relation. The synthetic unresolved affine results alone do not prove nonexistence.

The target is a newly constructed mathematical observation view, not a second independently observed external processor. Source CIG admission is independent; the target view is qualified through the whole-domain relation, not assumed from the hidden generating map. The independent ordinal oracle computes the three full CRT phases from the hidden permutation; it does not use the discovered map or target rank implementation. For each distant ordinal, check native exact target rank and original CIG terminal receipt at the reconstructed source phase. The source phase is a representative modulo P, not equal to the target time or its chronological ordinal.

Then alter one local map to duplicate the preimage of one event, yielding four realizable phases in the same period. The bijective route cannot realize a different cardinality; the general discovery route reconstructs an independently qualified map. Verify eight additional distant ordinals by independent enumeration of the hidden map's local preimages and CRT, native target ordinal verification and original terminal receipts. The actual source preparation, discovery, selection and terminal audit are separately measured. No global-period enumeration occurs. Map table byte counts are serialized map arrays only (exclude source/target keys, metadata, runtime, retained views and receipts).

Results are in `PGI-004-results.json` and regression logs. The synthetic work totals account for the explicit `Work` charges, not all Python overhead/sorting/big-integer bit costs. Wall-clock measurements are local and empirical. Synthetic discovery 84/84 permutation tasks (PGI-003 0/84 under its bounded grammar), 40/40 general maps (permutation route 0/40); these are success/work comparisons, not speedups between two successful solvers. Many-to-one search explores substantially more branches in the coupled controls. All eight actual relationships and 64 ordinals verified. The large permutation case uses 7,879 charged operations, 15 matched class choices, and zero backtracks, with 888 serialized map-array bytes. The largest noninjective case changes 3 events to 4, uses 6,398 charged operations and 15 branch choices. Direct native rank selection remains relatively costly on this sparse fixture because it uses chronological CRT cover probes. Future optimization: transfer the admitted signed rank memory through coordinate preimages, and choose between expansion and factored arithmetic, explicitly charging growth.
