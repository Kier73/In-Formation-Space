An immutable source is wrapped in a bounded read-through memory with per-byte coverage. A prefix sensor proposes a ramp or period. The VLM admission scan stops at the first mismatching block; derive its exact first differing coordinate and reuse the failed descriptor restricted to the admitted prefix. Recursively investigate the suffix, bounded to four splits and at least 64 bytes on both sides. Otherwise use original VLM exact route search. Keep the split if its logical descriptor size beats raw, not necessarily the best global compact route; this is a heuristic, not optimal segmentation. A mismatch need not be a true change-point. An isolated mutation or coincident prefix can misdirect discovery. Cached and uncached split use identical operations. Each source receives fresh memory; no cross-epoch reuse.

160 synthetic sources, 40 each of ramp/period/constant mixtures, ramp+random, uniform ramp, random. Compare original whole-source VLM exact, same with memory, fixed 256-byte windows with memory, and witness-directed splitting with/without memory. All 800 source reconstructions and 9600 range sums checked directly against original bytes using the original Ground.read/total, separate from the producer cache. Source lengths, cache hits, total requested bytes, underlying Source.read counts, logical retained descriptor sizes (including 4-byte count and 4-byte offsets), split counts and independent audit bytes recorded. The peak_cache field is the sum of per-source two-byte-per-coordinate cache allocations, not simultaneous peak memory or process RSS; the source itself is already in memory. This is logical acquisition accounting, not physical I/O, complete machine work or timing. Audit reads are separately recorded. Cached routes read every byte once from the underlying Source, which is also the raw exact-capture lower bound for arbitrary bytes without trusted prior proof; gains are reduced redundant read calls and retained representation size. Cache cost is real; on random and uniform inputs global cached is competitive, and no universal advantage is claimed.

Run `python clt012.py --vlm /path/to/pinned/native64`. CI uses the actual full pinned module and reproduces the measured JSON via parsed equality. A separate optional --artifacts gate builds the VLM and tests its actual source and binary artifacts; it has not run locally. No physical E-CPU or bare-metal test claimed. The split witness is an observation-derived action (change segmentation); next investigate a bounded policy that chooses between split, alternate codec and raw based on measured marginal utility, including persistent storage and trusted source identity.
